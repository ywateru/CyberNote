# CyberNote 产品网站与账户体验

## 定位与信息架构

网站面向想记录生活与工作的 macOS / Android 用户。首页先解释本地笔记，再说明用户明确选择的设备同步，最后提供真实源码与 CI 构建入口。网站不承诺云端笔记编辑、后台长期保活、正式签名或已经完成的商店发行。

| 页面 | 路径 | 内容与行为 |
| --- | --- | --- |
| 产品首页 | `/` | 产品介绍、编辑器示意、文字/图片/录音/附件能力、本地保存、同步方式、源码、构建包与常见问题 |
| 账户与设备 | `/console/` | 未登录引导、真实托管登录、账户身份、产品选择、设备在线状态、刷新与退出 |
| 授权回跳 | `/console/callback/` | 与账户页完全相同的入口，保留 code/state 给现有 PKCE 流程处理 |
| 连接服务文档 | `/docs/` | 保留底层协调服务文档，与产品功能说明区分 |
| 管理入口 | `/admin/` | 现有独立鉴权管理页面，不在面向用户的主导航曝光 |
| 源码与构建 | GitHub 外链 | `ywateru/CyberNote` 源码与 Actions 构建；仓库私有时说明需访问权限 |

## 视觉与响应式布局

沿用应用的系统字体、白纸、淡灰分组和黄色操作，避免将产品主页做成 SDK 控制台。基础色为纸白 `#ffffff`、正文 `#242426`、次级文字 `#66666e`、分隔线 `#e6e6eb`、柔灰 `#f6f6f8` 和淡黄 `#fff4d4`。标题使用系统字体的中粗字重，正文保持左对齐与适度行长。

桌面首页：顶栏 → 左侧产品文案 / 右侧笔记界面示意 → 记录能力 → 本地与同步 → 源码 → FAQ。移动端切换为单列，导航允许分行，笔记示意保留文件夹与正文的关系，320px 下没有横向溢出。无外部字体、统计脚本、追踪像素或用户笔记截图。示意内容是手写合成文本。

账户页桌面为账户侧栏和设备工作区，移动端上下堆叠。按钮至少44px，长身份/设备名允许折行；焦点可见，首页锚点滚动尊重减少动态效果偏好。账户页面延续原登录代码，HTML 与 callback HTML 必须保持一致。

## 登录与数据边界

1. 未登录：只显示引导和未登录状态；授权配置读取失败显示真实错误，不伪造设备或登录成功。
2. 登录：使用既有 Console SPA OAuth/OIDC + PKCE 流程，账户密码只进入托管身份提供方。只存储必要的短期 OAuth 事务，访问 token 和协调会话不持久写入 localStorage。
3. 已登录：显示服务确认的账户身份、可访问产品、在线设备与最近刷新时间。Console session 与原生设备 session 权限分离；设备在线不等于笔记已经传输。
4. 刷新失败/权限变化：清除过期设备快照并显示未知/失败状态，保留现有跨请求及 generation 检查。
5. 退出：清理当前页面内存状态并尝试撤销控制台会话；不得声称已经退出其他客户端。

页面不读取原生端私有账户 profile API、不保存笔记正文和附件，也不提供云端笔记编辑。笔记数量/摘要若未来需要在浏览器展示，必须新增明确授权的 Console DTO，不能把 Native bearer 接口直接开放给网页。

## 发布与后续规划

产品首页及沿用真实鉴权代码的账户页随协调服务的 Node/Vercel 构建打包。GitHub Actions 构建客户端与校验网站；生产部署沿用既有项目配置。新域名部署时必须逐项配置同源 callback、CSP、公开身份配置并验证完整登录回跳，不能仅凭静态页面可访问宣称登录成功。

下载区提供版本化 Release、校验文件、第三方许可与平台安装说明。正式签名和公开分发另行安排。源码保持当前保留权利声明；私有仓库不对外宣传为开源。账户编辑、邮箱验证、密码重置继续使用身份提供方能力，不在网站重复存储账户密码。
