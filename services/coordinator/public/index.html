前往 GitHub

开始之前

需要先注册账户吗？

本地编辑不需要账户。只有在多台设备之间使用账户同步时，才需要登录同一账户。

网站可以查看我的笔记吗？

网站提供产品介绍和账户设备控制台，不是在线笔记编辑器。协调服务处理身份和设备连接信息，不保存笔记正文与附件。

在哪里下载和安装？

在上方下载区选择对应平台，或进入 GitHub Release 查看完整发行文件。仓库目前为私有，需要访问权限。macOS 包未公证，Android 包未签名，需要开发者签名后安装。

源码使用什么许可？

项目当前保留作者权利；仓库可见性不代表开源授权。第三方组件遵循各自随附的许可，具体见仓库 LICENSE 和 THIRD_PARTY_NOTICES.md。
