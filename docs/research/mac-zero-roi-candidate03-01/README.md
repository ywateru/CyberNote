## 比较边界与方法

两图均为 2×，但窗口尺寸不同。不得缩放配对。仅取相同可见状态“搜索 / 无结果 / 备忘录”的内部文字，比较它们相对共同列表左边界 x=456 px、窗口顶边 y=0 的位置。列表右边界原版 x=1016、candidate03 x=1014，完整列表宽度差 2 px，因此完整列表 header 并非等宽控件对。文字内部原生裁剪为 `[480,15,680,168)`，保持原始像素，不作平移或缩放；边框及玻璃背景不参与差分结论。

以 `min(R,G,B) < 160` 提取手动限定区域内的文字前景，另在 128 / 180 / 200 阈值复核。坐标为左闭右开的截图物理像素。位置差在阈值变化时稳定；这不是字体识别或验收评分。所有输入 SHA-256、区域、阈值结果见 `measurements.json`。
