## 坐标和方法

所有数字都是解码后的图像像素，左上为原点，边界框为 `[x0,y0,x1,y1)`，右边和下边不包含在框内。报告不把它们换算为 AppKit 点、CSS 像素或 DPR，也不把墨迹顶部称为排版基线。

中性墨迹条件为 `299R + 587G + 114B < threshold × 1000` 且 `max(R,G,B) − min(R,G,B) < 25`，分别计算阈值 **120 / 160 / 200**。正文横向 ROI 为原版 x=[1210,2760)、候选 x=[1300,2760)，这是显式的绝对取样范围，没有移动原图或强制配准。逐行 y ROI、空段 ROI、重复后缀 ROI 以及所有边界框见 JSON。空段只判断指定矩形内是否存在满足条件的像素，不能据此单独测出段落框高。

以下主要展示阈值 160；阈值敏感项另列。所有边界框已从本轮文件再次独立计算，旧报告数字未用于填充本轮结果。

## 本轮可支持的结论与边界

重复正文和空段前后的纵向推进稳定复现：候选前部偏高，部分间隔比原版多 1 图像像素，到空段后部分行重合。首行、末行和重复后缀已各自列出，长段两条视觉行的垂直位置也已单独测量。

本轮仍存在列宽、正文左分隔线和长段换行差异，焦点状态也不能认定为相同。没有测量真正字体基线、正文右边界、动态交互或同焦点状态，JPEG 阈值墨迹也不是无损像素判定。本轮报告不宣称像素 PASS，也不从这些截图单独推断字体根因或应采用的 CSS 改动。
