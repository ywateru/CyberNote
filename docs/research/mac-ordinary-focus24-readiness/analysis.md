本轮仅只读 [SmartFolderForm.tsx](../../../src/SmartFolderForm.tsx)、[smart-folders.css](../../../src/smart-folders.css)、[style.css](../../../src/style.css)；未读正在修改的 App、types 或侧栏helper。

- 20未改上述名称框规则；源码仍有同一候选接缝。这不是20后准确包画面的测量：当前23只有原版输入，旧克隆18不能冒称Mac11现状。

## 建议最小任务与验收边界

优先只改 `.smart-mac .smart-ordinary .smart-name input` 及其焦点/选区局部规则，保留真实可访问input与现有组件聚焦/选择逻辑；禁止全局input或selection改动。先验证内边距能否使文字左缘左移4图像px，同时保持输入外框、焦点外包、名称标签、纵向基线和400×207 CSS表单布局。19/20既有DPR2映射是定位线索，约2 CSS px的候选必须按真实WK和准确包验证，不把截图差值直接当固定实现。

验证须覆盖准确Mac11包首次打开、全选默认名称、输入替换、部分选择、失焦/重新激活与键盘取消；清楚记录图片捕获时的激活状态。保持ordinary局部约束，并核智能创建/编辑、手机名称输入和深色可读性；没有原版深色目标，不能授深色像素通过。若候选需要改focus逻辑、原生层或整个表单布局，应另列任务而非混入本批。
