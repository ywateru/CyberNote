## 自然字形：保持unknown

自然raw160覆盖1162与1166接近，但94个原版独有和98个克隆独有像素相互抵消，不能称形状一致。以白底为固定端点，仅拟合一项全局墨迹强度缩放，raw/sRGB三通道斜率约0.998；glyph union每通道MAE约30.3，拟合后仍约30.4–30.5，未改善。它否定本采样上“只差同一个整体墨迹强度”的解释，不能证明具体font-weight或光栅机制。

## 选区底色、ICC与混色边界

固定无字色条[145,120,265,124)共480px，原版raw(249,235,198)，Mac13 raw(247,233,204)；独立相同ICC转换后分别(252,234,193)/(250,232,200)。差异在raw已存在，统一ICC后仍存在，不能归咎只漏做某一张ICC转换。ICC转换会改变差值，不证明绝对显示已匹配。

该色条在字形上方、选择区内部，但JPEG4:2:0及块变换仍会受附近边缘影响，像素非平坦常量；各通道min/max完整保存。因此底色中值不能直接复制成CSS，也不能认定取样未落在字形上就完全没有压缩混色。

当前CSS背景本来就是#fceac1，即(252,234,193)，准确13仍拍到(250,232,200)。26的离屏声明绘制曾约(251,233,193)，Safari实际全选约(250,233,197)，显示宿主/激活/捕获路径不能由一次离屏RGB覆盖。具体偏差来自系统选区颜色处理、混色或捕获的比例本轮unknown。不能简单把背景乘白色alpha：与当前CSS目标相比，实拍红绿降低而蓝升高，单一白底混合不能同时解释三个方向；这也不是复杂色彩管线的排除证明。
