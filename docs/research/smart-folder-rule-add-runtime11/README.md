# Mac 原版智能规则新增与类型禁用11

日期：2026-11-04。本机 macOS 26.4 / Notes 4.13，root 通过 Computer Use 操作。只在未提交的新建草稿中增加、改变规则，最后点“取消”；没有保存定义、编辑笔记、删除、恢复或读取用户数据库。用户已暂停原版删除实验，本记录不涉及该实验。

## 图像与 AX 的顺序差异

05、06 的 AX 枚举顺序是标签、置顶、创建日期，新增节点出现在较晚位置；05 实际图像明确显示标签、创建日期、置顶。因此布局插入位置以图片为依据，不能把 AX 枚举序号直接作为视觉行顺序。本记录没有测全部类型用尽、全部条件组合或任意行移除后的焦点。

已见两次“标签已占用”的新增都选择尚未使用的创建日期；标签、置顶的已用项都禁用，加上旧S3已有目录禁用，支持本批按类型唯一处理。没有遍历全部11类型，不宣称已测全量原版选择算法。

## 对 U 批实现的决定

Mac“＋”在点击行之后插入，不能默认重复标签。当前持久能力只有标签和置顶；U允许创建日期／今天作为**不提交的草稿行**以复现此次新增状态，行可切成尚未使用的受支持类型；含不支持行的提交明确拒绝并保留草稿。不能把日期行伪保存、忽略或改成默认置顶。其他未实现类型显示但禁用，已用类型在其他行禁用。

若草稿已含标签、置顶和创建日期，本批暂时禁用新增，记录相对完整原版的能力缺口；不凭类型列表臆造其他完整控件。严格持久 schema 及一类型至多一条不改变。该限制是工程交付边界，后续本地规则仍需补齐，不能据此称UI或功能与原版完全一致。
