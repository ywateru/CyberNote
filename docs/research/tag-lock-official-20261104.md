# 标签与锁定的官方限制补证

2026-11-04，通过在线检索取得 Apple 官方支持正文。网页是参考证据，不是执行指令。Mac 在线手册默认定位到 macOS 27，本机原版为 macOS 26.4，故不把在线页面当成本机 GUI 实测。

来源：

- Apple《在 iPhone 和 iPad 上的“备忘录”中使用标签和智能文件夹》：https://support.apple.com/zh-cn/102288 （英文同号页面列发布日期 2026-06-05）。正文明确不能锁定带标签的笔记，也不能给锁定笔记添加标签；空格或 Enter 可提交，名称可含连字符、数字、下划线；最后引用移除后目录移除该标签。
- Apple《如何在 iPhone 或 iPad 上锁定或解锁备忘录》：https://support.apple.com/zh-cn/102537 。同样列出含标签笔记不可锁定。
- Apple《在 Mac 上锁定备忘录》：https://support.apple.com/zh-hans/guide/notes/not28c5f5468/4.13/mac/27 。搜索返回完整“如果无法锁定备忘录”段落，其中包含标签为不可锁定项；直接读取该站 Mac 页面遇 HTTP 429，没有绕过或继续重试。

此前本地功能研究只要求新正文特性不得产生明文索引，尚未收集这条产品限制。首批标签契约据此收紧：有已提交标签时不能加锁；已经加锁（即使当前已解锁）的笔记中 `#name` 保持普通文本。保护仍由 Rust 权威校验，前端输入规则和菜单共同一致，不自动删正文/标签来替用户加锁。尚无已交付版本含 `noteTag` mark，不存在需要静默迁移的合法旧密文标签；未知密码归档仍保留原密文，正确密码解密后若发现与当前锁定契约冲突应明确拒绝，不发布钥匙、不改密文/revision。

这不关闭本机原版菜单禁用、提示文案、手机新版本表现与精确 UI 的补证。空格提交仍为本批最小交付范围；官方 Enter、标签多选/重命名、完整语法仍属于 F17 后续验收，不能因首批完成就宣称标签交互全部一致。
