## 方法与共同限制

坐标均为原图解码像素，左上原点，框为 `[x0,y0,x1,y1)`；不换算DPR、AppKit点、CSS像素，不把墨迹顶部称为真实排版基线。中性墨迹条件为 `299R+587G+114B < threshold×1000` 且 `max(R,G,B)−min(R,G,B)<25`，阈值为 **120/160/200**。逐图绝对ROI、行映射、全部框及差值见result.json。没有图像平移、缩放、强制配准、抹除或字体宽度归一化。放大裁剪只用于人工读换行，测量一律使用原始图像。

侧栏边界目视原版约x456、候选约x546。统一ROI `[1168,1200,1280,1280)` 的列平均灰度<240测得，原版正文分隔线 `[1176,1178)`，所有候选状态均 `[1267,1269)`，候选右移 **91**。阈值160标题墨迹左缘距各自分隔线起点均50。恢复完整窗口只恢复相同画布；真正正文右边界和独立滚动偏移没有测量，不能据此宣称相同正文布局框。

## 可支持的结论和封存

本轮支持：在相同画布的有界普通正文语料中，候选04消除了body03的重复行累积纵向偏移，恢复原版空段推进，同时保持body03的长段换行；仍有阈值相关1像素墨迹顶界差和明显横向宽差。不同正文左分隔线、不同原版wrap、焦点和JPEG限制保留。
