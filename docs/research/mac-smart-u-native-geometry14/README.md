## 圆角、背景与表面样式

原版白色面板对克隆偏灰面板，样本RGB中位数为`255/255/255`对`247/247/247`；取消填充`236/236/236`对`231/231/231`，类型选择器填充`236/236/236`对`240/240/240`。好按钮左内侧干净样本为`243/187/76`对`234/191/63`。这些是**解码截图的局部RGB**，不是推定的系统设计色或CSS色；全部样本ROI已记录，未由颜色差推断内部实现。

克隆选择器和按钮有明显灰描边，原版主要呈浅灰/黄色平面；空token框也有明显边深差。共同标题深墨迹像素RGB中位数原版约40、克隆约33；不把差异归因为某个未经确认的字体或渲染开关。

圆角不拟合未经证实的半径。用局部y行内首个`minRGB>=240`像素的x值重算可见轮廓：原版在y8/16/24为x24/15/8；克隆含细边裁切中为x9/3/2。尽管两种边缘起点有约2px细边差，曲率差仍明显。见[原尺寸角部拼图](corners-native-tiles.png)及JSON完整profile。原版角外露出的底层文字不是表单自身内容，不参与文字对照。
