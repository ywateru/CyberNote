# 原版普通名称31：额外同态与Tab观察

| 文件前缀 | 实际动作与可见状态 |

| 01-name-click-select-all | 点击名称并Cmd+A后，默认名称全选、暖环与暖选区、黄色主按钮；指针光晕位于名称中部x约450，默认文字及checkbox标签区域干净。 |

| 05-escape-cancelled | Escape后普通新建表单从AX消失，回到既有合成对照笔记。没有提交新目录。 |

01/02供后续文字单变量诊断使用，不能据此确定原生font-weight/font-family；原版与旧截图相同字节时不重复计独立样本。所有图像保留原色彩配置、JPEG/抗锯齿局限，指针光晕不修补、不充作色值或字形依据。不同焦点状态不得混合作为选区颜色相同结论。

Tab序列与准确Mac12 runtime29中“Tab至checkbox”的记录存在差异。这是新增待查交互问题；后续应核对当前系统键盘导航设置、原生控件与WK焦点规则，再决定兼容方式，不为一次观察阻止用户在已开启键盘导航时访问控件。task31当前只改文字渲染，不改该交互。
