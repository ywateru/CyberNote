# 手机保存后的录音卡片：可见范围与校准入口

2026-11-04，有限只读研究。**用户原视频确实覆盖了完成后的正文 inline 录音卡片，但目前证据只确认其紧凑外观，没有确认该卡片的展开/收起、播放推进、进度条、波形或菜单交互。** candidate04 Android 的最终展开卡片是克隆自身运行事实，不能据它反推原版。

本轮不操作 GUI/ADB/麦克风，不构建、运行测试、安装依赖或修改产品/契约，不复制整视频、不提取音轨、不覆盖旧证据、不提交主线。开始可用空间5,268,082,688 B，始终要求≥2 GiB。

建议下一批仅校准**已保存紧凑卡片**的层级和可见文案：标题、真实日期时间行的来源决策、`音频`类型、短时长表达、右侧白色播放按钮及灰卡的相对布局。先区分可局部完成的文案/布局与必须新增真实元数据的日期接入；不要为补日期制造静态样例。

保存后展开、inline回放进度、波形、菜单及手势应另列原版补证目标：同一录音卡的播放前→播放中→暂停→结束，以及实际展开/返回/菜单序列。只有取得这些对应状态后，才有依据校准当前最终展开卡。当前transport验收可继续保留为工程能力通过，原版外观/交互一致性为unknown。

本报告没有形成像素pass、原版音轨有效或可听结论，没有更改已冻结Android验收结果。原视频已在项目保全；本目录只保存少量可追溯衍生帧、裁剪、索引与manifest。
