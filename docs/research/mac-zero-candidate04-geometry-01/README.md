## 原始材料与限制

- `original-fill.jpg` / `clone-fill.jpg` 与对应 `.ax.txt` 是主要同画布材料。原版 Fill 后搜索框从 disabled 变为 settable；两者均保留零态和禁用的正文编辑工具。
- `original-before.jpg` 为 2784 × 1806；`clone-before.jpg` 为 2176 × 1320，记录 Fill 前尺寸不同，不能混用作同几何对照。
- `clone-window-menu.ax.txt` 为 CUA 实际返回的 Window 菜单，包含启用的 Fill。原版菜单通过同一正式 API 观察到启用的“填充”并点击；原版菜单本身未另存 AX 文件，该动作记录在 actions.json，最终 AX 与 JPEG 已保存。
- `measurement-scan.json` 和 `measurement-supplement.json` 保留扫描结果；`measure.py` 给出相同阈值及扫描区域，可在现有 Pillow 环境下重算，不产生新图片。
- 正式 CUA 文档未提供 window bounds 接口；本次截图返回对象只有 state / screenshot，没有 origin 或区域几何。两张 Fill 画布尺寸相同已确认，绝对屏幕位置仍未确认。没有发明 API，没有通过其他技术控制窗口。
- 原版列表标题上有鼠标光晕。一次试图点击空白区移开鼠标的正式 CUA 调用返回 `windowNotFoundAtPosition((373.0, 229.0))`，本轮立即放弃该坐标路线，没有重试；因此不对被光晕覆盖的列表标题文字做精密包围框测量。它未修改正文。
- 未尝试 PNG observer、权限变更、Dock、附件/下载点击或构建。本轮所有 GUI 调用均有界，未遇到新的锁屏或 timeout。GUI 已释放。
- 原始 JPEG 是工具直接返回的有损格式；没有转换为 PNG 并称作无损。没有整图 diff、lossless、原生输入法或像素 PASS 声明。
