## 坐标与方法

统一左上原点，`[x0,y0,x1,y1)`，右/下边界不含；宽=`x1−x0`。`measurements.json`保存每项ROI、阈值和结果，便于复用，不需要重编码原图。

- 字形：ROI内 `max(R,G,B)<80/128/180`；正文表列128阈值，另报变化。测的是字形墨迹，不是字号、行高、基线或控件框。
- 灰底/细线：`min>=210`、`max<240/245/250`、`max−min<=4`；表列245。只在有界ROI取包围框，不声称通用组件识别。
- 黄色按钮/焦点环：`R>200`、`R−B>30/50/70`、`G−B>阈值/3`；表列50。可定位填充区域，不作精确原版色值。
- JPEG边缘及抗锯齿可使阈值范围变1–2px；阈值敏感项不报告虚假小数。A名称框受光标阴影污染，灰框测法舍弃，只列黄色焦点环；A2模式框的灰像素延至ROI边界，明确排除其高度。禁用减号圆形边界随阈值变化，不等于原生点击区域。

## 给U的使用边界

先复用A/B稳定的左右40px、控件48px高、类型224px、类型/模式间16px和按钮160×48px/间16px/右底40px，作为**同原图参考尺度**的可审阅布局；规则横向宽度随类型内容，不能将模式宽328/173/147合并成一个固定值。标题以墨迹锚点校准，本文不给字体大小或系统基线。

要把这些值落实为目标应用尺寸，下一步须取同一状态、相同捕获工具/范围、已知显示缩放的原版与准确克隆包配对。至少分别覆盖：空标签聚焦名称、任何标签隐藏输入、双规则未聚焦名称、验证警告；避免光标遮挡关键框线。原生无损图、字体/颜色、焦点和hover、圆角/阴影、窄窗/长token滚动仍待证。本轮没有克隆配对、叠图零差、原生point换算或手机测量结论。
