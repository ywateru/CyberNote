## 坐标和方法

全部数字是JPEG解码图像像素，左上原点，bbox为`[x0,y0,x1,y1)`，右/下排除。不反推CSS px、AppKit frame、屏幕原点、DPR、字体名或真实baseline。沿用旧geometry01中性暗墨迹：`299R+587G+114B < threshold × 1000`且`max(R,G,B)-min(R,G,B)<25`，阈值120/160/200均保存。空ROI返回null。

正文共同ROI为`[1200,160,2740,585)`，各自crop、墨迹框、50%overlay、原始absdiff及x4均在同坐标生成；不平移、不配准、不缩放、不重采样或用遮罩修补原图。两个画布相同，但分栏位置仍差2像素，不能强行对齐。日期、账号、笔记数、列表与原版拼写检查红线不同，排除整窗相似度。
