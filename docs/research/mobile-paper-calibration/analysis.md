# 手机纸张选择器：有限离线几何校准

2026-11-03；只比较相同的“横线与网格”浅色选择器、空白选中模式。原输入未改，未操作GUI/设备，未修改应用、顶部栏或扫描生产代码。本轮为一轮测量，不声明已实现或通过像素验收。

`measure.py` 可在仓库根运行，依赖现有Pillow。它保全输入SHA，记录原始坐标、阈值/连续像素聚类、所有线位置、宽度比例和390宽换算，并生成标注图。`measurements.json` 是完整原始数据；红框标卡片，绿框标图案墨迹范围。`annotated-comparison.png` 两图等比映射到448宽，原录屏仅nearest放大，不补造高清细节。两个component图也各自等比缩放，没有按高度拉伸或计算整体相似度。

标题应独立绝对居中，避免左“取消”和右空span宽度不相等导致偏移。取消左锚可由20px试到16–17px。当前文字宽已接近，不建议仅按墨迹高度缩字号；建议先保留标题16px/600、取消17px、说明12px。两张说明均只有一行，**实际font-family、line box、基线和行距无法由单行截图恢复**；草案标题24px、说明18px行高是工程选择，不是测量结论。

草案用相对sheet锚点：说明line box top约94px@390（期望实际墨迹top97.5），网格整体top约143px；随后129×104.5卡片、45.3行列gap、两侧43.5。其余宽度随100vw/224等比例。它是有限校准草案，没有接入现有滚动/安全区/键盘/选区恢复逻辑；开发接入时必须保留这些已修复行为，并用真实装包重新检查。原版DPR未知，后续仍需高清原图或同尺寸实机对照才可验收像素一致。
