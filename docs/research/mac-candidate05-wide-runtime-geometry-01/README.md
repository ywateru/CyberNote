# Mac candidate05 宽三栏局部图像几何对照 01

只比较主线真实Cua的`09-wide-body-focus`（克隆）与`11-original-wide-columns-matched`（原版）。AX确认相同三行QA正文且正文获得焦点。两源虽名为.cua-image，实际均为JPEG、2784×1806。先核字节SHA，结束再次核对不变；精确身份见result.json。只分析下面两个ROI，不计算全页相似度或授予pixel PASS。

**结论：顶部编辑区工具栏的主要可见图形位置已接近，尚不相同；正文文字的字形尺寸和行宽仍有明确差异。** 同坐标叠图不做平移、配准、缩放或重采样。所有数值都是解码图像像素，不反推AppKit frame、屏幕位置、DPR、字体名/字号或真正文字baseline。

## ROI与方法

- toolbar：全图`[1176,0,2784,112)`，输出1608×112。
- body：全图`[1200,155,1600,280)`，输出400×125，只有同三行正文。
- bbox均为`[x0,y0,x1,y1)`，右/下排除。暗色中性墨迹：`299R+587G+114B < 160000`且RGB通道差<25；在明确的子ROI内取全部符合像素的外接框。result.json另列阈值120/200敏感性，不以JPEG边缘当精确字体轮廓。阈值过低可能没有像素，按null记录。
- 可见白色圆角表面由原尺寸crop人工读边，约±2px；材质/阴影/色彩/JPEG会影响读边，它不是内部控件frame。

## 限制和证据

源图的侧栏账号、计数、列表内容和时间不同，窗口屏幕位置未获证明；均不纳入全页对比。两图指针光晕约在克隆(1980,900)、原版(1020,956)，在所选ROI外。克隆正文黄金色caret约(1448,250)位于body ROI内，原图该时刻未见同位置caret；AX均为body focus，因此可能存在光标闪烁/采集相位差。中性墨迹规则排除金色caret，原始叠图/差异仍保留它，不将caret差异单独算作产品几何失败。

工具栏符号深浅、白色材质/阴影及抗锯齿存在差异，可能受活动态或颜色影响。PNG只是源JPEG解码后的派生图，差异同时包含JPEG、材质、颜色与真实形状差异；没有无损原始像素证据。overlay为原坐标50%blend，absdiff为逐通道绝对差，x4只增强显示；未调整任何图像几何或颜色来制造吻合。

analyze.py保存实际方法，result.json保存全部ROI、敏感性、字形框、源SHA与来源不变检查；原尺寸crop、墨迹框标注、50%overlay、raw absdiff和x4各自保存。初版脚本在阈值120下遇空集合而exit1，原脚本和原因保存在analyze-attempt01.py/attempt-history.json；修正为空集合返回null后exit0。此前numpy不可用，仅改用已有Pillow，没有安装依赖。这些是分析脚本问题，不是产品执行结果。

本轮只读取指定两图及其AX，没有GUI、新截图、产品修改、代码测试、平台构建或target操作。manifest逐文件列字节/SHA，按Path组件对UTF8 `<sha256>  <relativePath>\n`聚合，排除自身。
