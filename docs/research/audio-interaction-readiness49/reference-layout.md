## 开发可直接采用的桌面布局选择

以下均为**工程起点**，不是截图测得的CSS或Apple内部参数；按应用实际截图比例校验即可，不展开新候选矩阵。

| 工程选择 | 建议 | 与观察的关系 |
| --- | --- | --- |
| 宿主位置 | 使用正文旁的独立右栏，参与应用横向布局；打开时正文收窄，页面结构保留 | 对应原图四栏并列。避免用手机底部sheet代替桌面栏。 |
| 栏宽 | 当前桌面尺度先取约280逻辑px；窄窗必要时以现有应用断点调整 | 只是将约560图像px按看似2倍比例换算的初始值，不宣称DPR=2，不设560 CSS px。 |
| 右栏网格 | 顶部标题组、可伸缩波形区域、下方计时/播放组、底部动作组；大计时与播放共享中轴 | 高度变化优先由波形及组间空白吸收；底部操作和播放行不要随计时文字位数移动。 |
| 标题组 | 左右约16逻辑px起步，标题约16px粗体、副行约13px灰色；⋯/×同一标题行 | 来自约32图像px边距的工程换算，字形/字号没有高清量测证明。 |
| 计时与播放 | 大计时约24px粗体、等宽数字；播放按钮中心约50%，两侧±15等距 | 保持视觉中轴；图标的墨迹偏移不应改变逻辑按钮中心。 |
| 底部动作 | 左/右动作约40逻辑px视觉直径，中间胶囊自适应剩余宽度；底部约16px起步 | 对应约80图像px外观。触达范围可大于图形，不能反称是原版实测热区。 |
| 正文卡 | 在正文流中插入附件块，当前尺寸起点约292×66逻辑px，内边距约12、圆角约12；最大宽度受正文可用宽限制 | 不固定为正文74%响应规则；74%只是一张图的结果。保留标题/日期/时长与右动作区，窄时优先省略日期文本，避免控制挤压。 |
| 波形 | 根据真实采集数据绘制红色振幅线，金色播放/录制位置线；空白/低振幅依据真实数据 | 不把截图红线复制成固定波形，不让计时器冒充录音文件时长。 |

进行中卡、侧栏必须引用同一个录音会话与附件身份；计时、暂停/继续、结束保存通过同一状态源更新。点击正文卡重新打开侧栏、×仅关闭视图还是结束会话、红方块是否结束及勾的提交时机，都属于**工程行为选择/根合同**，截图没有证明；开发需按明确合同接线，不能为保留图形放无功能按钮。截图并不证明正文持久保存成功或重启恢复。

这张截图仅支持所见暂停/预览外观。桌面初始/采集中/结束后的按钮样式没有在本次图片里出现；可复用手机已证状态的语义，但桌面具体变形与动画仍标为工程选择，不写成已观测原版。

## 手机：已证基本交互与实现边界

已有视频确认以下稳定外观顺序，未捕获可识别触点，因此输入动作是工程实现选择：

| 状态/阶段 | 录屏事实 | 可采用的工程行为 |
| --- | --- | --- |
| 初始 | 稳定`00:00.00`、底部红圆、灰完成与灰播放/±15 | 进入先显示初始，用户点红圆后请求/启动真实录音；不能进入即假装已持续录制。 |
| 采集中 | 大计时递增、红暂停双竖条胶囊、完成/播放/±15灰 | 真实采集开始后推进显示；点暂停调用真实采集器暂停。 |
| 暂停 | 计时冻结`00:02.60`、红“继续”胶囊、金完成、黑播放/±15 | 提供继续与直接完成；继续后的真实序列未在有限录屏中出现，实现需自行保证接续。 |
| 暂停完成 | 仍为“继续+完成”时面板直接向下关闭，随后正文显示录音卡 | 不额外要求先进入另一个stop页面；内部须结束编码并等数据收尾与正文保存确认。 |
| 完成卡 | 灰圆角“新录音”、日期、`音频·2秒`，右侧白胶囊`▶ 播放` | 有真实文件后可播放；视频没证明卡片单/双击、展开、seek或±15实际效果，不冒称已证。 |

手机面板沿用既有规格的固定区位：顶部把手/标题/实例日期时长，中部波形及金色中轴，下部大计时、播放/±15，最底部中央红圆或暂停/继续胶囊与右“完成”。三态共享中轴，不因状态切换上下跳；使用真实宿主安全区，不自行画状态栏或Home指示条。完整坐标与误差边界以recording-mobile.md为准。
