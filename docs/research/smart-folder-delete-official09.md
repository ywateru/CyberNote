# 智能定义删除的官方边界09

2026-11-04只读检索。Apple Notes 4.13 / macOS 27 官方指南“使用智能文件夹”明确：智能文件夹不能设为子文件夹；删除智能定义保留其引用的笔记，笔记继续位于原有物理文件夹。该文字支持本工程“定义不是所有权、只删定义”的数据契约，不需要执行任何用户数据删除。

```text
https://support.apple.com/zh-cn/guide/notes/apd58edc7964/4.13/mac/27
```

目标是本机macOS26.4。相同指南的mac/26地址本次读取HTTP429，没有取得其正文，因此27页只能作相邻系统版官方次级依据，不作为目标原版实际验收。用户已明确选择暂不进行删除实验，仍遵守；本轮没有新建/删除任何原版测试数据。

这不解决“物理文件夹被删除时智能规则的引用如何变化”、最后token/最后规则、include/exclude与子树问题。C4该部分仍待证，D2首批tags/pinned不依赖目录引用生命周期，后续文件夹规则继续保留在完整范围。
