## 发现与后续门槛

P1：共享folderDraft持久PinnedRule.value没有映射到草稿pinned；默认true盖住false，重开后原样保存/只改名可能改查询。已建[hydration16修复](../../plan/tasks/app-smart-draft-hydration16.md)，新准确包必须复验false重开、只改名、成员及冷启。当前APK不得作为完整智能界面通过包。

空标签错误不可见及长按目录系统选字为另两项待修。日期等完整原版筛选功能仍未实现，移动端只禁用明确未支持项；没有伪保存日期。未测本批智能中新建默认目录、完整搜索/取消、移动目的地排除智能、marked中文组字、失败ACK/跨窗、归档回放或全部模式。UI几何延续只限[新05有限ROI](../../research/mobile-folders-baseline14-new05/README.md)，非录屏整页像素通过。
