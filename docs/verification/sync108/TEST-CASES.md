# 数据同步测试用例

日期：2026-11-12。当前表为待执行清单；实际结果另附报告，不将设计用例计为通过。

## 环境与断言规则

桌面A/B为两个原生App进程，使用两个全新绝对数据目录。A监听，B加入；Android C采用独立应用ID与沙箱，通过ADB指定serial访问并加入A。测试合成文本包括中文、ASCII、换行和emoji，附件使用固定合成PNG与普通文件。每次等待均有deadline；超时保留当时状态和数据差异。

内容断言比较完整document及plainText，元数据逐字段核对，附件比较完整长度和SHA256，并检查正文attachment ID确实对应接收端文件。不能只以连接、标题、总数或pending=0断言内容正确。业务写入走实际UI处理器或明确标注的生产Session API；只读SQLite可作为独立落盘证明。

## 启动与隔离

| ID | 步骤 | 预期 |
| --- | --- | --- |
| ROOT-01 | 未传 `--data-dir` 解析启动配置 | 使用平台默认路径；单测验证，避免启动用户原库 |
| ROOT-02 | A/B传不同绝对目录启动 | 两个PID同时存活，实际数据库及媒体目录分别落盘 |
| ROOT-03 | 空、相对、重复、缺值、未知参数 | 明确错误退出，不打开默认数据库 |
| ROOT-04 | 同目录与其规范化别名启动第二实例 | 第二实例被拒绝，原实例仍可保存；退出后原目录可重开 |
| ROOT-05 | 数据目录含空格/中文、路径为普通文件或不可用 | 合法路径正常；非法目录明确错误，无静默回退 |
| ROOT-06 | 对A创建数据后只读B的落盘与缓存位置 | 配对前B不含A记录；缓存和身份不共用 |
