# 数据同步测试用例

日期：2026-11-12。下表定义用例，文末逐项记录实际执行边界。结果分别见 [桌面报告](DESKTOP-RESULT.md)、[三端报告](three/README.md)、[启动独审](../../plan/reviews/app-sync108-startup-independent.md)与[浏览器定向复验](browser/README.md)。只按实际断言记账。

## 环境与断言规则

桌面A/B为两个原生App进程，使用两个全新绝对数据目录。A监听，B加入；Android C采用独立应用ID与沙箱，通过ADB指定serial访问并加入A。测试合成文本包括中文、ASCII、换行和emoji，附件使用固定合成PNG与普通文件。每次等待均有deadline；超时保留当时状态和数据差异。

内容断言比较完整document及plainText，元数据逐字段核对，附件比较完整长度和SHA256，并检查正文attachment ID确实对应接收端文件。不能只以连接、标题、总数或pending=0断言内容正确。业务写入走实际UI处理器或明确标注的生产Session API；只读SQLite可作为独立落盘证明。
