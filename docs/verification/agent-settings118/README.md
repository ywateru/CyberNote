# Agent 接入界面重整

日期：2026-11-17。用户反馈实际设置截图中缺少“启动 MCP 测试程序”，且授权、配置、诊断信息混在同一层。设计见[Agent设置](../../ui/agent-settings.md)，使用见[Agent接入指南](../../agent-usage.md)。

## 原因与实现

旧测试入口位于 `availableGrant` 条件内的配置区域，只有点击授权卡“查看接入配置”后才会出现；未选授权时整块配置区域消失。Agent页面又继承了外层设置页的滚动/内边距，同时内部使用100%高度的独立滚动，造成嵌套滚动与顶部裁切。

- 页头固定显示“启动 MCP 测试程序”；未开启或尚未配置时也能打开准备弹窗，不自动开启接入、创建授权或启动二进制。
- 正文只有一个滚动容器，按“允许本机接入 → 授权客户端 → 配置与连接”排列。授权摘要使用名称、状态、中文权限、目录和有效期；机器标识、完整授权详情、配置代码与近期操作默认折叠。
- 配置区始终可发现，默认选择第一项有效授权；明确选择失效授权后不自动替换。刷新保留有效选择，所有配置仍由原 DTO 和 `agentLaunchConfig` 生成。
- 准备弹窗共用同一套接入条件，可补齐授权和绝对路径。条件齐备后进入原有控制台；点击“连接”才执行真实 stdio 握手。单项、只读/显式读写批量、停止/回收与写入恢复逻辑未修改。
- 活动控制台使用启动时的授权和路径快照；关闭接入、撤销/到期、资料库或宿主会话变化后关闭测试器，沿用其原有卸载清理流程。点击启动时再次检查真实时钟，避免30秒状态刷新间隔内使用已过期授权。

## 手工验收

1. 进入“设置 → Agent 接入”，无需点击授权卡，应立即在页头看到测试入口；上下滚动正文时标题和入口保持可见。
2. 无路径、关闭接入或无有效授权时点击入口，应打开准备弹窗并说明缺少条件；填写路径/选择授权不自动执行文件，返回设置应定位到相应步骤。
3. 条件齐备时启动控制台，连接后逐工具及批量测试；停止/关闭应保持原有回收与恢复信息行为。
4. 检查窄窗口、大字号、明暗/八主题、键盘焦点与长授权名称。关闭主设置或退出应用后再打开，确认实际运行的构建身份。

以上UI步骤由用户完成，未计为通过；原生打包与启动结果在完成后另记准确来源。
