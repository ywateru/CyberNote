## 输入实验与限制

两边直接执行 `typeText('输入回归：中文 abc 123')`、Return、`typeText('END-VERTICAL04')`。克隆17实际出现 ` abc 123END-VERTICAL04`，中文未进入正文，第一次Return也未分段。随后Escape与Return能产生空行。粘贴已提交的 `输入回归：中文 abc 123\nEND-VERTICAL04-COMMITTED` 成功，18保存全部失败ASCII行、空段及新提交中文，21冷启可见相同文字。

原版19相同直接输入也缺少中文，实际为 ` Abc 123` 后换行 `END-VERTICAL04`。这证明当前工具的直接键入不能作为中文输入法验收；Return表现不同的原因仍未知。没有更换输入法或系统设置，不把粘贴成功称为真实组字、IME或换行交互完全通过。克隆对首空段笔记的列表标题为“新备忘录”，原版从后面的非空段导出标题，另有差异未修。
