## 最小源码候选

只读上下文为 `plugins/tauri-plugin-notes-ui/macos/toolbar.m`，具体读取身份在 JSON。当前 `makeGroup` 将 sidebar 与其他组一样放进 glass / legacy effect；`layout` 的 sidebar 从 traffic x 开始并用 36×action 数量；`placeGroup` 按传入总宽均分 action。候选应限于 sidebar：

1. 可见时给每项 44pt 的槽宽，组 x 取 `max(traffic, side - 44 * count)`，使用普通容器承载图标。AX 208 / 228、两按钮时，名义 x 是 120 / 140。原版图像移动量支持靠右规则，但非对称 SF 图标的墨迹中心不能反推出精确按钮 frame，候选仍需真实运行采集。
2. 隐藏时保留现有 36pt 恢复按钮的玻璃和位置，添加文件夹不显示；恢复操作保持直接可达。可见但过窄时仅允许添加文件夹溢出，按候选可见槽宽重新判断容纳关系，切换按钮仍保留。
3. 不通过全局 `makeGroup` 改变其他工具栏组，不同时调整标题、搜索、编辑器、图标大小或列表 CSS。先验证 208、228、隐藏、恢复与窄态溢出行为，再决定是否接受候选。

## 保存和复核

输入共 16 份：14 份原始 AX / JPEG、root README、冻结 corpus；输出前后大小和 SHA 均保持不变。源码只是读取时上下文，其身份另列，未作为不可变封存输入。所有 ROI 框及数量用另一种 crop 枚举方式复算并一致；这是测量作者自查，不冒称第二作者审计。写输出前检查空闲空间超过 2 GiB。
