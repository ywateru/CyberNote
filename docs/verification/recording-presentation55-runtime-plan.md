2. 建QA-RECORDING-55-A，在该处开始短录音；默认浮窗显示，实际采集后切到当前主窗右侧展开。计时/波形仍实际活动，同一会话不重启。
3. 展开下继续编辑A、撤销/重做；新建并编辑QA-RECORDING-55-B；使用搜索定位B、清空搜索、选择文字加粗。原生工具栏和正文可点击，不被覆盖或遮罩。
4. 录制中展开→浮→展开。暂停后试听，检查实际播放位置、±15/seek（若无真实有限范围则如实未通过）；试听中切换，停止试听并继续录制，时间连续。没有听写入口。
5. 停在B时完成录音，B焦点/正文保留，A只有一张保存卡且采集中最新文字保留。正常退出再开，A/B及音频保持，实际播放位置推进。
6. 记录新包有限尺寸截图，与references/desktop/recording-20261105/user-recording-sidebar.png对照。JPEG仅用于有限视觉观察，不作全界面无损像素相同结论。
