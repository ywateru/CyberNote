1. A开始真实录音，记首次开始时间；一边录音一边编辑A、切B编辑和搜索，再回A。检查未抢焦点、录音未因导航/失焦停止。
2. 暂停，等明确保存结果；录音窗保持且可继续。A应该只有一张本会话卡，B无录音。切换A/B或重开笔记，保存卡仍在；录音控制不因单次checkpoint被销毁。
3. 继续录第二段，再暂停；只更新A原卡，活动时间不包含暂停间隔。浮窗与右栏切换期间仍沿同一会话。

5. 新短会话覆盖面板×或Escape；受控检查覆盖系统/owner/quit多入口和故障，实包只在实际可操作范围内记账。正常退出/重开后，最后已确认卡与A/B文字保持。
