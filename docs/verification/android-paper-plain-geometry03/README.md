## 可交给作者的窄修边界

精确source347的手机规则在白卡上设置`border-radius:5px; border:0`，选中层独立设置`outline:1.5px solid var(--accent); outline-offset:0.5px`。通用selected的border-color在手机border0下不产生该金框。新实机同plain金框与这个独立outline选中层对应，构成明确可隔离的修改位置。

建议仅手机modal-paper的selected卡片改用带明确圆角的绘制层，例如绝对伪元素border，保留当前白卡5px圆角、卡片槽、预览、七卡顺序、按钮命中区域、阴影、颜色与现有外扩范围。现有outline外缘名义外扩为0.5+1.5=2CSS px，可把它作为保持几何的实现约束；它不是由截图测得DPR换算的原版参数。作者仍需核对已有伪元素占用、pointer-events与未选态/桌面范围，并用准确新包复验四角和plain→grid-large保存重开。

这是**截图形状+精确源码的来源判断**。本轮没有从Android WebView读取computed style、DOM或paint tree，没有判定具体引擎内部缺陷；源码属性和其他Chromium预览的computed结果均不等于当前实机像素。不能用一个radius值来自证原版完全一致，也不扩张成全局按钮outline或无障碍焦点修复。说明文字宽差暂独立保留，不夹带在选框窄修中。

`analysis.json`保存完整测量、输入hash、源码片段与限制，`result.json`保存设备步骤和有限视觉保全，`manifest.json`封存本新目录。主机及设备输出前均检查至少2GiB。没有暂存或提交；旧证据未改写。
