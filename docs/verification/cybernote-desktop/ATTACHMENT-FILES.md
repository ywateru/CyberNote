# 附件文件、剪贴板与预览

2026-11-07。按用户提供的附件菜单和预览截图更新桌面附件流程。

后续交互已更新：单击选中、共用系统菜单、可拖动非模态预览和列表缩略图，详见[最新验证记录](UNIFIED-MENUS.md)。本文保留上一轮文件存储和剪贴板验证。

## 存储与显示

原生应用的附件原本就由 Rust 写入独立受管文件，SQLite 仅记录元数据，正文保存附件 ID、名称和类型。本轮沿用该存储和持久提交日志，粘贴图片同样先保存原始字节、再插入正文引用并确认保存，不把 base64 或 Blob URL 写入文档。受管文件名由系统生成，以保持恢复、同步和撤销所需的稳定身份。

图片、音频和视频显示对应组件，其他类型显示文件卡。媒体读取通过授权检查，运行时使用有明确生命周期的 Blob URL；视频和音频在源释放时停止播放。不能由当前 WebView 解码的图片显示可打开原文件的文件卡。

SVG 问题有两个原因：通用或空 MIME 未识别 SVG；只有 viewBox 的 SVG 在自适应按钮内可能得到零宽高。现在读取和导入均识别 SVG，并为矢量图片建立明确的可用宽度。新增或补齐 PNG、JPEG、GIF、WebP、BMP、TIFF、ICO、AVIF、HEIC、HEIF 的内容签名识别；文件扩展名本身不决定类型，也不覆盖明确的自定义 MIME。

## 剪贴板和菜单

- 直接粘贴截图或剪贴板图片时，从真实 FileList 或图片数据保存附件。只有 base64 图片的 HTML 粘贴也转为独立附件。普通文字仍走原有编辑器粘贴行为。
- 附件菜单新增剪切、拷贝、粘贴；Mac 另有共享、打开附件、在文件夹中显示。图片提供快速查看，音视频保留播放操作；原有保存附件、显示信息、从备忘录中移除继续可用。
- Mac 拷贝向系统剪贴板写入真实文件 URL，图片同时提供原始图像类型数据。截图没有文件 URL 时也能读取其图片字节。文件型剪贴板最多 20 个文件、总计 100 MB。
- 跨笔记粘贴会生成归属新笔记的新附件身份；不会把旧附件 ID 直接粘到另一笔记。粘贴位置、文档版本和原笔记在异步读取前捕获，变化后拒绝迟到的插入。
- 剪切先确认系统复制成功，随后只移除正文引用；失败或目标变化时保留原引用。底层文件保留，支持撤销。复制和系统文件操作均检查当前笔记授权及原文件完整性，录音专用窗口不能调用。
- 对外打开、共享和 Finder 显示使用保持原名及原始字节的文件副本，位于系统临时目录的 `CyberNote Attachments/<独立目录>/<原文件名>`。系统剪贴板可继续引用该文件；外部应用编辑副本不会改写受管原件，也不会自动回写笔记。

## 预览

预览改为黑色背景、浅灰圆角窗口。顶部依次提供关闭、放大/还原、文件名，以及信息、共享、导出、通过默认应用打开。图片按比例适应窗口，SVG 可按可用空间缩放。Escape 关闭，Tab 焦点保留在预览内，关闭后恢复原附件焦点；源失效仍沿用原有立即关闭机制。

## 验证

- `pnpm test:attachment-mime`：26 个类型签名/通用 MIME 组合及 3 个类型边界断言通过。
- `pnpm test:attachment-clipboard-native`：生产 Objective-C 文件服务与真实 AppKit **独立命名剪贴板**验证 SVG、二进制文件、无文件 URL 的 PNG 图片剪贴板及普通文字。文件名、磁盘字节和剪贴板读回一致；没有读写系统剪贴板。
- `pnpm test:attachment-files`：真实 App/Editor/持久提交前端流程，在隔离浏览器工作区完成 9 组检查：通用 MIME SVG 解码、预览、系统操作接线、直接粘贴图片、跨笔记粘贴、剪切失败保护与撤销、HTML 图片粘贴、真实 WAV/MP4 播放、迟到粘贴和剪切隔离。系统接口由边界模拟；不是 Finder 或系统共享的原生执行证明。无页面异常。
- Rust：217 项通过、4 项保留忽略。新增检查覆盖真实 Store 中 SVG 的独立文件写入、重新打开后的原字节、四种文件操作载荷，以及旧授权拒绝。
- `pnpm test:editor`：96 个 schema 用例及真实表格/历史回归通过；`pnpm test:native-toolbar`：22 项通过。
- TypeScript/Vite 和 macOS release 构建通过。日志及截图在 `artifacts/attachment-files/`。浏览器预览截图使用合成 SVG，不含用户笔记。
- 最终 release 应用在现有合成 QA 附件上完成只读核对：菜单、快速查看、放大/还原、Escape 与焦点恢复正常；“在文件夹中显示”实际打开 Finder 并选中原名 PNG；“通过默认应用打开”实际打开系统预览中的同名文件。外部验证窗口已关闭，原文件夹视图已恢复，没有修改用户笔记内容。结果在 `desktop-menu.png`、`desktop-preview.png`、`finder-result.txt`、`system-open-result.txt`。
- 本机应用和 ZIP 解压后的 `codesign --verify --deep --strict` 均通过，主程序与 Info.plist 摘要一致；源码、前端资源和压缩包摘要记录在交付目录 `manifest.json` 与 `SHA256SUMS`。

本轮交付目录为 `artifacts/attachment-files/release/`，应用为 `CyberNote.app`，压缩包为 `CyberNote-macOS.zip`。采用项目现有 entitlements 的本机 ad-hoc 签名，未经 Developer ID 公证；本轮未重新构建 Android APK。
