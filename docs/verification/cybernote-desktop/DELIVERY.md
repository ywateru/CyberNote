## 最终界面

- 以用户提供的设计图为依据，重构三栏边界、浅灰侧栏和连续顶部栏；默认侧栏 272px、列表 390px、顶部栏 68px。保留用户已有栏宽，窄窗口压缩为 220px / 280px。
- 新建笔记移至列表顶部，顶部工具依次提供格式、清单、表格、附件、录音、标签、共享、更多、搜索、设置。原生 macOS 栏保留 AppKit 控件和原有事件/选区校验；空间不足的操作进入“其他工具”。
- 调整列表日期分组、置顶折叠、选中态、文件夹展开收起、标签和附件信息。编辑区使用标签胶囊、方形待办框及全宽录音卡。
- 产品更名为 CyberNote。新图标保留附件 SVG 的轮廓与配色，两组同心圆眼睛改为同心正方形；更新 SVG、网页图标和桌面打包图标。

## 字号设置

设置 → 设置提供“界面字体大小”与“编辑器字体大小”，两者独立、即时更新并自动保存。标题按编辑器字号同比例缩放，字号设置不改写文档内容。macOS 原生顶部栏跟随界面字号。

| 档位 | 界面基准 | 正文基准 |
| --- | --- | --- |
| 极小 | 12px | 12px |
| 小 | 13px | 14px |
| 中（默认） | 14px | 16px |
| 大 | 16px | 18px |
| 极大 | 18px | 20px |

- `test:native-toolbar`：20 项通过，包含新增工具及五档字号的状态投影断言。

- 实际 AudioPlayer 与 NoteEditor NodeView 的浏览器回归通过；覆盖新增波形进度跳转及既有触控、键盘、播放、展开收起和编辑内容隔离。
- 通过原生 macOS UI 确认 CyberNote 窗口、两个字号选项及五档菜单可见。
- 本机 `.app` 以项目现有 entitlements 做 ad-hoc 签名，并通过 `codesign --verify --deep --strict`。不是 Developer ID 公证发行包。
