# APP-001-FIX-00 开发者验证

日期：2026-11-03。范围为归档事务与恢复可靠性，基线 `4133ff6`；本记录是开发者自测，等待独立 verify，不能代替 APP-001 整体验收。现有 Mac/Android 安装包仍为首轮基线，本轮先提交存储修复，独立复核通过后再更新平台产物。

## 变化与契约

- 归档完整校验完成前不写生产文件，检查版本、实体唯一 ID、系统文件夹、父引用/环、笔记和附件归属、文档附件引用、类型、受管路径、声明大小与 Base64。
- 同 ID 导入采用副本策略，重写层级、附件与文档引用及选中项；既有笔记修改和附件字节保留。系统目录复用。归档设置在同一数据库事务完整恢复，保留未知设置；失效选中目录回 default，失效选中笔记清空。
- 附件使用独占新路径。先暂存并持久化恢复日志，再发布文件，最后单 SQLite 事务提交元数据和设置。失败或重启时仅按日志清理数据库未引用的本次文件；提交后的附件保留。恢复日志损坏会明确阻断并保留未知文件。
- 限制归档 256 MiB、单附件 100 MiB、附件解码总量 128 MiB、实体 10,000、JSON 值 500,000、深度 120、字段名 4,096 bytes。JSON 流式预检先于对象树分配。
- 导出以同目录临时文件替换目标，失败保留原目标；禁止导出覆盖存储数据库、WAL/SHM 或受管附件/暂存目录。原归档始终只读。
