| 继续后完成 | 同一会话时间累计，完成后仅A新增一个持久录音卡，A最新文字和B文字保留；当前B焦点不被切回A |

| 录音中关闭主窗口 | 主窗口隐藏，录音独立窗继续；恢复原主窗继续工作，完成保存到原A |

| 正常重新打开 | 查看原A/B最新文字和一个录音卡保留，可再次播放；不读取用户数据库或导出新麦克风文件 |
