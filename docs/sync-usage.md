# 设备同步使用说明

2026-11-06。新同步版本正在集成和原生验收；已交付的Mac26/Android16不包含此功能。准确新包及实际验证路线以最终交付记录为准。下面按当前产品入口说明操作，不能作为未完成验收的通过证据。

## 先连接同一局域网

1. 在Mac打开设置按钮，切到“数据”，滚动到“设备同步”。填写本机名称，服务端口可保留界面默认的49632，点击“开启此设备同步服务”。
2. 在“服务地址”填写手机能访问的Mac局域网地址，例如 `ws://192.168.1.20:49632`。这里的IP只是示例，替换成自己的Mac地址；`127.0.0.1`只指当前设备，不能用于另一台手机。
3. 点击“生成配对串”并复制。配对串十分钟内有效，关闭或切换设置页会清理当前显示的配对串，需要时可以重新生成。
4. 在Android打开设置→数据→设备同步，填写手机名称，点击“加入同步”，粘贴完整配对串，点击“连接并加入”。已有本地笔记保留并参与同步。
5. 两端均可正常新建、编辑和添加附件。界面显示连接状态、最近传输时间、待安全应用数量和冲突数量，也可以点击“立即同步”。

桌面应用运行期间同步；手机重新进入前台会恢复连接。手机被系统结束进程后需再次打开应用，不承诺常驻后台网络服务。临时断网时继续本地编辑，恢复可达后再同步。

## 录音、编辑与冲突

收到远端数据与把数据应用到当前笔记是两个阶段。“已接收，等待安全应用”表示数据已经收到，正在等待本地编辑安全点；录音、输入法组字或附件保存进行中时会保护所属笔记，无关笔记可以继续同步。正常结束后再应用，不要求用户为了同步关闭当前录音。

离线期间两端修改同一笔记时，保留并发版本，不只按设备时间覆盖。进入同步区的“冲突”查看各版本，可明确选择保留指定版本或将各版本全部另存。删除、恢复和永久删除也有版本记录。笔记锁定及密码授权保持本机处理，同步不分享当前解锁状态。

## 其他网络地址

使用已经建立的WireGuard或EasyTier虚拟内网时，把生成配对串所用的服务地址改为Mac在该网络中的IP与监听端口。应用复用系统已提供的网络，不在设置中创建VPN或修改路由。是否已实测该路线在交付记录中单独列明。

使用匿名隧道时，将本机监听端口映射为可达的 `wss://` 地址，再用该地址生成新配对串。隧道进程和地址由外部工具提供；地址改变后需要按新地址重新配对/重连的实际支持流程操作。应用的设备认证与内容加密仍通过自己的配对协议完成。正式可用流程、实际隧道传输及停止清理证据由87路线验收补齐，不把输入wss地址直接算作测试通过。

“停止同步”会保留本地数据和已配对配置，“继续同步”重新连接。设备列表的“撤销”用于取消该设备的后续访问；已复制到另一设备的本地数据仍属于那台设备上的数据，不能远程擦除。
