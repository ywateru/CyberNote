## Findings

### QA-01 — P1 / blocking：导入失败会覆盖已有附件

契约：`docs/architecture.md`导入导出、`docs/plan/analysis/delivery-map.md` I12原子性、F08/F15/F19。位置：`src-tauri/src/store.rs:630`—先逐个`fs::write`现有附件路径，直到全部写完才开启数据库事务。

复现：在真实临时Store新建笔记及内容为`original-content`的附件，导出后修改备份：第一个附件同id/路径但内容改为`overwritten-during-failed-import`；第二个附件为无效base64。导入返回`invalid/附件内容无效`，随后通过真实`read_attachment`读取原id，实际内容已被覆盖。数据库回滚不能恢复文件。证据：`docs/verification/qa-001/store-probes/result.json`中`originalPreserved:false`。探针直接编译基准store.rs，未接触用户数据。坏输入已固化在`fixtures/bad-second-attachment.notesbackup`。

要求：先验证完整归档及关系、解码所有附件，准备受管暂存内容，再以可回滚方式提交数据库与附件；任何失败须保留既有工作区及附件字节。

### QA-02 — P2 / blocking：归档导入丢失设置

契约：F19完整工作区归档，architecture Settings/Import。位置：`src-tauri/src/store.rs:622`；导出包含`settings`（607起），导入只写folders/notes/attachments，从未写settings。

复现：源Store设置`view:gallery/theme:dark/selectedFolder:quick`，导出并导入全新Store；workspace实际`settings:{}`。证据：同一`store-probes/result.json`的settings expected/actual。要求：明确覆盖/合并策略并按契约恢复有效设置，选择引用须验证。

### QA-03 — P2 / blocking：导入绕过文件夹树约束

契约：F01层级、architecture禁止循环。位置：`src-tauri/src/store.rs:627`及642；直接反序列化/插入，未校验parent树、循环、引用或受保护默认文件夹。

复现：在有效备份folders增加`id:self-cycle,parentId:self-cycle,kind:normal`后导入，返回成功。证据：`cycleImportAccepted:true`，输入`fixtures/self-cycle.notesbackup`。普通moveFolder的循环检查不覆盖导入入口。要求：写入前对完整最终图做同等约束检查；拒绝时原状态不变。本轮未触发依赖该损坏图的后续循环操作，以免挂住进程。

### QA-04 — P2 / blocking：扫描入口尚未实现约定能力

契约：F16、手机80秒录屏。位置：`src/App.tsx:1111`、2236。文稿扫描只是调用相机file input并提示自动裁边/扫描归档未实现；文本扫描仅提示未接入识别。源码明确缺口，不能以拍照插图当扫描流程通过。需要真实离线OCR/裁边/多页等对应行为和平台错误处理后复验；本轮不将相机权限/硬件路径标pass。

### QA-05 — P2 / blocking：Mac菜单与图标布局明显未达原版

契约：F04/F11/F13、`docs/ui/macos.md`。位置：`src/App.tsx:923`及更多/媒体菜单，`src/style.css`。

实际Mac克隆格式面板把样式列放最上方，标记/颜色放下方；原版首行标记与单个颜色入口，下方样式；标题层级文字也不同（克隆“大标题/小标题”，原版“小标题/副标题”）。缺少原版已取证的短划线/块引用入口。媒体次序、更多菜单与原版不同。克隆更多中出现Mac原版同位未出现的横线网格；原版最近备忘录/数学结果未实现。实际截图：`qa-001/mac/format.png`、`media.png`、`more.png`，原版参考在`references/desktop/`。

公共工具栏区域的逐像素比较在`qa-001/pixels-toolbar/`：两张原图同为2176×1320，无重采样、无遮罩，裁剪矩形`[1140,10,1680,100]`，540×90。raw exact mismatch ratio **0.5268930041**；RGB平均绝对差均为**16.14874485597/255**；最大差均223。该区域含图标几何、位置和材质差异；原版表格按钮此帧带省略号，作为状态差异单独披露。不能把这项数值当整个应用相似度，也不能将剩余白色相同背景算UI验收。清单双勾图标与原版清单圆点/横线的结构差异肉眼明确。

纯文本粘贴的首段样式也与采样不同，但本轮没有核实原版新笔记开头设置/直接输入路径；仅记录paste路径差异，不据此要求全局取消h1默认。

### QA-06 — P2 / blocking：Mac画廊双击路径不符

契约：最新`docs/ui/macos.md`与`interaction-matrix.md`，原版`macos26-gallery-open-note.png`。位置：`src/App.tsx:1725`（所有桌面笔记卡片双击`openSeparate`）及472（创建WebviewWindow）。原版实际行为是同一主窗隐藏画廊进入编辑器，侧栏保留，返回按钮回画廊。本轮对已提交处理器作静态确认；未额外打开独立窗口以扩展测试。修复后应实际走画廊双击/返回并独立验证多窗另入口。

### QA-08 — P2 / blocking：F17/F18/F19仍有明确功能覆盖缺口

契约：requirements F17标签/智能文件夹、F18数学/笔记链接、F19文本/Markdown导入与标准格式导出。已提交源码有`#`子串搜索过滤（App.tsx662），没有标签模型/标签浏览与智能文件夹规则；更多菜单没有数学结果模式；归档UI仅`.notesbackup`。这些是尚未完成范围，不能在首轮“构建与持久化通过”中省略。相应模块应拆任务实现并取证，本轮未把未出现入口伪装为通过。
