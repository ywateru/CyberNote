# 八套外观、紧凑清单与 MCP 测试程序

状态：源码实现、独立复审及合并后组合命令检查完成，详见[交付记录](../verification/feedback117/README.md)。承接用户 2026-11-17 的截图反馈；UI 由用户验收，本轮以命令、功能及单元测试验证。旧发布包不包含本任务，本轮未重新生成 Mac/APK 安装包。

## 外观与清单契约

保留 classic / paper / high-contrast 的持久 ID，增加 ocean / forest / rose / lavender / graphite，共八套，每套支持浅色和深色。正文、侧栏、列表、工具栏、选中态及弹层使用各套语义色；配色差异覆盖整个工作区。纸感统一暖纸表面，高对比以文字/表面对比为主，普通分隔线仍为 1px，不以粗框制造对比。保留可辨认的键盘焦点。

桌面原生标题/工具栏也要检查：若已有桥仅支持明暗，需同步扩展实际背景色投影，不能仅改 WebView 后声称顶部一致。备份/导入的原生外观验证同步接受八套 ID，拒绝未知 ID。

```text
外观与字号 > 外观（桌面）
[经典] [纸感] [高对比] [海洋]
[森林] [玫瑰] [薰衣草] [石墨]
明暗：[系统] [浅色] [深色]
```

手机在可用宽度内展示全部选项；桌面正常设置宽度每行四个，窄宽/大字允许合理降列。外观切换不重建 EditorSession / SaveQueue / 录音 owner。

待办采用圆形可见框；框与第一行文字垂直对齐，框和正文紧邻，多行项对齐第一行，嵌套层级保持。去除任务项内普通段落造成的多余 margin/min-height，不改变普通正文段落。手机保留可用触控区域但不靠额外段间距扩大行高：可向左扩展至44px宽，高度限制在首行行盒内，不覆盖相邻行或正文选字；不把工具栏44px正方形下限套用于正文内清单。勾选/撤销/持久文档结构保持。

## Agent 测试器契约

从桌面 Agent 接入页面点击“启动 MCP 测试程序”，弹出独立的测试对话框；不必额外建立一个参与笔记编辑协调的原生文档窗口。使用本页填写的适配器绝对路径及选中的现有有效授权。通过原生受控子进程启动真实适配器，完成 MCP initialize / initialized / tools/list / tools/call；不得用直接 Store / application-service 调用代替 MCP。

```text
Agent 接入 > [启动 MCP 测试程序]
┌ MCP 测试程序 ─────────────────────┐
│适配器路径 / 有效授权 / [连接]      │
│[单项测试] [自动测试] [停止/断开]   │
│工具选择 / JSON 参数 / [调用]       │
│逐项结果：通过 / 失败 / 跳过        │
│响应与耗时 / 操作回执 / 错误        │
└─────────────────────────[关闭]───┘
```

手动模式从真实 tools/list 取得工具及输入 schema，允许逐个调用全部九工具并查看 JSON 结果。批量模式默认只读，可显式选择读写测试；创建/追加/替换仅对本轮新建的明确标识测试笔记执行。权限不足显示跳过及原因，错误不冒充成功。读写批量使用 UUID 幂等键、读后 CAS 版本和操作回执；不自动重试写入。无删除工具，不隐藏测试笔记留存事实。

批量写入发送前记录恢复所需的工具、原始参数及幂等键；收到业务错误时保留 `operationId`、`committed` 和 warning 等实际恢复信息。停止/超时的迟到结果不采纳，但不能因此清空已记录的写入意图。连续停止/重连的异步收尾必须按连接代次判断，旧操作不得清除新连接的 busy/working 状态。

后端只接受当前窗口/访问 Token、有授权的当前资料库/宿主；从宿主设置解析授权，不接收任意凭据或任意命令参数。启动不经过 shell。输入/响应/日志有界、调用有超时、连接有容量限制；停止、关闭、超时、撤权、库切换/宿主关闭、窗口销毁均不能留下失控进程或过期结果。错误净化，不展示原始凭据/环境变量/任意 stderr。焦点约束和关闭恢复沿用现有设置对话框语义。移动端明确说明桌面可用。
