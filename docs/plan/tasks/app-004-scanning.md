## objective

完成 F16 的真实离线能力，用实际相机/本地图片输入替换当前扫描占位提示。Android 的扫描文稿界面以录屏80秒原帧为基准；录屏未展示的成品编辑过程须明确为本项目实现，不声称已与原版逐步比对。Mac 按本机原版实际可用条件显示入口，不把禁用的连续互通入口替换成另一个同名假流程。

1. 先接入 bundled 中文 OCR：所选受控本地图像在设备上识别，展示结果并允许确认插入最初的目标笔记/选区。区分取消、识别无文字、识别失败、目标冲突；空结果不能伪装成功。实现后再接真实相机图像与方向处理。
2. Android 自有扫描页包含真实预览、拍摄、取消、闪光/滤镜/自动模式中已实现的动作和提示，外观向录屏对齐。文稿检测、手动四角裁切和透视校正须真正改变输出；自动检测失败可明确转手动，不能产生虚构边界。可多页拍摄、复核、改序/删页/重拍，完成后本地生成 PDF 与预览，保留可再裁切所需的原图/参数。
3. 所有扫描中间文件留在应用私有会话目录，原生层返回受控 token/元数据；不允许前端提供任意绝对路径。点击完成后才提交正式附件与文档节点；切笔记、目标删除/锁定、取消、保存失败与进程中断均有明确恢复/清理结果。
4. Android 模型随应用分发，首次启动前断网仍可识别；不采用首次动态下载模型/逻辑/UI的现成扫描器。正式锁定依赖版本、ABI和实际包体积，不能把研究建议版本当作已集成。
5. Mac 对实际导入的本地图片走 Vision accurate 路线，查询目标系统语言/revision 能力；本项目最低macOS12与本机26.4须按可用性分支处理。相机/扫描仪/连续互通仍以实际硬件和公开系统能力为准，不伪造启用状态。

## verification

由开发提交源代码和相同源码构建的新.app/.apk，独立verify执行以下真实调用链：

| 路径 | 必须保存的证据 |
|---|---|
| 全新Android安装、首次启动前断网→本地中文图→识别→确认插入 | 网络关闭状态、无旧模型缓存的隔离条件、原图/识别文本、耗时、真实Rust文档、重启保持；不能仅说明依赖是bundled |
| 相机拍摄两页→自动/手动裁边→透视校正→改序/删页/重拍→完成 | 原图/四角/结果图与PDF页序、实际UI过程、附件元数据；手动调整后输出确实变化 |
| 完成后移除原临时来源→冷启动→预览/重新裁切 | 正式受管字节、原图参数与页序仍可用；无临时URI依赖 |
| 取消/拒绝权限/识别空结果/保存失败/中断 | 不插假节点、不覆盖旧文档、不泄漏可读附件、会话恢复或安全清理；错误在界面可见 |
| 等待识别时切笔记/删除目标/锁定目标 | 结果不能错插当前另一篇；明确目标冲突，旧内容保持 |
| Mac离线受控简繁图像→真实Vision→确认插入 | 系统/revision/语言列表、原图与结果、重启文档；语言不支持有明确错误 |

扫描取证用合成文稿和已知文字，不拍摄用户私人材料。模拟器无法证明真实镜头/闪光和真机拍摄质量；这些项按实际设备保留unknown，不能用静态图片注入冒充相机通过。录屏只提供扫描相机原帧，后续未知原版状态不填像素pass。PDF可搜索文字层/语音转写不由本任务自动宣称完成。
