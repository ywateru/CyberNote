## Entry gate

本任务仅准备交付要求，尚未授权正式构建。U作者SOURCE-READY STOP、root固定产品commit、不同作者源码审查pass后，root另行明确40位源SHA、输入/平台冻结及独占输出目录，才可构建。禁止拿活动HEAD、旧安装包或浏览器预览代替该准确源。复用已审查的candidate06离线构建/收集工具及已成功Android环境，不新增下载、升级、缓存复制/清理或proof flags。

D1/D2/O/U和此前已合入录音、标签、工具栏/侧栏变更都必须在同一准确产品输入中。两平台的完整依赖/生成输入分别冻结，不能因应用源码相同就声称完整构建身份相同。每次新尝试独占新目录，失败不覆盖；至少2GiB空间、jobs2、每次600秒有界，仅停自有进程组；主机target不可与验证/另一构建并用。

## Package checks

沿现工具保留Mac原始完整app和ZIP，再由该原件形成独立本地adhoc签名完整app和ZIP；验签差异只限已批准主可执行/签名资源。记录非DeveloperID/未公证。Android记录精确APK、ABI/离线OCR模型/签名和与现安装兼容性。核前后输入不变及收集结果、字节、SHA；未通过不安装。工具或环境错误先记录，不顺手改生产依赖。

## Native acceptance ownership

root用Computer Use操作Mac，沿用户明确授权的ADB操作Android；不用截图helper，也不请求TCC授权。启动前核对现有安装/运行身份和已有合成测试状态；Mac正常退出旧克隆、Android保数据升级。不得卸载、清库、重置权限、降级新DB2到旧程序或导出用户数据库/音频。原版删除实验仍暂停；不因本任务测试定义删除而操作原版数据。
