# ACCOUNT109 手机起源文件用例补齐

2026-11-13。现有三端执行器 `c-ui-note` 仅验证手机完整正文；ANDROID-03 明确还要求手机起源附件到双桌面的原字节。手机 coordinator 网络未恢复，本轮只准备并独立验证设备外执行器，不启动设备或宣称实际通过。

复用隔离包、原四篇全文/附件保全、既有生产附件提交与读取链。新增固定的 Android driver 方法，只向本轮新建且授权的合成笔记提交少量已知合成文件；优先使用现有 `attachment.submit` 测试命令，真实 Session/import/save 不得被 fixture DB 写入替代。不新增产品 IPC、任意 JS/URL/token 参数或文件系统全路径入口，不改 APK/账号/网络/转发配置；若候选没有所需调试能力，应明确失败，不降级为伪造结果。

三端场景除已有完整正文外，还须核对手机本地授权读取、附件归属与文档引用、期望长度/SHA，以及 A/B 原始受管文件字节。记录真实边界：手机正文仍由既有 UI 路径创建，合成文件由固定功能命令提交，不能声称经过系统 picker。原手机数据的最初基线与每个保全门槛均保留。

设备外测试验证固定 payload/owner/新建身份约束、完整正文未丢、文件损坏/引用缺失拒绝、未执行后续场景和清理失败仍为失败。作者与独立审阅者分离；仅修改执行器、必要测试和本用例说明。实际设备运行待正式可达 coordinator 和真实授权之后，以全新输出目录执行。
