## objective

从空目录实现可以实际运行的 Tauri 2 + Rust + pnpm Mac/Android Apple Notes 克隆。遵循全部已记录需求，先核心闭环再补功能。生产数据使用 Rust/SQLite，不得伪装保存/录音/附件/锁定。搭建可构建的完整项目、原生配置、包命令、测试，实际构建 Mac .app 与 APK，并运行。复杂或来不及达成的功能诚实标注，保持继续开发所需结构，不交付隐藏假按钮。视觉匹配本机 macOS 26 浮动侧栏与胶囊工具栏、录屏 iPhone 风格移动布局。
