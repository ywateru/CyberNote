## verification

1. 真实 Rust 边界：初始化幂等、层级循环拒绝、中文检索、更新版本防覆盖、删除/恢复与计数、附件路径校验、归档完整性、锁定后数据库/附件/归档无未说明的明文泄露、密码错误保留数据。
2. 真实 Mac .app：新建→中文/输入法→任务/表格→快速切换→返回→退出重启，确认内容、勾选、表格仍在；快捷键与菜单互通；在原版基准1088×660pt截图，至少主三栏/格式菜单/媒体菜单/更多菜单对比。
3. 真实 Android APK：安装 emulator-5580；冷启动→文件夹→新建→输入→Back隐藏键盘→返回列表→杀进程重启；核对清单、表格、附件、录音保存播放、绘画保存重新打开。若权限/模拟器硬件不支持，记录未测而非通过。
4. 逐页记录截图尺寸/缩放/字体/主题/内容/动态遮罩。输出可解释的差分，不可用低质量原视频插值去宣称高清字形一致。使用系统区域与应用区域分别报告。
5. 遍历所有可见菜单/工具条，无效按钮、静默错误、假保存、调用未接入均是 blocking。检查执行中的 source/debug 路径是否混用到 release。
6. 输出 P1/P2/P3 与 blocking/non-blocking、文档与代码位置、实际复现、证据路径，最终 pass/blocked。用户要求逐像素一致，尚未测量或明显不一致则 parity blocked，即使功能测试通过。
