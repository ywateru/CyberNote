# APP94 标签回车提交与正文 Tab

状态：in-progress。基线 APP93/Mac31，用户反馈 `#标签` 仅空格可提交、Enter 不提交；正文 Tab 跳焦点而未插入制表符。

## 契约

- 在可编辑正文的折叠选区，合法普通 `#标签` 后按无修饰 Enter，提交与空格相同的 noteTag，并继续原有回车行为（段落、列表、表格按编辑器既有规则）。不把换行替换为空格，不吞回车，不把标签 mark 带到下一段。
- IME 组字期间 Enter 不提前提交或破坏候选确认；非法名称、嵌入单词、代码/链接、非折叠选区和不可提交/不可编辑文档沿用既有边界。Undo/Redo 与保存快照保持合法。
- 正文普通 Tab 在现有表格单元格导航/列表缩进处理之外，插入字面 `\t`（选中文字时替换选区），焦点留在正文，走正常事务/保存/撤销。表格及列表既有 Tab/Shift+Tab 保留，Shift+Tab、Control/Meta/Alt Tab 和正文外焦点导航不扩张拦截。只读与 IME 不写入。
- 不改原生全局键盘策略，不改变文件夹表单、搜索、菜单的 Tab 导航。不添加生产 debug 入口。

## 执行和验证

沿用 docs-sprint：原作者实现，另一代理独立审查。用现有真实 Editor/App DOM 和合成隔离数据，先保留可复现的旧失败，再定向验证中英文标签/空格/回车/组字保护/代码链接/选区/Undo/Redo、普通段落/标题/选区 Tab、表格导航和列表缩进、正文外焦点、不可编辑。不重复无关网络/设备大矩阵。

不读取真实 Notes/用户DB/麦克风，不操作任何 Android 设备或旧 AVD，原录音现场保留。复用现有缓存。通过后准确构建新 Mac32（新 artifacts/editor94，保留 Mac31），不同代理核对动态产品输入、完整嵌入前端/原生脚本/Info/实际签名。作者和独审证据与限制分别收档。
