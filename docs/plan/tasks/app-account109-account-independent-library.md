## 行为契约

1. 本地笔记、文件夹和附件属于此设备上的资料库。未登录、退出、登录另一账户均不删除或改写这些内容；本地资料库不因旧账户或手工同步 workspace 拒绝登录。
2. 登录先验证固定 issuer 的身份及 coordinator profile 的 subject/issuer/product/workspace，保存当前会话身份。旧本地同步 workspace 与新 profile 不同不构成认证失败。首次登录或换账户保持同步暂停；同一已启用会话正常重启可恢复其原状态。
3. 退出关闭当前账户网络、映射和邀请并清理登录授权，保留本机内容。完成退出后可登录任意其他账户。refresh、设备凭证和对端握手仍必须匹配当前已验证身份，不能接受跨账户远程连接。
4. 用户显式“开启并合并”后，才允许将本资料库当前内容与当前登录账户合并，包括以前同步后留在本机的内容。确认页应明确说明此效果。不能在登录或状态轮询中静默上传。
5. 采用新的同步 workspace 前，先停止并封闭旧账户及手工同步连接，清除其活动会话。旧 peer、邀请、grant、inbox、vector/frontier 等协议状态不得作为新账户状态继续发送或应用。同步空间迁移必须可回滚，本地笔记与附件须保全；新的同步基线由保留的本地内容重新建立，同会话重启不重复重建。
6. 未解决的冲突及未投影的数据不得为迁移而丢弃。若实现不能安全保全，可明确阻止“开启同步”并提供处理入口，仍允许保持登录和本地编辑。不要以 Busy、资料库归属错误或要求删除数据库来掩盖这一状态。
7. 无活动授权事务的未登录终态错误允许显式重试登录，尤其当前 `account_owner_workspace_mismatch`；真实 lifecycle/attempt 并发仍返回 Busy，grant 清理未完成仍必须提供明确的退出/清理路径。轮询只读，不自动重登。
8. `account_owner_workspace_mismatch` 若保留，只表示服务身份或同步凭证不一致，不再表示数据库属于另一用户名。错误文案和重试动作必须与原生状态机一致。
