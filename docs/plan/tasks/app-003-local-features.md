## objective

完成 F17/F18/F19 的本地功能真实接入，并维持 FIX-00 归档可靠性。由 root 在共享工作区安排 `develop_app` 串行实施，不与 FIX-02、APP-004 或其他 App/Editor/存储变更同时开发。APP-002 提供真实媒体预览；扫描来源类别依赖 APP-004，未完成时不得宣称扫描浏览已通过。

按以下可独立提交/验证的次序推进；root 可拆分为更小任务，不能把未完成的后续项算整批完成：

1. **契约与兼容。** 依据研究文档确定标签表示、smart 查询联合类型、数学节点/模式、noteLink 稳定引用、媒体投影和标准格式边界；先更新架构/UI 契约。解决锁定密文内 noteLink 的归档碰撞映射，再接界面。新文档 schema、Rust 校验、文本投影和迁移原子交付，旧文档和既有 `.notesbackup` 可读。
2. **标签与智能文件夹。** 走通正文 `#UI对照`+空格 → 真实标签 → 侧栏/筛选 → 持久化。智能文件夹可创建、编辑、保存规则并重新求值，全部/任意实际生效；是查询视图，不搬动/复制笔记。已证据覆盖的文字、顺序、加减状态按原版实现。规则边界、空选择、物理新建目录、最近删除和锁定过滤明确约定。共享/@提及不伪造数据。
3. **数学与链接。** 三数学模式真实保存，至少完成 `2+3=` 建议→Return无换行接受→编辑来源→重启；insert 模式具体触发补证后落定。安全有限语法与错误明确。`>>` 检索/键盘接受 → 稳定 ID 链接 → 同主窗目标 → 原版证实的返回路径；普通超链接拥有真实打开/编辑行为。源保存失败不跳走，目标缺失/锁定有明确反馈。
4. **标准格式与附件浏览。** 文本/Markdown 预检、导入至验证后文档和受管附件；真实 Markdown/PDF 导出；完整归档继续独立保留。定义映射/格式损失，不把备份改后缀。按已实现的真实媒体类型浏览 → 所属笔记 → 定位/预览，复用 APP-002，智能附件规则使用同一类型投影。
5. **补证与差异记录。** 优先补原版智能文件夹保存后结果、混合清单/日期/目录语义、数学插入模式、笔记链接返回/生命周期、Markdown 导出样本及附件布局。未取证部分可先完成独立工程能力，但需登记工程选择和 unknown，不能把菜单选项/样例数据当运行或像素通过。

| 真路径 | 必须核对的结果 |
|---|---|
| 中文组合输入/粘贴→标签提交→侧栏点击→撤销/重做→退出冷启动 | 正文/标签目录/筛选一致；普通井号不误认；删除最后引用/删除恢复按明确契约；不能静态样例 |
| 两篇异同标签笔记→创建全部/任意智能文件夹→编辑规则→重启→改原笔记 | 结果随真实数据改变；原 `folderId` 不变；取消无写入；无效规则拒绝且旧规则保持 |
| 日期边界、混合清单、目录移动、置顶/锁定、附件新增删除→智能结果 | 明确判定表和当地时区边界；原版未比对的语义单列 unknown，不凭菜单名判一致 |
| 数学模式切换→`2+3=`→接受/撤销→改来源→冷启动 | suggest 未接受不伪装持久结果；Return不换行；off无新建议；insert真实行为；无效/超限不返回假结果；表达式与结果可恢复 |
