## observation sequence

1. **入场身份。** 解锁后重新读取原版当前窗口、版本、菜单与选中目录。退出其他未完成的合成表单前先确认其真实状态；不能取消正在进行的用户编辑。记录 CUA 原始状态与已知限制。
2. **合成数据。** 创建两个普通测试目录 A、B，以及 A 的子目录 A1；分别创建标识唯一的合成笔记。只将 A 中的一篇置顶，另保留一篇未置顶。记录真实实体归属、标题和置顶状态。若本机 UI 不支持某步，保留实际错误，不换成推断。
3. **取消和保存。** 从原版新建入口打开智能文件夹，确认默认规则/名称/加减按钮与取消状态。先取消，确认无新条目；再设置仅置顶的规则保存，记录真实侧栏图标、名称、计数、结果、选中目标与正文。不能仅凭表单关闭判断保存成功。
4. **公开元数据求值。** 在真实源笔记上置顶/取消置顶，观察结果和计数是否更新。最后匹配消失时记录空列表、编辑区、原目标能否继续编辑及是否自动跳转；一次普通编辑即可，不在此轮推断原生中文组字规则。
5. **目录规则。** 使用实际目录选择器创建 include A 的视图，明确观察 A1 是否入选、是否可多选、能否选择其他智能视图。再记录 exclude A 的真实结果。不要把子目录的出现仅归因于名称；每篇样本用唯一标题标识。
6. **组合与搜索。** 使用 pinned 与 folder 两条规则依次观察全部/任意；保留相同样本，用结果辨别 AND/OR。通过真实搜索入口输入唯一匹配 B 的文案，记录搜索是否限定当前智能视图、是否切全局、清除后恢复哪个上下文。不因一条路径推断所有快捷键作用域。
7. **新建与移动。** 在当前智能视图执行真实新建，记录新笔记实际所属物理目录、是否被赋予条件、当前筛选与正文如何变化；不要为匹配而手动补条件。观察移动目标列表是否含智能视图，并取消移动，保留原归属。
8. **定义与引用生命周期。** 通过原版编辑入口修改视图名称和规则，先取消再确认旧定义，随后保存一次合法变更。物理目录删除对规则的影响留给独立后续场景；本轮不删除普通目录或清空最近删除。删除智能视图的行为也仅先记录菜单/确认内容，不据菜单证明成员保全。
9. **冷启。** 在确认合成编辑保存后正常 CmdQ，再启动原版，核对保存的视图、规则、结果及源笔记仍存在。若退出路径遇到用户未保存内容，则停止该步骤并记录，不能强杀原版。
