# APP93 导入记录内部化与附件右键菜单

状态：in-progress。基线f0c1c29e，上一轮Mac30/Android21保留。用户要求导入不添加“Apple备忘录原始记录.json”附件，全部用户附件有右键菜单；第二截图无菜单可参照，采用现有应用风格。

## 改动

1. 新导入返回用户的正文不再添加原始记录卡，普通附件列表不显示内部来源记录。旧已导入记录兼容处理，只按专用类型和有效来源记录/归属识别，不按名称误处理用户JSON。保留内部导入去重及必要原始数据；利用已有受管文件及owner生命周期、备份/恢复/同步，不另造与目标失联的成功ledger。保持旧同步协议：内部持久化/备份/wire保留已验证raw引用，public Store投影剥离，正常保存内部合回，严格wire references集合规则不变。旧记录投影不改原时间/revision。
2. 图片、已保存录音、视频和普通文件共用右键菜单，按实际能力提供预览/播放、保存原文件、信息及可Undo的正文移除；见[UI契约](../../ui/attachment-context-menu.md)。
3. 调整导入结果说明及使用文档，不再告诉用户正文末尾有JSON附件。内部数据占用仍准确计量。
