# CyberNote 设置重构：功能与界面方案

2026-11-07。用户后续要求不再调用图片生成模型，直接基于现有样式和功能修改设置页，现已转入实际实现。以下为此前功能梳理与设计记录；实际行为以[设置页规格](../../ui/preferences.md)为准，生成图只作历史参考。

## 顶部栏消失的原因

`src/App.tsx` 将 `modal === "preferences"` 映射成 `contentOverlay=true`。`plugins/tauri-plugin-notes-ui/macos/toolbar.m` 的布局逻辑在此状态主动隐藏 groups、buttons、title、count，然后提前返回。旧规格 `docs/ui/preferences.md` 曾要求“native toolbar 退让”，这是旧约定的遗留，并非图标资源加载失败。

新版要求优先。需要拆开“禁止操作底层备注”与“隐藏工具栏”：设置打开时保留工具栏的位置、按钮及标题，用标准禁用态表达不可操作，遮罩从工具栏下沿开始。不能通过移除 modal / 权限检查让底层编辑动作穿透；关闭设置后恢复原按钮状态和入口焦点。

## 功能盘点与新归属

根据 `Preferences.tsx`、`DataManagement.tsx`、`SyncSettings.tsx`、`AppleNotesImport.tsx` 实际实现核对。

| 已有功能 | 能力与约束 | 新归属 |
| --- | --- | --- |
| 外观 | 跟随系统、浅色、深色；即时保存 | 外观与字号 → 外观 |
| 界面字号 | 极小、小、中、大、极大；影响文字、图标、间距 | 外观与字号 → 界面字号，独立示例 |
| 编辑器字号 | 同样五档，与界面字号分开 | 外观与字号 → 编辑器字号，正文示例 |
| 排序 | 编辑日期、创建日期、标题 | 备忘录 → 列表 |
| 列表 / 画廊、日期分组 | 桌面偏好，移动首页固定画廊 | 备忘录 → 桌面列表 |
| 关闭所有锁定备注 | 关闭已解锁的锁定备注；没有修改密码功能 | 备忘录 → 锁定备忘录 |
| 同步状态 | 未开启、等待、连接中、同步中、已连接、停止、异常；最近成功时间、待应用数 | 设备同步 → 状态 |
| 创建同步 | 本机名称、端口；显式操作才启动 | 设备同步 → 在此设备创建同步 |
| 加入 / 更新连接 | 完整配对串、本机名称；保留本机身份与数据 | 设备同步 → 加入已有同步 / 更新连接 |
| 生成和复制配对串 | 服务地址、十分钟有效期；离开清可见值 | 设备同步 → 添加设备 |
| 同步操作 | 立即同步、停止 / 继续、刷新、异常重试 | 设备同步 → 状态附近 |
| 已配对设备 | 名称、连接状态、最近成功时间、撤销确认 | 设备同步 → 已配对设备 |
| 冲突处理 | 版本详情、保留某版 / 全部另存、显式确认 | 设备同步 → 需要处理 → 冲突详情 |
| 存储总览 | 实际文件大小合计、分类比例、未知大小、采样异常 | 存储空间 → 总览 |
| 分类文件 | 图片、录音、视频、其他附件、数据库、辅助日志、其他文件与目录 | 存储空间 → 分类详情 |
| 文件详情 | 搜索、分页、名称、大小、时间、状态、原文件导出 | 存储空间 → 文件列表 |
| 数据位置与诊断 | 真实路径、采样时间、数量、缺失附件、警告 | 存储空间 → 位置与详情，按需展开 |
| 完整备份 | 导出 / 合并导入；含设置及登记附件，冲突另存副本 | 导入与备份 → 本地备份 |
| Apple 备忘录导入 | 仅 Mac 主窗口；读取、选择、复制、取消、结果，保留原件 | 导入与备份 → 从 Apple 备忘录导入 |
| 操作反馈 | 加载、在途、错误、取消、成功；录音中禁用备份和相关导入 | 各动作原位显示，真实结果驱动 |

不凭空增加账号、iCloud、自动备份、自动清理、修改密码、通知或云空间套餐。存储空间表示应用文件占用，不虚构设备总容量百分比。

## 信息结构

两端共享功能与数据模型，使用不同导航外壳。

```text
设置
├─ 外观与字号       外观 / 界面字号 / 编辑器字号
├─ 备忘录           排序 / 桌面列表 / 锁定备忘录
├─ 设备同步         状态 / 创建或加入 / 设备 / 冲突
├─ 存储空间         总览 / 分类文件 / 位置与详情
└─ 导入与备份       本地备份 / Apple 备忘录导入（Mac）
```

取消包罗多种任务的“数据”标签。五个分类直接可达，不另造空的“高级”“关于”页面。

## 桌面方案

主窗口工具栏始终保留。在其下方居中显示设置面板，底层备注暂不可编辑，原工具栏保持位置并使用禁用态。更改即时生效，不另设保存按钮。

```text
┌ 主窗口原工具栏，原位置、完整保留 ─────────────────────┐
│   ┌ 设置 ──────────────────────────────── 关闭 ┐   │
│   │ 外观与字号 │ 外观与字号                     │   │
│   │ 备忘录     │ 外观 [系统] [浅色] [深色]       │   │
│   │ 设备同步   │                                │   │
│   │ 存储空间   │ 界面字号 [极小 小 中 大 极大]    │   │
│   │ 导入与备份 │ 小型界面预览                    │   │
│   │            │ 编辑器字号 [极小 小 中 大 极大]  │   │
│   │            │ 正文预览                        │   │
│   └────────────┴────────────────────────────────┘   │
└────────────────────────────────────────────────────┘
```

- 中档目标尺寸 920 × 660 逻辑像素，分类区 196px，内容区左右 32px；受可用空间约束，内容滚动，分类与关闭入口稳定。
- 不仿制交通灯，不重复主窗口工具栏，不再增加一排图标标签。左侧分类用普通列表行，当前项为浅琥珀底。
- 标题和标签左对齐，行尾控件；说明置于名称下。外观为三种紧凑预览，两个字号各有五档选择和用途明确的示例。
- Escape 关闭并恢复入口焦点。切分类保留文件筛选、分页、滚动与在途任务；离开同步分类清理可见配对值。选择菜单继续复用共用菜单组件。

## 移动方案

全屏设置首页列出五个分类及摘要，点击进入子页。首页“完成”回备注；子页固定“返回 + 标题”。Android 返回先关闭选择面板，再退一级，最后退出设置。

```text
设置首页                  外观与字号               设备同步
┌ 设置             完成 ┐ ┌ ‹ 设置    外观与字号 ┐ ┌ ‹ 设置     设备同步 ┐
│ 外观与字号     系统  › │ │ 外观     跟随系统  › │ │ 未开启               │
│ 备忘录       编辑日期 › │ │ 界面字号           小│ │ 在设备间同步备忘录   │
│                       │ │ [极小 小 中 大 极大] │ │ 加入已有同步        ›│
│ 设备同步       未开启 › │ │ 界面预览             │ │ 在此设备创建同步    ›│
│ 存储空间     示例占用 › │ │ 编辑器字号         中│ │                      │
│ 导入与备份            › │ │ [极小 小 中 大 极大] │ │                      │
│                       │ │ 正文预览             │ │                      │
└───────────────────────┘ └──────────────────────┘ └──────────────────────┘
```

- 按“阅读与记录 / 数据与设备”两组排列，不把桌面面板缩窄。行高至少 52px、触达区至少 44 × 44px；小字号也不缩触达区。
- 普通选项用行尾当前值和子页 / 底部选择面板；五档字号直接可选，最大字号允许换行。安全区、软键盘、横屏独立适配。
- 移动“备忘录”先显示排序和锁定；“桌面列表选项”按需展开，明确不会改变手机首页。
- 同步初始只有“加入已有同步”“在此设备创建同步”。创建流程才显示端口；配对流程才显示配对串。已开启显示真实状态、最近成功时间、常用动作、设备及冲突，不将连接中或待应用显示为完成。
- 不支持 Mac 导入的平台隐藏该入口；保留完整备份。文件列表转为两行，名称、大小、时间分层，行尾菜单提供导出，不让长文件名挤掉按钮。

## 视觉基准

延续白纸、浅灰、琥珀色的 CyberNote，不加装饰性渐变、巨型标题或仪表盘卡片。

| Token | 浅色 | 深色 |
| --- | --- | --- |
| 内容 | #FFFFFF | #1C1C1E |
| 背景 | #F5F5F7 | #111113 |
| 导航 | #F0F0F3 | #242427 |
| 主文字 | #1D1D1F | #F5F5F7 |
| 次文字 / 线 | #6E6E73 / #E5E5EA | #A1A1A6 / #38383C |
| 强调 / 选中底 | #C78600 / #FFF0C7 | #FFBC36 / #3D3017 |

系统中文 PingFang SC、系统西文字体。桌面中档正文约 14px、标题 20px；移动默认阅读密度约 16px、标题 24px。五档依平台角色校准，不把桌面全局几何等比压到手机上；持久化仍保留 tiny / small / medium / large / huge。编辑器现有 12 / 14 / 16 / 18 / 20px 为实施校准基线。图标、字体、触达区分别建模，避免小字号裁切图标或大字号顶出控件。

## 两轮推敲

第一轮考虑沿用顶部标签再增加更多标签。拒绝：同步与存储仍需长滚动，移动端横排容易溢出。也考虑桌面一张长表单。拒绝：备份与连接表单持续挤占常用选项，状态更新容易造成跳动。

第二轮收敛五分类；不为单个关闭锁定备注动作新造安全页。少用技术字段进入明确流程，常用状态常驻；文件查看与备份分开。字号区减少重复说明，保留两个用途不同的示例。

线框复核：五入口可见、两个字号不混淆、同步未开启无地址表单、工具栏完整保留、没有虚构能力。生成后仍需检验中文、菜单样式、密度和移动触达；每轮针对一个问题迭代，避免同时改动全部风格。

## 实施验收

1. 设置开关前后工具栏几何一致，按钮保留且底层编辑动作禁用；关闭恢复，不删权限校验。
2. 五分类覆盖上表功能；settings / data 旧入口和调试命令有兼容映射。
3. 即时保存失败给出真实结果，打开设置不改正文或新增撤销历史。
4. 切分类保留文件状态及任务，配对敏感值按规则清理，隐藏页不抢焦点或消费按键。
5. 双主题、五字号、桌面 800 / 1280 宽、移动 320 / 390 宽、短屏和键盘无横向溢出，关闭与返回可达。
6. 录音中备份限制、导入权限、锁定授权、同步冲突确认、过期请求拒绝继续有效。
