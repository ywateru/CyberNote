# CyberNote 插件中心与工作区扩展：UI 评审稿

状态：M0/M1-lite 与声明式 ZIP/GitHub 安装已实现；第三方可执行页面、同步/模型/Agent 适配器和硬件交互仍为提案。日期：2026-11-26。能力、信任边界和阶段见[插件架构](../architecture/plugin-platform.md)。本稿沿用[设置页](preferences.md)、[双端呈现](adaptive-presentation.md)和[主题架构](../architecture/theme-presentation.md)，不新增独立的编辑、保存、导航或授权控制器。

当前落地范围：设置新增「插件」分类；桌面为主从列表/详情，手机为列表→详情子页并支持返回列表；支持名称/能力搜索、全部/已启用/需要处理筛选、启用开关、损坏状态错误横幅、宿主生成的布尔/选择设置、权限与贡献摘要、只读设备能力。首个内置插件「附件详情」默认启用，关闭后附件菜单「显示信息」立即消失；`showByteCount` 与 `showRecordedAt` 直接作用于现有信息面板。声明式外部包支持本地 ZIP、GitHub 仓库/子目录、预览确认、安装后关闭、升级、卸载、来源展示和加载失败记录清理；示例区块由宿主按 `ui.sections` 渲染。第三方可执行页面、签名/商店、同步/模型/Agent 适配器、实体设备、安全模式重启仍未实现。

## 1. 入口与布局

在「设置」新增固定分类「插件」。桌面沿用设置侧栏与同一个详情区，手机用设置首页 → 插件 → 详情子页；不在手机正文页头新增全局插件按钮。当前原生应用在列表顶部显示「从文件安装…」和「从 GitHub 安装…」，浏览器合成预览不显示这两个入口。插件本身不能隐藏安装入口或安全模式。签名包、商店和更新检查尚未上线，不显示不可执行占位按钮。

```text
Desktop: existing Preferences shell
+------------------+--------------------------------------------+
| Settings         | Plugins                     [Search]      |
| Appearance       | [All / Enabled / Needs attention]         |
| Accounts & Sync  |--------------------------------------------|
| Agent            | Attachment details    Built-in  [On]     |
| Plugins   >      | Extra palettes        Built-in  [Off]    |
| About            |--------------------------------------------|

+------------------+--------------------------------------------+

```

示意图中的英文仅用于标注布局。实际界面使用本地化文案。启用状态与详情分别用开关和可访问的详情入口，详情行点击不隐式启用；手机可把状态、开关和长文案分行。使用现有设置分隔列表、语义 token 和焦点环，不给每个插件套一层大卡片。固定筛选用分段控件（长文本或最大字号下改为单列选择器）；版本或 provider 用选择器；危险操作放在详情底部。列表匹配名称、发布者和能力类别，不搜索笔记内容。过滤后保持当前操控焦点，错误筛选按名称稳定排序；无匹配提供「清除筛选」。从业务设置进入插件详情，返回保留来源、滚动和焦点，不重置业务草稿。

详情按「基本信息 → 能力与位置 → 插件界面 → 权限 → 设置 → 设备接入 → 维护」排列。显示来源（内置、本地 ZIP 或 GitHub）、安装时间、版本、平台可用性、作用位置和激活原因；权限分开显示「已授权」「未授权」「本端不可用」，敏感目标显示用户可辨识的名称而非完整令牌或路径。宿主按严格 schema 生成设置表单，复用 `PreferenceSegments`/`PreferenceSelect` 和现有表单校验；`ui.sections` 只显示宿主渲染的纯文本区块，`visibilityConfig` 控制其显隐。普通偏好按已确认设置的回执更新；影响数据外发或后台任务的变更先保存草稿、预览范围、再确认。外部插件底部提供卸载，文案明确只移除插件文件、安装记录和本插件设置，不删除笔记、附件、备份或远端数据。

## 2. 工作区挂载点

```text
WorkspaceShell (stable, owned by CyberNote)
+-----------+-------------+------------------------+------------------+
| Folders   | Collection  | Editor / host toolbar  | Inspector        |
|           | row menu    | [More -> commands]     | only when opened |
|           |             | editor and IME stay    | local boundary   |
+-----------+-------------+------------------------+------------------+
              Plugin views use host-owned routes outside the editor tree.
              Mobile: More -> Tools -> separate sheet or subpage.
```

| 插槽／入口 | 桌面 | 手机与回退 | 约束 |
| --- | --- | --- | --- |
| `workspace.more`、`note.menu`（M0 基座） | 现有「更多」或笔记菜单，在宿主命令之后加一组插件动作 | 现有溢出菜单或长按菜单；入口仅在当前上下文适用时出现 | 仅传动作 ID 与受限能力上下文；执行时重查目标。不能复用/覆盖系统快捷键；首版不开放第三方自定义快捷键 |
| `workspace.inspector`（M0） | 用户主动打开辅助检查面板。录音 dock 优先；可用空间不足时用现有受管浮层，不挤破正文宽度预算 | 受管底部面板或独立子页；底部面板放不下、IME 打开或滚动层过多时用子页 | 不常驻，不跟随正文逐键触发；收起先取消视图订阅，不触碰编辑器 key、保存队列或录音 session |
| `view` / `settings.section`（M2 对外） | 明确从「插件」入口打开独立视图；设置表单走插件详情 | 局部展示适合用面板，复杂内容用全屏子页；返回至原触发点 | 不向核心设置目录投放任意 HTML。非核心视图替换如获批准，必须用户显式指定，并提供宿主「恢复默认视图」 |
| `format.import/export`（M1） | 在「导入与备份」或原有导出入口按能力列格式；系统文件选择器由宿主打开 | 同入口，系统选择器和普通服务的失败路径不变 | 源文件/导出范围明确；预览列出新增、格式损失或不支持的附件。完整备份和恢复始终单列 |
| `theme`（M0 内置，M2 对外评审） | 「外观」的扩展区展示明暗色样，选中后同一 resolver 生效 | 主题选择器支持长标签；不可用时展示 Classic 回退与原因 | 不改文档 `paperStyle`/marks；不允许插件控制系统栏、任意 CSS 或系统菜单；原生界面仅使用已实现的投影能力 |
| 云同步 / 备份（M3）、模型 / Agent（M4） | 现有业务入口选择插件 provider；选区菜单可触发 Agent 工作流 | 同一业务语义，用本端受支持的设置、菜单和面板 | 未配置时显示「设置服务」而不是假执行；不临时切换账号、provider 或扩大上下文。外接页面/浏览器都有来源标识 |

同槽多项按宿主分组、稳定顺序和 ID 排列；同一条命令在多个位置来自同一个注册项。`when` 只能消费宿主提供的枚举/布尔能力（例如是否有已解锁的选区），不在渲染时执行插件代码，不传正文来计算菜单显隐。平台不能投影的原生工具区动作留在 Web 侧可达的「更多」，不新增原生命令绕过既有 intent 检查。视图关闭、插件停用或会话锁定时，移除贡献并回到上一个宿主可访问位置；不替插件恢复旧书签、不用当前笔记代替原目标。

## 3. 关键操作流程

```text
Install -> Choose ZIP / enter GitHub URL -> Host verifies package
        -> Review source, version, conflict, slots and access
        -> Install disabled -> Enable -> Active + host-rendered contributions

Command -> Check current target -> Preview data / effect -> Explicit action
        -> Run with Cancel -> Preview result -> Apply only if still current

Disable -> Show affected views / active work -> Pause at safe point
        -> Remove access and contributions -> Return to host fallback
```

| 场景 | 用户看到的行为 |
| --- | --- |
| 安装、启用和首次授权 | 从系统选择器选择 ZIP，或输入公开 GitHub 仓库/子目录。宿主下载/读取后展示名称、ID、版本、来源、平台、界面区块、权限和升级/冲突状态；无效包、内置 ID 冲突、同版本/降级、超额或危险路径直接拒绝。安装成功仍为关闭。当前外部包权限必须为空，因此不会出现第三方授权弹窗；未来新增权限时只由宿主确认 |
| 逐次敏感授权 | 宿主确认界面展示插件名、当前对象、数据范围、动作及目的地。比如「将选中的 3 段文字发给服务 X 的模型 Y」，或「把结果插入本笔记」。发送与写入分别确认；用户拒绝不再连续弹窗。关闭前返回焦点，敏感数据在锁定/切笔记时清除，晚结果不得重现 |
| 文件往返 | 系统选择文件 → 格式选择（有歧义时）→ 导入预览 → 确认；取消清暂存，不新增笔记。导出先选择范围和格式，再由宿主选择目标；渲染失败不覆盖现有文件。完整归档依旧使用原安全流程 |
| 同步与备份 | 展示配置名称、目标与读写能力；切换前预览源/目的，错误留在当前配置。禁用活动适配器时说明暂停影响，只保留一个进度/取消入口；暂停不删除已有备份和远端密文。无法证明已暂停时不报完成 |
| 模型和 Agent | 先显示发送预览，再显示逐段可取消输出。生成的建议可复制、丢弃或「审阅并应用」；预览以安全文本/结构化片段渲染。同一笔记内容已变化时只保留可审阅结果，不允许应用到旧选区；切换笔记、锁定或撤权则清除敏感预览 |
| 升级、撤权和卸载 | 预览显示「升级自 x.y.z」；升级保留设置、先关闭插件、原子替换目录，失败恢复上一版。当前不允许降级。卸载前确认，移除插件目录、安装记录和设置，绝不删除笔记、附件、备份或远端数据 |

操作成功按宿主回执更新列表、详情和工作区。插件界面只接受本窗口当前 context；离开页面默认释放第三方 frame，保留滚动等宿主导航状态，不保留私密表单数据。若离开时确有宿主能判断的未提交草稿，再用单一宿主确认；第三方页面不得拦截系统返回或阻止关窗。

## 4. 响应、输入与故障状态

| 条件 | 界面规则 |
| --- | --- |
| 初始读取 / 空列表 | 保留设置标题、返回与完成；加载骨架使用固定行高，呈报加载中。空列表解释无可管理插件；仅有内置时仍显示真实插件和当前状态，隐藏未上线操作 |
| 更新 / 启停中 | 行内显示当前动作，阻止重复提交；同一个 operation 只显示一个进度和取消。开关显示最近确认值和忙碌态，失败后仍能看到有效状态与重试 |
| 安装 / 预览中 | 对话框显示来源与验证阶段；预览期间禁止重复检查。失败显示宿主错误文案，不显示堆栈或包内路径。取消不写入插件目录，也不保留下载临时文件 |
| 外部包加载失败 | 注册表返回 `installErrors`，顶部横幅列出插件 ID、原因和「移除记录」；其他插件与内置插件继续工作。清单被修改、目录缺失、版本不一致都属于失败关闭 |
| 不兼容 / 缺依赖 / 未授权 | 详情显示具体原因和服务/设置定位；不出现失效工具按钮。缺授权与不支持本平台是不同文案，不让移动端误以为可以运行 macOS 的 MCP 宿主 |
| 面板本地故障 / 握手超时 | 仅该区域显示宿主标题、「未能加载」「重试」「关闭」；重试换实例代次。重试不重发原操作，不显示 raw stack。重复失败的插件由宿主标成需要处理，其他页面正常工作 |
| 注册表损坏 / 安全模式 | 固定恢复入口显示「插件未加载」及安全状态；保留宿主编辑、预览与恢复。启动失败或登记状态不可确认时，在核心启动页提供「不加载插件继续」；应用仍可用时，从插件中心可选择「在安全模式下重启」。原生宿主在加载插件前决定该模式。用户可在可读的注册表中定位、停用问题插件；若状态不可读，保留原文件并提示修复，不加载旧权限掩盖错误 |
| 键盘 / 屏幕阅读器 | `Tab` 依现有顺序经过筛选、列表和操作；`Enter`/`Space` 执行有名称的控件。`Esc` / Android Back 先关闭宿主最内层确认或面板，再返回详情列表或设置首页。焦点回触发器；入口消失则回宿主「更多」或页头。非紧急状态用 `aria-live="polite"`，错误与状态不只靠颜色 |
| 遮罩与窄窗口 | 未解锁覆盖层处于最高访问优先级，其后是系统权限/宿主确认、设置/插件面板、普通工作区。隔离页面不能创建越层遮罩。沿用 196px 桌面设置侧栏与现有 safe area；320px、最大字号时不并排强塞长按钮，触控至少 44px。Android 横屏/分屏仍是 mobile，不能触发桌面分栏策略；主题与语言变化不重建编辑器 |

原生 Mac 和 Android 的快捷键、返回、IME、系统选择器、深浅色由宿主适配；Web 预览只是合成 UI。滚动容器由宿主限定，面板申请高度须裁剪且不得反复抖动。宿主复用可访问性和布局 token；第三方 UI 可以获得必要的主题/locale 投影，但不能写回全局样式或访问相邻区域。

## 5. 组件树与验收任务

```text
Preferences
  PluginCenter -> PluginList / PluginDetail / InstallDialog / host PermissionDialog
  Existing business pages -> plugin status or settings deep link
WorkspaceShell
  Existing menus -> contributed command group
  InspectorSlot -> local ErrorBoundary -> built-in panel or isolated frame
  Host navigation -> plugin view boundary -> restore host route
```

当前 `PluginCenter`、安装对话框、升级/卸载、附件详情插件、设置挂载和注册表订阅已落地；图中独立外部视图、权限对话框和安全模式入口仍在后续阶段。`PluginCenter` 和现有业务页订阅同一投影；打开设置不触发初始化所有插件。原生投影只传固定动作与回执，同一能力不在多窗口重复启动。

| 验收组 | 可观察结果 |
| --- | --- |
| 内置 UI 基线 | 初次升级保留原外观、编辑、录音和备份行为；打开/关闭只读面板与配色后 Editor 实例、中文 IME、撤销、选区和保存轨迹保持；打开两窗同步看到确认状态 |
| 声明式外部包 | 示例 ZIP 与 GitHub 子目录均可预览、安装为关闭、启用后出现宿主区块、切换设置隐藏区块、升级保留设置、卸载移除记录；损坏 ZIP、路径穿越、内置 ID、降级、缺失目录和清单篡改按错误状态处理 |
| 双端布局 | macOS 正常宽窗、短窗和原生菜单，Web 699/700px，Android 320/390/430px、横屏和分屏。测试浅/深色、最大字号、长翻译、键盘/读屏、Back、焦点回归与安全区 |
| 业务流程 | 用新、旧库和真实形状 fixture 验证格式预览/取消/提交、关闭插件仍可读取旧内容、同步停点及回执；模型和 Agent 用模拟 provider 验证取消和待确认写入，不使用用户正文或密钥 |
| 故障与恢复 | 校验空态、升级权限变化、模块异常/超时、旧事件、并发停用、授权撤销、设置写入失败、快照损坏和安全模式；主编辑器不能被插件错误遮挡或卡死 |
| 对外能力放行 | 用实际 macOS 安装包和 Android 签名候选分别验 ZIP 文件选择、Android `content://`、GitHub 下载、预览确认、安装后关闭、卸载和焦点；浏览器画面与 fixture 结果不替代原生验证。可执行页面未放行，不纳入本组通过条件 |

## 6. 设备插件交互预留

硬件入口仅在平台与指定适配器实际可用后显示。设备管理挂在「插件 → 插件详情 → 设备」；工作区快捷入口复用「更多」与速绘、录音的原生宿主表面。不加全局蓝牙按钮。蓝牙权限、设备授权、输入目标与格式契约见[硬件设备插件](../architecture/plugin-devices.md)。

```text
Settings > Plugins > Device adapter > Devices
  Scan -> Select device -> Confirm connection and allowed actions
  Connected device -> Point-code bindings / Audio files (as supported)

Note > More > Receive Smart Pen -> Note-scoped input status
                                  -> Drawing panel -> Done / Cancel
Note > More > Import device audio -> Select item -> Preview -> Attach
```

| 交互 | 宿主界面约定 |
| --- | --- |
| 扫描与连接 | 在用户点击后申请系统权限；扫描中有取消，空结果有重扫。蓝牙关闭、权限拒绝、设备忙与协议不支持分别提示。显示实际连接与可用能力，不把「已连接」显示成「正在接收」或「录音中」 |
| 学习与绑定 | 宿主面板展示选定的笔、所识别码与白名单动作选择器，确认前不触发。显示既有绑定；冲突支持明确替换，取消不更改；离开释放学习状态并回到来源焦点 |
| 手写接收 | 用户在可编辑笔记启用接收后，显示「正接收：此笔记」和「停止接收」。点已绑定码或有效首笔可打开原有速绘面板；「完成」沿用原提交动作。断开保留仍可提交到原目标的完整笔画并提示，失效时不会改投当前笔记。提示与焦点变化按状态而不是逐点发布 |
| 外部录音 | 设备文件选择器显示设备、可用格式、导入进度和取消，预览后明确「添加到此笔记」。实际支持实时采集时，才为现有录音面板加来源选择；录音中标识跟真实状态及原笔记，不自动启用、切换麦克风或展示推测波形 |
| 窄屏与退出 | 桌面在现有设置面板内显示设备详情，手机用设置子页和现有速绘/录音面板。沿用安全区、键盘焦点与触摸命中区；`Esc` / Android Back 优先取消内层选择或学习，再退回来源，不结束无关的本机录音。受系统授权和锁定遮罩保护 |

## 7. 示例插件与安装文案

仓库内置 [`examples/plugins/cybernote.sample`](../../examples/plugins/cybernote.sample/README.md)，用于界面与安装回归。它不包含脚本，只声明：

- 一个 `cybernote.sample` ID、`1.0.0` 版本和 macOS/Android/Web 平台；
- 一个 `plugin.detail` 宿主渲染区块「示例插件已加载」；
- 一个布尔设置 `showPanel`，控制该区块显隐；
- 空的权限、主题和设备适配器列表。

```text
GitHub: https://github.com/ywateru/CyberNote/tree/main/examples/plugins/cybernote.sample
Local:  pnpm plugin:package
        release-packages/cybernote-sample-plugin.zip
```

安装对话框必须使用以下语义，不能把“安装”描述成“立即运行”：

| 状态 | 文案与行为 |
| --- | --- |
| 预览成功 | 显示「安装并保持关闭」；若已有旧版则显示「升级到 x.y.z」，并说明保留设置、先关闭 |
| 已安装同版本 | 显示「此版本已经安装」，禁用提交 |
| 内置 ID 冲突 | 显示「该插件 ID 已被内置插件占用，不能覆盖」 |
| 降级 | 显示已安装版本，禁用提交 |
| 本端平台不可用 | 允许安装但标注「本端不可用」；启用开关禁用，设置保留 |
| 安装成功 | 关闭对话框、选中新插件，提示“已安装并保持关闭”；不自动启用 |
| 卸载 | 二次确认，明确不会删除笔记、附件、备份或远端数据 |
