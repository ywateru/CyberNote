# 标签、智能文件夹、数学与笔记链接

基准：2026-11-03，本机 macOS 26.4、Notes 4.13。以下是 CUA 操作原版的实际观察；仅操作 `Notes Clone UI 对照` 中的合成笔记。它们规定离线实现的行为，不包含 iCloud 协作。手机对应页面尚未在提供的短录屏中确认，不能将 Mac 弹层直接宣称为手机原版。

## 数学结果

```text
编辑区输入 2+3=
  → 等号后出现黄色 5（建议，尚未接受）
  → Return 接受 5，当前行为不新增换行
  → 结果成为可编辑来源表达式的内联元素

更多 → 数学结果
  ├─ 插入结果
  ├─ 建议结果 ✓（初次采样设置）
  └─ 关
```

实采只证明 `2+3=` 的建议与接受行为，不证明原版完整数学语法、变量、单位或全部运算。`macos26-math-suggestion.png` 是接受前，`macos26-math-confirmed-tag.png` 是接受后。AX 对结果有编辑其源表达式的 Help。菜单中 AX 的 selected 可能仅表示鼠标悬停；本次真实勾号在“建议结果”，不能把悬停“插入结果”误判为设置。

同日续采在独立合成笔记 `Math Mode Reference` 中切换到“插入结果”，`macos26-math-insert-checked.png` 可见该项真实勾号。有限输入探针得到混合状态：旧的黄色 `=5` 仍具有“编辑产生此结果的表达式”AX说明，相邻 `4+6 =10` 在切换笔记重开后为普通文本；另行输入的 `7+8=` 重开后仍为原文字。由于本轮的键名 `equal` 与字面等号、Return 接受/换行路径未被完全隔离，这些截图只记录本次序列，不能据此确定插入模式的一般触发条件。最终状态见 `macos26-math-insert-bounded.*`。收尾已通过菜单点击“建议结果”，但未取得恢复后的可见勾号，恢复设置仍待复核；不得把该动作记录为验证通过。

实现必须分别保存表达式和结果，并可重开/编辑来源；仅把算式替换为普通字符串不足以重现已观察的编辑行为。关闭模式不自动计算。具体支持的安全表达式范围及错误路径需在实现任务中明示，不执行输入中的脚本。

## 标签

在普通正文粘贴 `#UI对照` 并输入空格后，原版将其识别为标签；侧栏出现标签分组、“所有标签”和 `#UI对照` 的芯片。截图 `macos26-math-confirmed-tag.png`。本次未测清空最后一个引用、标签重命名、标签多选的完整行为。

内容标签须来自真实文档且持久化；锁定笔记的标签、标题与正文泄露边界以本地加密契约为准。不能只在侧栏静态摆放样例标签。

### 标签首批实现边界（APP-003-TAGS-01）

```text
侧栏（Mac 原版已见结构；精确尺寸待新截图）
┌───────────────────────────┐
│ 在我的 Mac 上             │
│   全部备忘录         计数  │
│   备忘录             计数  │
│                           │
│ ▾ 标签                    │
│ [所有标签] [#UI对照]      │
│ [#另一个真实标签]          │
└───────────────────────────┘
点所有标签 → 至少含一个已提交标签的真实列表
点 #UI对照 → 精确该身份的真实列表 → 原有正文编辑
普通编辑/删除最后引用 → 原筛选空结果；普通文件夹导航 → 清除筛选
标签内部活动组字失去匹配 → 列表立即更新，当前组字结束后停车编辑区
访问失效且无其他合法引用 → 清除该名称，转“所有标签”
```

标签提交显示在原正文位置，不替换正文字符串，不新增弹窗；首批单标签选择即可。目录没有真实标签时不显示样例芯片。选中/未选中、深浅色、空结果、删除/恢复、锁定后立即移除受保护目录内容均需覆盖。文字、分组及芯片参考已保存原图；未测量的字体、内边距、颜色、hover/选中、滚动与手机页面均保持待证，不能给本工程初始 CSS 标成原版数值。手机复用本地标签数据与导航能力，但标签页面外观尚无录屏依据，不宣称原版 UI 完成。详细语法及编辑边界以架构的已提交标签契约为唯一来源。

编辑已提交标签内部文字时，不因活动组字产生的暂时失配而隐藏或 blur 当前编辑区；仅保留当前输入过程，结束后按真实筛选结果停车。列表与目录不伪造匹配，访问失效仍立即遮挡。此输入边界是防止丢字的工程契约，尚非本机原版同场景取证。

## 笔记链接

```text
普通正文键入 >>，继续输入目标标题片段
  → 建议浮层：新建笔记入口在先，匹配已有笔记在后
  → Down / Down / Return 选中并接受已有笔记
  → 输入片段替换为黄色下划线链接（含笔记图标与目标标题）
  → 点击链接，在同一主窗打开目标笔记
```

本次查询“样式与表格”，匹配合成笔记“样式与表格对照”，浮层带时间。`macos26-note-link-suggestion.png` 为浮层，`macos26-note-link.png` 为接受后的链接。打开目标时未观察到新增可见返回按钮；后续应核对“最近备忘录”等返回路径，不能凭猜测增加按钮并声称一致。

本地链接应以稳定 note ID 存储，不能以标题作为主键。目标改名、删除、锁定、导入重映射等状态仍需取证与验证；有效链接必须调用既有选中/保存入口，不另起文档状态。

## 智能文件夹

```text
┌────────────── 新建智能文件夹 ──────────────┐
│ 名称：[新建智能文件夹                 ]   │
│ ☑ 制作智能文件夹                          │
│ 使用标签和其他过滤方式整理。              │
│ 包含匹配下列 [全部 ▾] 过滤条件的备忘录：   │
│ [标签 ▾] [所有已选 ▾] [标签输入] [-] [+]   │
│                           [取消] [好]    │
└──────────────────────────────────────────┘
```

顶部组合规则为“全部/任意”。本次下拉菜单逐项采得过滤种类：标签、创建日期、编辑日期、共享、@提及、核对清单、附件、文件夹、快速备忘录、置顶备忘录、锁定备忘录。标签匹配规则为：所有已选、任何已选、任何标签、仅不含标签的备忘录。

默认新建只有一条标签规则，移除按钮禁用，添加按钮可用；名称选中可编辑。本次仅采样，最后通过“取消”退出，没有保存智能文件夹。截图和 AX 见 `macos26-smart-folder*`。因此它们是界面/选项证据，不是创建后匹配结果的实证。

克隆只实现离线可成立的条件。共享/@提及依赖网络协作，不能伪造协作状态；可清楚说明本地适用范围。日期、标签、清单完成情况、附件类型、文件夹、快速/置顶/锁定等本地规则需真实求值并保存规则。先核对各子条件的原版文字与可见行为，再完成对应 UI；尚未采样的子菜单保持待证。

## 标准格式入口

原版文件菜单 AX 记录 `macos26-file-menu.ax.txt`：导入至备忘录…、导入Markdown…；“导出为”下为 PDF、Markdown；另有“在Pages文稿中打开”、打印…、复制备忘录。仅确认入口，尚未在该批次导出样本或确认 Markdown 附件的目录组织。克隆的本地完整归档解决另一项恢复用途，不能替代这两个标准格式出口。
