## 已观察尺寸与样式

原版截图 2× 像素除二后：侧栏宽 228 pt；列表宽 280 pt；编辑区左边距约 23 pt；日期行在窗口顶部约 68 pt，正文起点约 86 pt。侧栏为浮动圆角浅灰玻璃区域，边缘约 8 pt 留白，圆角约 24 pt。工具栏为分组的胶囊/圆形玻璃按钮，26 版外观；不能用旧版 14/15 的平直工具栏冒充。列表选中卡片约横向 10 pt 留白，圆角约 8 pt。侧栏选中项为浅灰底、黄色图标与文字；非当前编辑焦点的列表选中为灰色。具体色值/字体在截图差分时校准。

基色起点（估计，尚未逐像素认证）：paper #ffffff、sidebar #f7f7f7、selection #dedede、ink #262626、secondary #898989、accent #e4ac00、divider #dedede。字体系统默认，正文约 14 pt，侧栏约 14 pt，列表标题约 14 pt semibold。不要为了统一设计而修改原版层级。

## 交互

| 动作 | 结果 |
|---|---|
| 选择文件夹 | 计数、列表、编辑器上下文更新 |
| 新建笔记 / Cmd+N | 在当前文件夹创建，编辑区获得焦点 |
| Cmd+F | 原版范围待核对，全局搜索与笔记内查找分开 |
| Cmd+B/I/U，撤销/重做 | 对编辑器选区应用，保留光标 |
| 点击格式 | 样式弹出菜单，显示当前样式 |
| 点击核对清单 | 当前段变任务项，回车续项 |
| 点击表格 | 光标处 2×2 表格 |
| 点击媒体 | 文件/照片/录音等菜单 |
| 调整分栏 | 内容随宽度换行，保存布局 |
| 画廊切换 | 日期区→缩略图+标题+时间；双击打开独立窗 |
