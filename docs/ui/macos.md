## 默认设置与粘贴路径补证

只读打开原版设置（未更改）：新备忘录开头格式为“标题”，可选标题/小标题/副标题/正文；按日期分组=开；自动排序已勾选项目=关；默认文本大小滑块AX值=1。截图`macos26-settings.png`。该设置页本次截图1058×1270px，不能与主窗尺寸混算。

新建测试笔记后直接键入ASCII `Title Reference`，回车，再粘贴中文正文，得到标题粗体约20pt，正文约14pt，紧随标题下一行（`macos26-typed-title.png`，实测2176×1322px，比此前主窗高2px，后续比对须对齐而非盲目缩放）。此前两次空笔记纯文本整段粘贴都得到普通正文。故不能用“首段是标题来源”强制重写任意粘贴文档，也不能为匹配粘贴而取消直接输入时的默认标题样式。实现与验收必须按相同输入路径比较。

补充明确路径：新建后 `paste('纯文本输入对照\n第二行正文', {format:'text'})`，两段均为14pt正文，无标题粗体（`macos26-paste-explicit-text.png`与AX）。本次明确记录传入纯文本格式；普通粘贴的系统类型与富文本粘贴另验，不扩大为“任何粘贴必为正文”。

## 表格转换补证

在含“项目/状态；本地保存/待核对”的表格上，通过单元格公开的 AX 动作“将表格转换为文本”，得到 `项目\t状态\n本地保存\t待核对\n`，转换后的整块文本被选中；一次撤销恢复原表格。截图与AX：`macos26-table-converted.*`。表格按钮Help可能滞后：焦点不在表格内时点击曾新插入空表格，已撤销；不能仅凭Help字段决定转换，必须按真实选区。

边界样例“表格转换边界”：第一行左格含两段 `A1\nA2`、右格C，第二行左格B2、右格空；转换选中文本为 `A1\nA2\tC\nB2\t\n`。单元格内部换行保留，列间Tab、行间换行，末尾空单元格仍保留Tab；一次撤销恢复含多段的表格。`macos26-table-boundary-before.*`和`macos26-table-boundary-converted.*`保存操作前后。样例准备中使用了AX设置多段内容，转换本身为真实公开UI动作；不据此声称多行键入/粘贴在单元格内的全部行为已经验证。
