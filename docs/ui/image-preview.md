# 图片选择与浮动预览

2026-11-07 更新。本文取代之前整窗遮罩和焦点锁定的预览契约。当前交付及证据见[统一菜单与浮动预览验证](../verification/cybernote-desktop/UNIFIED-MENUS.md)。

正文图片单击使用 ProseMirror NodeSelection 选中，仅改变选区，不写入正文或增加撤销项。编辑器保留焦点，随后点击文字、进入表格或使用编辑快捷键仍按正常编辑流程执行。双击或通过附件菜单的“快速查看附件”打开图片预览。

预览是主窗口内的非模态浮动面板，使用浅灰色圆角窗口。背景没有遮罩，不隐藏或禁用主工具栏，不锁住 Tab 焦点。拖动标题栏可移动位置；拖动按钮不会移动窗口。位置限制在视口和原生工具栏保留区域之内，调整主窗口大小后保持标题可达。双击标题栏或点击放大/还原按钮可切换面板尺寸。它不是独立的 macOS 系统窗口，不能拖到主窗口外。

顶部提供关闭、放大/还原、文件名、信息、共享、导出原图、通过默认应用打开。信息来自当前授权的原始文件及实际解码结果，不虚构日期或 EXIF；SVG 使用明确的可用宽度，图片保持等比显示。预览内部按 Escape 关闭，正文中的 Escape 保留正文的原有行为。

切换备忘录时，预览保留原图片和文件名，主界面可继续编辑。预览拥有原媒体 Blob URL 的独立租约，正文节点卸载仅释放正文租约，最后一个持有者释放时才撤销 URL。预览导出及系统打开仍针对原附件所有者鉴权，不依赖当前选中的备忘录或已卸载的正文按钮。

原图片引用被移除、所属备忘录被删除、锁定/撤权/prepare、授权代际变化、同步保护或窗口退出时，立即隐藏并关闭预览。关闭时仅在焦点仍属于预览且原入口仍可见时恢复入口焦点；不会把正在主界面操作的用户焦点拉回旧图片。每个面板拥有独立的运行状态和请求身份，迟到的导出结果不能修改另一个面板。

设置仍是模态窗口，使用 `contentOverlay` 隐藏底层原生编辑工具。图片预览和附件菜单不再使用这一状态。
