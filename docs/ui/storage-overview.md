应用frontend-design流程，在用户指定macOS系统外观内设计：系统SF/PingFang字体，白/深主题paper背景，浅灰grouped分组、12~16px圆角、细分隔线、克制阴影与对齐留白；文字主/次层次明确，主色继承Notes accent。类型颜色固定：图片橙#FF9F0A，录音红#FF453A，视频紫#AF52DE，其他附件蓝#007AFF，数据库青#30B0C7，辅助日志灰#8E8E93，其他文件#AEAEB2。颜色只编码存储类型；文本和可访问名称同时表达类型、字节和数量，不只依赖颜色。

## 统计与数据

仅使用get_data_management真实快照，不增数据库/存储迁移。总占用为totals.totalBytes（应用数据文件长度合计，不声称文件系统分配块或全盘容量）。分类互斥：database、wal/shm、已登记image/audio/video/其余附件、无登记信息的其他文件/目录。实际字节按唯一relativePath去重，每个物理路径只计一次；后端shared-path重复登记行仍可见但不重计，分类需与后端最后归属行一致（后端duplicate rows位于主rows之后，采用首个唯一路径）。byte=null保留未知/缺失且不加入空间条，不用declaredSize替代实际字节；真实零显示0，空分类明确0项/0B或未知项。总览说明未知项目数/采样警告，不能假造可用磁盘/时间/EXIF。校验分类合计等于已知物理总和，均不读取附件payload，不改变原库。

总览明显显示总字节与各类字节/条目数，柱条按实际比例，无数据时显示明确空态，不用最小宽度捏造占比。很小片段仍可用图例/分类行进入；键盘Enter/Space可操作，焦点可见。信息不需要在总览堆成多行实现细节；数据目录与采样信息放二级折叠区，警告/录音未保存说明仍可发现。
