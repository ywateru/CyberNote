# 附件画廊

2026-11-08，当前源码实现。

## 入口与布局

文件夹顶部的“显示选项”菜单提供“查看附件”；macOS 对应原生顶部栏的显示选项菜单。备忘录“更多”菜单中的“附件视图”进入同一界面，替代原来的文件名列表弹窗。独立备忘录窗口不提供文件夹附件浏览入口。

画廊保留文件夹侧栏，占用其余主区域，不同时展示备忘录列表和编辑器。桌面为四列、较窄窗口为三列，移动端为两列。顶部提供照片与视频、音频、文稿、全部附件四个分类，每个分类显示数量。当前产品没有独立的地图、网站或扫描件附件数据类型，因此不增加空壳分类；PDF 等文件归入文稿。

图片和视频用缩略图，录音使用试听按钮及真实波形，其他文件用文件类型图标。卡片下显示原文件名、所属备忘录标题、大小，录音有保存的录制日期时显示日期。分类、标题和画廊间距跟随界面字号，正文仍跟随编辑器字号。

## 定位备忘录

- 图片单击选中并显示金色边框，不自动预览。
- 双击附件缩略图、在缩略图上按 Enter、点击所属备忘录标题，或在右键菜单选择“在备忘录中显示”，均定位到原附件。
- 定位会退出附件模式，切换到所属的实际文件夹和备忘录，清除会遮住目标的搜索、标签等筛选，选中正文中的附件节点并滚动居中。
- 目标用金色框线高亮约 2.2 秒。期间跟随图片加载带来的正文高度变化；用户滚动或点击正文后停止自动跟随，避免抢夺操作。
- 原有备忘录列表/画廊偏好保留，不为附件浏览持久修改显示方式。

## 菜单与媒体生命周期

右键和卡片“…”使用现有 MenuSurface/MenuItem，macOS 可使用相同 AppKit 菜单构建器。提供在备忘录中显示、图片快速查看、保存、拷贝，macOS 还提供系统打开、从目录打开、共享。图片快速查看复用可拖动的非模态预览窗口，并绑定原附件所属备忘录的授权。

录音复用现有播放控制器、有限时长探测和波形组件。画廊内开始播放另一段录音会暂停前一段。切换分类、离开画廊或资源释放时停止播放并释放 URL。缩略图与媒体按可见区域延迟读取，文稿图标无需提前读取整个原文件。

## 范围、搜索与权限

非搜索状态沿用当前文件夹/智能文件夹/标签范围；搜索沿用应用搜索范围，并扩充匹配附件名。附件名搜索仅列出该附件；备忘录标题或正文匹配时显示其相关附件。

只展示非内部附件、未删除备忘录、获得授权且正文仍引用的附件。每次操作重新检查原所属备忘录、当前正文引用和权限代次。同步保护阶段立即隐藏画廊中的媒体、停止播放、关闭旧菜单，拒绝使用旧请求操作新的备忘录。

分类支持方向键、Home、End；Cmd/Ctrl+F 聚焦画廊搜索，Escape 先关闭菜单/搜索，再退出附件模式。
