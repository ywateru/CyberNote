# UI 证据与规格

界面以原版为目标，不进行自由品牌设计。Mac 使用系统 SF/PingFang 字体与 AppKit 窗口行为；Android 应用内容按用户 iPhone 录屏重建，手机系统字体/键盘差异另列。所有数值须区分观察值与估计值。

- [Mac](macos.md)：本机 macOS 26.4，Notes 4.13。
- [Android](android.md)：以 references/mobile 中保存的视频为基准。
- 图标：优先精确描绘原版线条与尺寸；通用图标库仅作为实现起点，不作为已匹配依据。
- 状态：亮/暗、选中/未选中、聚焦/失焦、菜单/弹窗、空/加载/保存失败、键盘显示/隐藏均需覆盖。
- 用户录屏只确认亮色；深色与未见状态需补充原版证据。

UI 状态归前端；持久内容归 Rust。未取证的数值/功能在各页面标记待验证，不能暗示已观察。
