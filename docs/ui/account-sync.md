# 账户与同步界面

当前交互见[设置页的账户与同步](preferences.md#账户与同步)。下文保留历史方案和当时包的验证入口；它们不能证明当前发布包的界面或账户行为。

2026-11-19 后续重构目标见[设置重构契约](../architecture/settings121.md)：右侧改为分隔列表，增加自有云存储配置，冲突入口收拢到账户分类。实施与验证完成前，下方既有功能证据仍只适用于对应旧包。

2026-11-19 的界面收敛与 CyberBus 修复见 [验证记录](../verification/cyberbus125/README.md)。当前账户页分为账户、本机及其他设备、桌面折叠的“登录与安全”三个区域。常用流程按左对齐纵向排列，沿用系统字体以及现有 `paper` 白色 `#ffffff`、`grouped` 灰色 `#f2f2f7`、`ink` `#19191c`、`secondary` `#666773`、`accent` 黄色 `#d99300` 和 `line` `#d1d2da` 主题 token；深色模式由既有主题处理。

```text
账户与同步
  账户名称 / 用户名                          退出账户
  我的设备                                  刷新设备
    本机名称                                更改名称
    允许此设备同步                          开关
    连接状态 / 待应用 / 最近传输
    其他设备 / 在线状态 / 笔记摘要             打开方向确认
      本次操作进度（对话框收起后显示）
  登录与安全                  当前存储方式    展开（仅桌面）
```

“登录与安全”默认收起，展开后再选择凭据存储，仅改变选择时显示应用按钮；登录期间显示实际使用的方式，退出后才可切换。界面不展示加密算法、文件权限或内部账户 subject。未登录保留两种登录方式、用户名大小写提示与本地使用说明；已登录不重复显示本地使用说明。

同一次传输在对话框打开时只显示对话框进度，收起后显示在对应设备行；目标已从目录消失时才在本机区域兜底显示。即时命令错误与状态错误具有相同安全代码和阶段时只显示一次，不同错误保留各自说明。设备对话框显示其错误时，页面不重复显示同一状态错误。需要退出重登录时，账户区域的单一退出按钮使用明确的恢复文案，仍经过退出确认。

手动验证入口：[当前双桌面启动与设备动作](../verification/account110/MANUAL-TESTING.md)，实际范围与保留失败见[当前交付结果](../verification/account110/RESULT-LATEST.md)。旧版Android及两种登录方式的历史记录见[account109指南](../verification/account109/MANUAL-TESTING.md)。本文件描述界面行为，不能代替按版本记录的实测结果。

沿用CyberNote已有白纸、柔灰分组、黄色选择和系统字体。新增设置分类“账户与同步”，保留原“设备同步”高级手工入口。保持未登录即可本地编辑，不在启动时强制登录。

## 桌面

```text
┌ 设置 ─────────────────────────────────────────── × ┐
│ 账户与同步       │  账户与同步                       │
│ 外观与字号       │  在你的设备间同步备忘录             │
│ 备忘录           │                                  │
│ 设备同步         │  [用户图标] 登录 CyberNote          │
│ 存储空间         │  备忘录保存在此设备。登录同一账户后， │
│ 导入与备份       │  可在你的设备间同步。               │
│                  │  登录方式                         │
│                  │  (●) 应用内登录 (○) 系统浏览器     │
│                  │  [登录]  [创建账户]                │
│                  │                                  │
│                  │  本地使用不需要账户。              │
└─────────────────────────────────────────────────────┘
```

登录后显示用户名称、账户标识和“退出账户”；下方为“同步此设备”许可开关及账户设备列表。以[单次设备操作契约](../architecture/account-device-actions.md)为准：设备发现独立于内容许可，开启不自动广播；原全局“立即同步”替换为“刷新设备/重试连接”，不发送无目标内容。

```text
账户与同步                         [退出账户]
同步此设备                         [──●]
允许与选定设备收发。开启后不会自动传输。

我的设备                           [↻ 刷新设备]
选择其他设备，开始一次同步
╭─ 淡黄色本机区域 ────────────────────────╮
│ Mac 工作台  [✓ 此设备]        [更改名称] │
│ ● 在线  可同步                          │
│ 12 篇笔记   笔记更新于 今天 10:32        │
╰─────────────────────────────────────────╯
┌─────────────────────────────────────────┐
│ Mac 测试端         在线 · 可同步       › │
│  8 篇笔记 · 笔记更新于 昨天 18:20        │
├─────────────────────────────────────────┤
│ Android            离线                 │
│ 设备上线后可查看笔记数量和更新时间       │
└─────────────────────────────────────────┘
待应用 0 项 · 冲突 0 项
```

设备行使用稳定ID区分，同名不合并。本机始终排在最前，以淡黄色背景、描边与“此设备”标记突出，独立提供“更改名称”，不提供对自己推拉；本机图标按实际运行平台显示手机或电脑。其他设备使用通用设备图标，整行可点击，末尾显示箭头。在线状态用文字与圆点共同表达，笔记数量和更新时间单独排列。在线但未启用的设备标“同步已暂停或暂不可用”；数量未知显示“笔记信息暂不可用”，0篇与未知不同；空库更新时间显示“暂无笔记更新时间”。每行时间必须来自笔记摘要，不能显示设备心跳或上次传输时间。离线行保留名称，隐藏过期摘要，点击时给出明确不可用说明。设备列表不显示内部URL、证书或协议标识。异常有文字和重试入口；冲突连接原“查看冲突”。

点击“刷新设备”后，按钮图标旋转、文字变为“正在刷新…”，同时禁用重复操作；列表保持可见，通过 `aria-busy` 与状态播报表达刷新进度。完成后恢复按钮，失败显示原有错误和重试入口。初次读取账户状态也显示 loading 图标。尊重系统减少动态效果设置，此时保留进度文字并停止旋转。仅有本机或设备目录为空时，显示登录另一台设备的引导。

点击远端设备打开统一模态框，默认双向；取消/Escape不传输，只有明确确认派发一次目标明确的请求：

```text
┌──── 与“Mac 测试端”同步 ─────────────────┐
│ ( ) 推送到此设备    本机 → Mac 测试端    │
│ ( ) 从此设备拉取    Mac 测试端 → 本机    │
│ (●) 双向同步        仅这两台设备收发     │
│ 合并笔记和附件，保留各端独有内容；       │
│ 冲突按既有规则处理，不覆盖整库。         │
│                      [取消] [开始同步] │
└────────────────────────────────────────┘
```

对话框绑定发起时的账户与稳定设备ID。目标离线、许可关闭或账户切换后不得确认；不自动改选其他设备，也不在恢复在线时补发。进行中禁用重复确认；显示目标与方向，成功文案为“本次传输完成”，待应用和冲突单独显示，不承诺所有笔记已应用。失败允许对同一目标/方向重新确认。更改本机名称使用同风格对话框，最多96字符，明确显示输入错误。


“同步此设备”使用圆角轨道与滑动圆点的开关，关闭、开启、禁用与键盘焦点均有明确样式。开启同步与退出账户的确认使用居中的模态对话框，不占用账户页正文空间：

```text
账户页：同步此设备                         [ ●── ]
          ↓ 点击开启，开关仍保持关闭
┌────────────── 遮罩上的确认对话框 ──────────────┐
│ 开启账户同步？                                │
│ 允许与当前账户选定设备合并本库笔记及附件。 │
│ 请确认允许将这些内容同步至当前账户。           │
│                        [取消] [允许同步]    │
└──────────────────────────────────────────────┘
```

对话框沿用现有纸面、边框、圆角和主操作按钮颜色，遮挡并阻止操作后方设置内容。初始焦点放在“取消”，Tab / Shift+Tab 只在对话框内移动；Escape 或取消关闭后将焦点返回发起控件。确认前不发送开启或退出命令；取消不改变同步状态。关闭开关直接暂停，无需合并确认。手机对话框按可用宽度缩小，正文可滚动、按钮可折行，开关触达区至少 44px，视觉轨道保持紧凑；尊重系统减少动态效果设置。

## 手机

账户资料、同步许可使用白色分组，沿用固定导航与独立滚动；省去与导航重复的页首说明。账户名和账号紧凑排列，退出操作使用轻量文字按钮。同步说明下方以分隔线区分连接状态，待应用数量与最近传输时间采用左右对齐的紧凑行。

“我的设备”标题和刷新操作直接放在分组背景上，本机区域以淡黄色独立突出，其他设备合并在白色列表中。本机名称和“此设备”标记允许换行，改名使用右上角的铅笔图标按钮，保留“更改名称”的无障碍名称和44px触控区。其他设备的整行是一个按钮，设备状态和笔记摘要关联为无障碍描述，笔记数量和更新时间分别成行；不再单独给设备名预留一行按钮高度。刷新、改名图标独立使用16px尺寸，避免全局录音布局样式将其放大。支持320px窄屏及极大字号；浅色和深色模式保持相同信息层级。

设置首页新增独立账户分组，进入全屏账户子页；固定返回/标题/完成，正文独立滚动。登录与创建账户按钮纵向或按可用宽度排列，最少44px触达；长账号标识折行，不横向撑开。登录方式提供应用内托管页与系统浏览器，等待提示跟随实际 native surface；只有已验证回跳可更新成功状态。

## 交互与状态

- 登录/创建账户根据登录方式，在独立原生 WebView 或系统浏览器打开同一 Logto 托管页。初始选择应用内登录，两按钮共享选择；授权中禁用方式选择。客户端不复制密码表单、不保存密码；注册完成回到同一账户页，保持同步暂停，明确开启许可并选择设备动作后才传输。
- 应用内授权等待时提供“在浏览器中继续”和“取消登录”；切换复用本次 native 授权，不在页面显示或复制授权 URL。用户关闭内置窗口等同取消，完成/取消/切换后清理窗口。具体接口与安全边界见[双入口契约](../plan/tasks/app-account109-login-surfaces.md)。
- 授权期间显示等待提示、取消按钮，防重复提交。取消后迟到回跳无效；错误可重试，本地笔记仍可访问。
- 本地资料库不绑定用户名，退出后可登录另一账户。登录保持同步暂停；开启确认说明后续选择设备传输时，本库所有当前内容（包括此前同步保留的内容）可参与当前账户合并，开启本身不广播，退出确认说明保留本机笔记并停止账户同步。同步空间切换遇到尚未处理的冲突或待应用数据时明确说明处理步骤，不阻止登录或本地编辑，见[资料库独立契约](../plan/tasks/app-account109-account-independent-library.md)。
- 同步暂停后仍保持已登录和目录在线，停止内容服务及在途操作；仅显式设备动作触发传输。无其他设备时提示“在另一台设备登录同一账户，即可开始同步”，不显示伪进度。
- 启动恢复遇到网络错误时显示“重试连接”，仅在用户明确点击后用已保留授权恢复；不因此打开登录页或撤销授权。恢复成功若原来暂停则仍暂停，不能以“重试”偷偷开启合并。明确的认证拒绝才显示“重新登录”；无效响应、配置、存储和资料库归属错误保留各自说明，不统一视为登录失效。状态轮询只读，不暗中反复发起恢复。
- token 响应信封拒绝在有完整有限诊断时，显示“登录响应”或“刷新响应”的授权类型、访问授权、有效期或授权范围未通过校验；文案取自本地固定表，不显示返回值。旧错误无细分时保持通用校验失败文案，不猜测根因，不新增恢复动作。字段与有效分支遵循[有限诊断契约](../plan/tasks/app-account109-token-response-diagnostics.md)。
- 登录返回后的错误按[阶段分类契约](../plan/tasks/app-account109-post-login-errors.md)显示具体操作与有限原因；可展开“错误详情”查看安全代码和阶段。即时命令拒绝与已保存账户状态分开标注，未知错误不猜为网络故障。
- 单次设备操作的 `account_sync_failed` 在具有完整 `syncStage/syncReason` 时，详情显示本地固定表中的配对、恢复配对、传输或收尾阶段，以及有限原因。仅有通用代码、没有阶段和原因时，提示“请先退出账户并重新登录，再重新开启同步”，并在已登录状态提供“退出账户以重新登录”入口；即时命令拒绝也显示相同恢复指引。入口复用退出确认，确认前不撤销授权，取消后保持原状态；退出成功后由用户显式登录和开启同步。该建议不将错误定性为 token 过期，不改变原生重新授权权限，也不自动退出、登录或传输。字段只接受[设备契约](../architecture/account-device-actions.md)列出的成对枚举，不透传远端错误文本。
- 大资料库开启时，窗口确认与附件准备分别计时，规则见[媒体准备期限契约](../plan/tasks/app-account109-adoption-large-library.md)。仅当原生同时返回有限的 `adoptionStage` 与 `adoptionReason: timeout` 时，显示对应的窗口响应、保存确认或附件准备超时及重试说明，不将明确超时标为旧同步冲突。详情仅显示固定阶段与原因，不包含内部路径、标识或用户内容。

```text
需要处理
无法读取账户同步资料：请求超时。请稍后重试。
▸ 错误详情
  错误代码 / 发生阶段 / 有限原因 / HTTP状态（如有）
```
- 使用现有偏好面板的焦点约束、Escape/返回、浅深主题、字号与桌面28px/手机44px全局控件规则；新CSS限定在账户区域，不覆盖编辑器或既有同步样式。

颜色参考来自既有CSS变量：纸面#ffffff、分组#f2f2f7、主字#1c1c1e、次字#8e8e93、选择#fff1c8、动作黄#e6a700。生产实现优先引用既有变量以正确跟随深色模式，不引入独立字体包或装饰性动画。


### 本机卡片内的同步许可（2026-11-16）

“同步此设备”独立分组并入“我的设备”首张本机卡片。设备名称、此设备标记、笔记摘要和更名入口在卡片顶部；下方为“允许此设备同步”开关与说明，底部紧凑显示账户连接状态、待应用数量和最近传输。移动端更名保留 44px 触控区，开关位于独立一行右侧。尚未取得本机目录行时仍显示本机卡片与同步开关，不生成伪设备 ID；更名需等待真实目录行。

开启继续走既有确认流程，开启和刷新不自动传输；用户选择其他设备与方向后才传输。其他设备列表继续显示在线、同步许可及笔记摘要。按用户要求，本次交由用户在 Mac 和 Android 测试机手动验收，不执行自动化测试。

### 可收起的同步进度（2026-11-16）

明确确认设备与方向后，原生运行时接管有限传输。弹窗显示连接、验证、比较内容、接收、发送、确认结果的真实阶段；有差集时显示已持久确认版本数/总数和进度条，同时显示已传输内容字节及耗时。版本项不称为笔记，不能把收据等同于已应用。总数未知时显示不定进度，不编造百分比。

传输期间隐藏方向选择与重复开始按钮，提供“收起，后台继续”；Escape、返回和关闭弹窗不取消同步。本机卡片保留完整进度、目标和方向；目标设备行显示紧凑进度，进行中仍可点击该行查看详情。关闭整个设置后，任务仍由原生运行时持有，重新打开从 status 恢复。这里的后台指离开同步界面，应用被强制退出/Android 回收进程不承诺继续执行。应用不自动重试，失败后保留最后计数与错误，用户重新确认方向后重试。

当前 ADB 故障截图保存在 `artifacts/account-sync-progress-20261116/android-before.png`，明确为传输阶段超时，而非凭证失效；超时提示引导保持两端运行、检查网络后重新选择设备，不引导无意义的重新登录。按既有用户要求不运行测试，仅构建、安装并交由手动验收。
