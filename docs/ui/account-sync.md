# 账户与同步界面

沿用CyberNote已有白纸、柔灰分组、黄色选择和系统字体。新增设置分类“账户与同步”，保留原“设备同步”高级手工入口。保持未登录即可本地编辑，不在启动时强制登录。

## 桌面

```text
┌ 设置 ─────────────────────────────────────────── × ┐
│ 账户与同步       │  账户与同步                       │
│ 外观与字号       │  在你的设备间同步备忘录             │
│ 备忘录           │                                  │
│ 设备同步         │  [用户图标] 登录 CyberNote          │
│ 存储空间         │  备忘录保存在此设备。登录同一账户后， │
│ 导入与备份       │  可在你的设备间同步。               │
│                  │  [登录]  [创建账户]                │
│                  │                                  │
│                  │  本地使用不需要账户。              │
└─────────────────────────────────────────────────────┘
```

登录后同一位置显示用户名称、账户标识和“退出账户”；下方是“同步此设备”开关、真实同步状态/待处理数/最近成功时间/立即同步，接着显示设备列表。本机标注“此设备”，其余端标注在线/离线以及同步连接状态；目录在线和同步完成分别描述。设备列表不展示内部URL、证书或运行协议。异常以文字＋重试操作呈现，不只变颜色；冲突给“查看冲突”入口，连接原有冲突界面。

## 手机

设置首页新增独立账户分组，进入全屏账户子页；固定返回/标题/完成，正文独立滚动。登录与创建账户按钮纵向或按可用宽度排列，最少44px触达；长账号标识折行，不横向撑开。使用平台同一浏览器授权流程，离开App授权时显示“正在等待登录”，提供取消；回到App后只由已验证回跳结果更新。

## 交互与状态

- 登录/创建账户打开系统浏览器中的Logto页面。客户端不复制密码表单、不保存密码；注册完成回到同一账户页并开始同账号设备同步。
- 授权期间显示等待提示、取消按钮，防重复提交。取消后迟到回跳无效；错误可重试，本地笔记仍可访问。
- 首次开启说明本地数据将与该账户设备合并；退出确认说明保留本机笔记并停止账户同步。资料库已属另一账户时显示明确冲突，不能悄悄合并。
- 同步暂停后仍保持已登录，停止自动传输；立即同步在已启用时触发真实请求。无其他设备时提示“在另一台设备登录同一账户，即可开始同步”，不显示伪进度。
- 启动恢复遇到网络错误时显示“重试连接”，仅在用户明确点击后用已保留授权恢复；不因此打开登录页或撤销授权。恢复成功若原来暂停则仍暂停，不能以“重试”偷偷开启合并。明确的认证拒绝才显示“重新登录”；无效响应、配置、存储和资料库归属错误保留各自说明，不统一视为登录失效。状态轮询只读，不暗中反复发起恢复。
- 使用现有偏好面板的焦点约束、Escape/返回、浅深主题、字号与桌面28px/手机44px全局控件规则；新CSS限定在账户区域，不覆盖编辑器或既有同步样式。

颜色参考来自既有CSS变量：纸面#ffffff、分组#f2f2f7、主字#1c1c1e、次字#8e8e93、选择#fff1c8、动作黄#e6a700。生产实现优先引用既有变量以正确跟随深色模式，不引入独立字体包或装饰性动画。
