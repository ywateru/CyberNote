文件夹页背景近 #f2f2f7，分组白色圆角卡片，黄色细线图标，标题大号粗体左对齐，搜索浅灰圆角。编辑页白底，顶部黄色操作，正文左对齐，未编辑底部工具栏；编辑时附加工具栏贴住键盘顶部。返回使用层级堆栈，左侧边缘右滑返回；左滑笔记露出操作，长按菜单弹在触点附近。Android Back 优先关闭菜单/键盘/编辑态再退页面。

## 录屏时间线（精确抽帧时刻；转场实际发生时刻仍需逐帧确认）

| 时间 | 观察 | 功能 |
|---|---|---|
| 0s | 快速备忘录画廊，置顶/今天/过去30天 | 卡片、分组、底部计数 |
| 2s | 文件夹页、搜索、分组、计数 | 文件夹导航 |
| 6s | 每日 TODO、紫色高亮、清单 | 富文本/已勾选/未勾选 |
| 8s | 编号列表、光标、键盘附加栏 | 编辑与输入法 |
| 12s/14s | 快速备忘录/文件夹页 | 返回 |
| 18–24s | 新笔记、格式面板、清单与表格入口 | 新建/编辑 |
| 20s | 底部格式面板，替代键盘 | 样式横排+标记+列表/缩进 |
| 26s | 附件浮动菜单 | 文件、录音、照片视频、拍照、扫描文稿/文本 |
| 28–34s | 新录音面板 | 波形、时长、暂停/恢复/继续、完成、前后15秒、转写空态 |
| 36s | 录音卡片嵌入笔记 | 音频附件与播放 |
| 42–46s | 绘画工具与笔迹 | 笔/颜色/橡皮、画布保存 |
| 50–58s | 清空/空笔记和附件菜单 | 空态、编辑、粘贴菜单 |

| 70–78s | 图文笔记、更多菜单 | 笔记内查找、移动、数学结果、最近笔记、横线与网格、附件视图、删除 |
| 80s | 文稿扫描相机，黑色预览与拍摄提示 | 扫描模式入口 |
| 86s | 横线与网格页，空白跨第一行，其下2列3行 | 空白+3种横线+3种网格（需逐图确认线宽） |
| 88–98s | 长笔记、搜索结果、含图片笔记、菜单 | 搜索、滚动、内容图片 |
| 102s | 无法锁定共享备忘录弹窗 | 不可锁定态（克隆无协作，不伪造共享） |
| 106s | 全部笔记画廊 | 置顶横向卡片、日期分组、底部计数 |
| 108–112s | 返回文件夹 | 导航转场 |

`frames-2s/frame-001.png` 对应0s，002对应2s，依此类推；该序列与 `contact-sheet-2s.jpg` 补充4秒序列漏掉的短暂页面。格式页是底部占据键盘区域的面板，不能在手机上沿用 Mac 的竖向悬浮菜单。纸张页观察到空白单独位于上方，其下六种线型，不能简化为六张含空白的网格卡片。

20s格式面板标题“格式”左上，关闭圆形×右上；下一行横排“标题 / 小标题 / 副标题 / 正文 / 等宽样式”，当前正文为黄色圆角选中。再下一行左侧B/I/U/删除线灰底分组，右侧高亮笔与颜色圆点灰底分组；最后一行是项目符号、短划线、编号分组与缩进分组，最右独立引用入口。底部留系统手势区。文字命名和顺序已有原帧直接证据，不能替换为“大标题”等其他标签。

该帧正文直接接格式面板，面板上方没有额外一排“格式/清单/表格/附件/绘画/收起键盘”的键盘附加栏。附加栏只在对应键盘编辑状态显示；格式面板打开时不能重复占一排。此结构来自原帧可见内容，不依赖推断原始设备DPR。

86s纸张页原帧顺序如下。注意是按行排列，不能改为左列全横线、右列全网格：

```text
取消               横线与网格
      更改此备忘录中手写输入的横线或网格样式。

  [ 空白：金边选中，无勾号 ]

  [ 密横线 ]      [ 中横线 ]
  [ 疏横线 ]      [ 密网格 ]
  [ 中网格 ]      [ 疏网格 ]
```

原224×480px画面空白卡片左上约(25,115)、大小约75×61px，下面三行约在y201/287/372，右列x125。面板顶部约y28，标题中心与左侧取消；背景近淡灰紫。尺寸仅用于该压缩帧的比例校准，不当作已知设备pt。网格/横线是给手写区域的纸张样式；实际作用范围还须通过绘画状态比较，不能仅选择后看到设置图标就判通过。

手机纸张选择页须在键盘隐藏时完整显示七项，底层编辑器在浮层期间不能重新唤起键盘。项目返回契约：进入时保存当前笔记及选区；选择、取消、系统Back、Escape或遮罩关闭后，恢复同一笔记的选区与可编辑状态，键盘保持隐藏，用户再次触正文继续编辑。切换笔记使旧选区目标失效。这是为跨平台入口明确的实现契约，未把录屏未捕获的关闭触点标为原版实采。验收使用真实系统键盘和原生触摸，不以额外按Back绕过遮挡后能选中作为入口通过。

纸张预览有限测量见[离线几何校准](../research/mobile-paper-calibration/analysis.md)（d22a393），原始坐标/线数/输入SHA在同目录measurements.json。以390宽等比换算的起点：正常卡片约128.8×104.5，左右外留白43.5、行列间距约45.3，图案左右内边约12.2；横线分别7/3/2条，完整网格分别8×6、4×3、2×2格。疏网格预览单格并非正方形；选择器须有独立内嵌图案层，不能改变真实绘画纸张步长。源DPR未知、边界约±1–2源像素，390不是恢复出的设备逻辑宽度；recommended.css为研究草案，未接入也未判像素通过。接入须保留既有滚动、七项可达、键盘隐藏、选择/取消/Back与选区恢复。

上述固定图案的独立透明SVG已于1ae3258完成，位于`assets/mobile-paper-previews/`；仅包含单色图案，适合CSS alpha mask，线宽仍为工程起点。[离线渲染与计数检查](../research/mobile-paper-calibration/preview-assets/README.md)通过，不代表已接入主应用或WebView像素通过。

补充导航抽样：`references/mobile/navigation-106-110/contact-sheet.jpg`按原始帧n=3180..3297、每3帧取一帧、8列5行；对应106.0..109.9秒、0.1秒间隔。该段返回时前景列表向右退出，后面的文件夹页从左侧较小位移进入，顶部标题/按钮也在转场；其后文件夹页纵向滚动时大标题收至导航栏中心。只可据此确认方向和大致顺序，0.1秒采样不足以精确拟合动画曲线。后续逐帧测量应读原视频30fps，不把采样间隔当动画时长。

18.5–23.5秒的加密抽样确认：键盘→格式面板→键盘，之后有清单与表格操作；录屏没有明确触点，不能证明格式右上X是否为触发动作。实现策略明确为X回键盘继续编辑，Android Back先关闭格式面板且保持键盘隐藏；这项是当前跨平台行为决定，不能标为原版X动作已实采。验收需明确区分关闭按钮与系统Back。

## 验收与缺口

必须在模拟器安装真正 APK 后截图，内容区按比例与参考帧比对，单独报告状态栏、键盘、系统分享面板的差异。动画对齐用录屏逐帧标注时长/曲线，不凭感觉宣称一致。当前录屏有压缩与低分辨率，精确字形/线宽/色值仍为未知；现有帧可验布局、相对位置、入口与流程。
