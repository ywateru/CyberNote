## 页面结构

```text
文件夹                 笔记列表                  编辑器
┌──────────────────┐   ┌──────────────────┐     ┌──────────────────┐
│            编辑  │   │‹ 文件夹       …  │     │‹ 文件夹 ↶ ↷ 分享 … 完成│
│文件夹            │   │备忘录            │     │       日期       │
│[⌕ 搜索         ]│   │[⌕ 搜索         ]│     │标题              │
│快速备忘录    n › │   │置顶              │     │正文/表格/绘画/附件│
│                  │   │标题  时间 摘要   │     │                  │
│在我的设备上      │   │今天              │     │                  │
│全部备忘录    n › │   │标题  时间 摘要   │     │                  │
│备忘录        n › │   │                  │     │☑   附件   绘画  新建│
│自建文件夹    n › │   │                  │     ├──────────────────┤
│最近删除      n › │   │                  │     │格式 ☑ 表格 附件 绘画×│
│新文件夹    新建  │   │    数量     新建 │     │ 系统键盘（出现时）│
└──────────────────┘   └──────────────────┘     └──────────────────┘
```

文件夹页背景近 #f2f2f7，分组白色圆角卡片，黄色细线图标，标题大号粗体左对齐，搜索浅灰圆角。编辑页白底，顶部黄色操作，正文左对齐，未编辑底部工具栏；编辑时附加工具栏贴住键盘顶部。返回使用层级堆栈，左侧边缘右滑返回；左滑笔记露出操作，长按菜单弹在触点附近。Android Back 优先关闭菜单/键盘/编辑态再退页面。

## 录屏时间线（抽帧观察，时刻为近似）

| 时间 | 观察 | 功能 |
|---|---|---|
| 0s | 文件夹页、搜索、分组、计数 | 文件夹导航 |
| 4s | 每日 TODO、紫色高亮、清单 | 富文本/已勾选/未勾选 |
| 8s | 编号列表、光标、键盘附加栏 | 编辑与输入法 |
| 12s | 文件夹页 | 返回 |
| 16–24s | 新笔记，清单与表格入口 | 新建/编辑 |
| 24s | 附件浮动菜单 | 文件、录音、照片视频、拍照、扫描文稿/文本 |
| 28–32s | 新录音面板 | 波形、时长、暂停/恢复、完成、前后15秒、转写空态 |
| 36s | 录音卡片嵌入笔记 | 音频附件与播放 |
| 40–44s | 绘画工具与笔迹 | 笔/颜色/橡皮、画布保存 |
| 48–56s | 清空/空笔记和附件菜单 | 空态、编辑 |
| 60–64s | 文件夹→搜索建议 | 类型过滤 |
| 68–80s | 图文笔记、更多菜单 | 笔记内查找、移动、数学结果、最近笔记、横线与网格、附件视图、删除 |
| 84s | 横线与网格页，2列3行 | 空白+3种横线+2种网格 |
| 88–96s | 搜索结果、图文长笔记 | 搜索、滚动、内容图片 |
| 100s | 无法锁定共享备忘录弹窗 | 不可锁定态（克隆无协作，不伪造共享） |
| 104s | 全部笔记画廊 | 置顶横向卡片、日期分组、底部计数 |
| 108–112s | 返回文件夹 | 导航转场 |

## 验收与缺口

必须在模拟器安装真正 APK 后截图，内容区按比例与参考帧比对，单独报告状态栏、键盘、系统分享面板的差异。动画对齐用录屏逐帧标注时长/曲线，不凭感觉宣称一致。当前录屏有压缩与低分辨率，精确字形/线宽/色值仍为未知；现有帧可验布局、相对位置、入口与流程。
