# CyberNote 启动加载

2026-11-07 实现于当前源码，未重新生成 macOS / Android 安装包。

首屏直接显示现有 SVG Logo，保留方形双眼。金色细线沿六边形轮廓匀速游走，双眼边缘轻微呼吸，周期 2.8 秒。Logo 下显示 CyberNote 与“正在打开备忘录…”。浅色背景为 #f7f7f9，深色背景为 #1c1c1e。桌面 Logo 为 104px，移动端为 88px。

## 启动与交接

- HTML 已包含加载画面，CSS 和独立恢复脚本在应用入口之前加载，覆盖 React 与主脚本初始化时间。
- 初次可信工作区读取完成后，恢复选中文件夹和备忘录、准备可见编辑器；macOS 再绑定原生工具栏，避免先用空工作区显示工具栏。
- 主界面提交完成后等待两个绘制帧，再用 220ms 淡出交接；没有人为增加最短等待时间，也没有模拟进度百分比。
- 加载期间主界面根节点保持 inert，屏幕阅读器只读取加载状态；交接完成后恢复主界面交互和可访问性。
- 此画面只创建一次；切换备忘录、同步、打开设置不重建它。

## 外观与恢复

外观默认跟随系统；本地仅缓存最近一次成功读取的主题偏好，供下次首屏使用，不缓存笔记内容。启用“减少动态效果”时停止循环动画并立即完成交接。

工作区初次读取失败、应用入口资源加载失败或启动期间发生未捕获错误，均停止动画并提供“重新加载”。超过 15 秒仍在加载时显示耗时提示和重新加载入口，后续正常加载成功仍可继续进入主界面。

## evolve114 外观首屏

head 在应用入口之前加载注册色板生成的 `src/themes/tokens.css`，启动表面直接使用 `--paper/--ink/--secondary/--accent`，不再有一套独立明暗色值。`public/startup.js` 独立校验三字段 AppearanceV2 缓存，设置 `data-theme-id` / `data-theme` / `data-scheme` 和兼容 `.dark`；跟随系统时订阅 media 变化。入口失败仍显示相同主题的重载入口，root 保持 inert。

缓存键 `cybernote.startup-appearance-v2` 只保存已确认外观，无正文/账号资料；仅无新缓存时兼容旧明暗缓存。非法缓存不会破坏启动，回退 Classic/system。App 等 workspace 权威设置加载完成后校正缓存；设置保存失败不提前应用或缓存。原生安装包冷启动的实际色块闪变在 116 验收，浏览器阻断入口的恢复截图只证明 Web shell。
