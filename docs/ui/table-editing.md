# 表格编辑

2026-11-09。补充用户明确要求，取代旧“先选中再点箭头”的菜单交互。

## 结构

```text
           [···] ← 点击一次：选中这一列 + 打开列菜单
         ┌───────┬───────┐    ┌─────────────────┐
 [⋮] →   │ 单元格│ 单元格│    │在左侧添加列     │
         ├───────┼───────┤    │在右侧添加列     │
         │ 单元格│ 单元格│    │删除所选列       │
         └───────┴───────┘    └─────────────────┘
```

- 点击行/列省略号即使用真实 CellSelection 选中并显示增强边框，同时打开统一 MenuSurface。下拉箭头可以保留为当前选区的再展开入口，不再要求第二次点击。
- 鼠标仅移动或悬停不能创建/扩展 CellSelection，不能将相邻表格或整片正文当成按钮显示高亮。高亮仅覆盖当前实际选中的单元格；行列操作不得影响其他表格。
- 左键释放、窗口失焦或指针取消后，旧表格拖动不得继续处理无按键的移动；丢失 mouseup 的受控复现与修复见 TABLE95H。只终止失效拖动的生命周期，保留合法跨格拖选、Shift选择和列宽调整，不修改选区视觉来掩盖状态问题。
- 外部点击、Escape、切换表格、滚动、字号、合并单元格和只读边界沿用既有契约。菜单开启不丢失原目标，禁止对过时 tablePos 执行操作。菜单键盘可导航。

## 文本与表格往返

- 表格转文本沿用现有契约：格内 LF、列 Tab、行 LF（含末行 LF），保留末空格，选中整个转换块，单次 Undo。
- 新增“将所选文字转换为表格”，使用用户当前文本选区；按 Tab 切列、按段落/行切行，转换块末尾的分隔 LF 不额外生成一行。保留空格/空单元格；不等长行用空单元格补齐，不丢弃文字。选区未涵盖的正文与其他表格不变。
- 为解决格内换行与行分隔同为 LF 的歧义，明确往返策略：普通文本转换按上述分隔解释；刚从表格转换出的完整块若仍保持可验证的原始内容/范围，可以复用来源结构以保留合并格与格内段落。若来源不再有效则按普通文本明确转换，不能用过时快照覆盖用户文字。
- 无文字选区、节点/单元格选区、跨越非文本附件/速绘/表格的选区、不可写或超出文档表格容量时不执行，并在能力投影/UI 中禁用或给出明确错误。转换是一个独立历史步骤，可单次撤销/重做，并走现有真实保存流程。
- 普通工具栏表格入口：已有表格中打开表格菜单；支持转换的文本选区显示转换入口；无选区保留插入 2×2。Web 与原生菜单必须均可达。
