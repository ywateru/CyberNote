# 统一菜单与附件操作

2026-11-08：备忘录菜单图标统一位于文字前方。Mac原生工具栏与正文菜单共用的构建器补齐置顶/取消置顶、锁定、查找、移动到、最近备忘录、数学结果、附件视图和删除等SF Symbols。移动到改为真实二级菜单，直接列出物理文件夹；当前文件夹勾选且禁用，智能文件夹和废纸篓不作为目的地。Web/移动端复用`MenuSubmenu`、`MenuSurface`和`MenuItem`，鼠标悬停、点击/触摸及左右方向键均可操作；子菜单在视口边缘避让。Mac两种菜单均支持嵌套条目，原生工具栏事件携带确切folderId，Rust只放行当前状态中启用的对应目标；前端仍执行原笔记及授权校验后移动。验证命令`pnpm test:note-move-menu`，证据`artifacts/note-move-menu/`。

2026-11-07 更新。交付及自动化、真实 Mac 验证证据见[统一菜单与浮动预览验证](../verification/cybernote-desktop/UNIFIED-MENUS.md)。

所有前端右键菜单和按钮展开菜单统一经过 `MenuSurface` / `MenuItem`：顶部菜单、溢出工具、备忘录、文件夹、附件、表格行列操作共用组件。格式面板保留其文字格式控件布局，不把控件面板降为普通菜单。原生格式颜色菜单及工具栏溢出菜单也使用同一个菜单条目构建器。

Mac 桌面通过平台适配器将同一组件的条目交给 AppKit。它与顶部工具栏共用 `notesUIMenuEntries`，使用同样的系统材质、字号、分隔线、选中标记和键盘交互，支持 SF Symbols。只有条目索引返回 React，原动作及授权检查仍在前端原流程执行。IPC 校验调用窗口、请求 UUID、坐标、条目数量与文本范围，不提供文件路径或存储操作。菜单关闭、目标变化或组件卸载时取消原生 tracking，旧返回值不能执行已经失效的动作。

浏览器及其他平台共用一套菜单材质、行高、字号、圆角、图标和交互。菜单挂在应用根部，避免表格、滚动容器或浮动预览遮挡；视口边缘自动避让。上下方向键、Home/End 移动焦点，Enter 触发，Escape 关闭并恢复焦点，Tab 或外部点击关闭。备忘录置顶、锁定和单独打开也使用普通菜单行，不再单独维护快捷网格。

附件菜单提供剪切、拷贝、粘贴、快速查看（图片）、播放/暂停（音视频）、保存附件、显示信息和从备忘录中移除；Mac 另提供共享、打开附件、在文件夹中显示。菜单项根据媒体、保存状态、写入权限和录音归属启用，未实现的功能不显示为可用菜单项。显示信息是轻量面板，可单独关闭。

拷贝、剪切和系统操作使用原始文件字节。剪切确认复制成功后才移除正文引用，保留底层文件供撤销使用。所有异步动作继续检查笔记、编辑器、附件引用、授权代际和原请求作用域，切换目标后不能作用到新笔记。附件菜单和信息面板不再通过全屏遮罩状态通知 App，因此不会隐藏或禁用顶部原生按钮。

原始导入内部记录不显示为用户附件；用户自行添加的同名文件仍为普通附件。
