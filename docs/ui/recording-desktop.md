桌面录音窗口不默认alwaysOnTop，不阻止主窗点击/键盘/编辑，不依赖主窗当前选中哪篇笔记。blur、普通visibility hidden、最小化、切换应用/笔记均不主动暂停或销毁真实采集。录音窗口关闭时仍沿“真实收尾→原笔记ACK→关闭”而非隐藏丢弃。主窗在其拥有的录音活跃时普通关闭可隐藏保活原编辑器/保存队列，录音窗口继续；普通主窗重显保持同一owner。整应用明确退出必须先完成所有录音及原正文保存，失败保留窗口/录音并终止退出；强杀/崩溃不承诺恢复内存音频。此处关闭规则覆盖早期“不扩张整体退出”的旧工程范围。

原笔记A的临时卡与游标映射仅投影会话；用户可继续编辑A、切B工作。源EditorA作为同owner稳定挂载，真实本地事务映射插入bookmark，最终在A最新正文中插入一次并经原SaveQueue/Rust ACK。其他B正文/选区/焦点不被强行切回。不能简单删除旧目标版本检查或直接写旧快照；录音专用校验须证明原note/owner/授权/窗口incarnation一致、最新可信A正文与待存队列一致。外部更改/真正撤权/锁定/删除/源editor销毁导致无法安全映射时，子窗保留同File显示失败，绝不写到当前B或覆盖A。

窗口间仅定向、带不可猜测session与operation的控制/状态/提交协议；捕获和File由录音窗持有，后端附件operation始终归原owner窗，原owner确认实际A正文ACK后才向子窗回成功。重试必须复用原owner缓存的同一File/operation，不重复解码为新File或重复插入；回执丢失/重复请求可查询同提交结果。事件到达、stop或store完成不等于正文ACK。若owner非正常失去存活，录音窗明确错误并保留File，不暗中冒认新窗口身份。

新窗口label精确为`recording-<标准小写UUID>`，URL为应用本地recording专用入口；新窄capability只授必要窗口/事件和麦克风预检，不能泛用note-*伪装。初始建议宽320、最低280 CSS px，高600、可调整大小；这是工程起点，内部视觉继续以原图比例校准。

## 定位与波形

试听计时由实际媒体事件确认；暂停播放仍保留最近实际位置，不能跳回活动录制总时间。真实未就绪时保留活动时间并给出状态。±15和绝对seek复用同一媒体可定位范围与seeked确认；拖动不会把UI预测值当成实际到达。鼠标/触摸拖动及键盘左右、Home/End对应真实seek，忙碌和失败不伪装成功。首次回放或播放结束后再次播放从头；当前播放的结束事实来自media ended。

历史波形必须来自本次实际onLevel采样，时间位置以活动时钟采样对应；不把最后90个值伸展为全部音频，也不通过随机波形掩盖静音。长录音可按时间桶聚合真实峰值限制内存；游标固定中轴并移动内容，刻度来自录音/播放时间。波形的时间轴表达不作为编码时长来源。
