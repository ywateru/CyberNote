## 暂停/关闭自动保存64（保存语义沿用，呈现以66为准）

用户反馈Mac录音中关闭后无法保存，要求“暂停或者关闭录音窗口，自动保存”。本节覆盖下方早期“暂停只试听/仅完成时提交”的规则，手机原现场不操作。暂停自动发布完整可播放累计音频及原A正文，确认后窗口保留且可继续；后续暂停继续累计，用户只看到同一张逻辑录音卡。关闭（右栏×/完成、右栏内Escape、主窗关闭及明确退出）保存最新音频和原A正文，准确final确认才销毁；失败保留窗口与字节供重试。

```text
录制 → 暂停/封存完整分段 → 累计合法音频 → 自动保存中 → 已保存暂停
  ↑                                                    │
  └──────────────── 同会话继续新分段 ───────────────────┘
有音频状态 → 关闭意图 → 排空/完成最新保存 → final ACK → 关闭
                                    └失败→保留窗口和音频，可重试
```

桌面采用完整分段生成有界累计WAV，不把非终结requestData前缀当可靠媒体。当前工程格式为24kHz单声道16bit PCM、100MiB含头（约36分24秒），并非原版压缩编码或无限时长；保存中可短暂禁用录音继续/试听，Notes其他操作仍可用，Close必须记录并随后执行。每次是不可变版本，复用附件journal；首次A映射书签插入，后续原位替换前一确认卡，保留最新A正文、选区和B操作。旧版在被替换前query确认committed，保留供Undo/历史引用；内部物理ID随版本变化，逻辑录音与开始日期不变。多版本增加本地及归档空间，错误明确不截断。checkpoint ACK保留会话，final ACK才允许关闭；原节点消失或真实权限/归属失效须失败保留，不能写当前B或重插。见[任务64](../plan/tasks/app-mac-recording-autosave64.md)与[逻辑分析](../plan/analysis/mac-recording-autosave64.md)。源码/受控验证不能替代真实麦克风与完整像素验收。

## 授权诊断63（内部验证，不增加产品界面）

研究61表明旧Start失败只能定位在AV授权预检，尚不能区分系统completion未到、主队列未处理或桥接交付未结算。新增默认关闭的进程环境诊断，固定事件和有界预算，仅输出无内容request ID、单调时间、stage/code、公开status/Boolean等标量；组件不自行落文件、不联网、不含音频、笔记或裸指针。受控测试可保存合成事件作为验证证据。Rust与ObjC共用request ID，分别记录OS completion进入（主线程派发之前）和main处理，以便后续正常验收判读。关闭开关不输出诊断，不改变授权、截止或生命周期。

```text
明确Start → Rust dispatch → native/main/window → AV status → request-issued
                                                     │
                         OS completion-entry（任意线程）
                                      ↓ dispatch main
                         main completion → pending clear
                                      ↓
                         Rust receive → window revalidate → JS settle
```

30秒native截止、两段35秒Rust等候及Session45秒截止保持。timeout/close只交付旧结果，不清仍在系统等待的pending或释放callback context；迟到completion只清原pending、不复活Session。JS错误保留code及可选stage/request ID，UI沿用既有message；busy/timeout仍各自独立，不推断为denied。诊断源码/伪OS检查不代表真实麦克风请求成功，当前包和手机现场保持。具体范围见[任务63](../plan/tasks/app-mac-recording-diagnostics63.md)。

诊断不能反向阻塞授权：main、OS completion及FFI仅非阻塞地尝试放入固定有界队列，由独立诊断writer处理输出；饱和有明确丢弃/截断标记。不得在producer同步写stderr、等待输出锁或join writer。writer卡住、stderr不读取也不能阻止completion进入主队列、超时交付或context释放。此诊断线程不改变原授权操作的main线程约束。

## 统一主窗口右侧栏66（2026-11-05最新要求）

用户明确要求“彻底重构一下录音这部分，不使用浮动窗口，而是都统一使用侧边窗口的方式”。本节替代50/55独立窗口、双模式、隐藏主窗保活及远程投影合同；旧实现与证据仅作历史记录。桌面只有主窗口右侧非模态录音栏，占据正常布局空间，无浮窗、切换入口或隐藏录音子WebView。手机保持既有sheet和现场。

```text
主窗口：工具栏、搜索、文件夹、列表、正文均可继续操作
┌────────┬────────┬─────────────────┬─────────────────┐
│ 文件夹 │ 列表    │ 当前正文A或B     │ 新录音        ×  │
│ 可导航 │ 可切换  │ A中的进行中卡    │ 日期 / 累计时长   │
│        │ 可搜索  │ 切B后仍保存到A   │ 真实波形 / 黄游标 │
│        │        │ 可编辑/撤销重做  │ 计时 / ±15 / 播放│
│        │        │                 │ 暂停或继续 / ✓   │
└────────┴────────┴─────────────────┴─────────────────┘
```

每个实际文档owner窗口至多一个活动录音会话；多个独立文档窗口仍各有自己的owner，不增加全进程录音锁。录音控制器在App稳定根布局持有唯一Session、MediaStream、累计PCM和不可变待存File；切笔记、文件夹、搜索、编辑器停车不卸载会话，失焦/最小化/切换应用不主动暂停。录音只绑定打开时的原A、原Editor、书签及授权身份，用户可同时编辑A/B和操作其他Notes功能。后续录音入口恢复当前右栏，不重复采集或更换归属；原A不可写时保留音频并显示失败，不迁移到当前B。

同renderer直接提交RecordingRevision，去掉child/relay/base64跨窗转换（附件Rust桥必要字节传输不变）。保留真实SaveQueue、store、正文ACK、journal query committed和65真实Host布局提交等待；等待之后重新核对原A、授权、版本、最新正文及唯一前版节点。不得伪造remote身份或删安全谓词。实时卡只投影会话；checkpoint实际插入/更新一张逻辑卡，final后撤装饰显示持久卡。

暂停封存完整分段并自动保存，右栏保留以继续；×/完成停止试听或采集，排空保存，准确final与本地生命周期清理均成功后收起。忙碌时的关闭意图必须排队且重复关闭共用同一等待结果。错误保留右栏、同一File/operation和重试入口。若正文已持久而native登记清理失败，只重试清理，不重跑已确认版本、不重复插卡。Escape只在右栏自己的焦点上下文处理，不能在正文、搜索、菜单取消时全局结束录音。

主窗口红色关闭/Cmd+W先完成同一可等待final流程、正文/偏好flush，成功才销毁；失败取消关闭并保留可用右栏。主窗不再显示浮窗后隐藏。Cmd+Q及原生退出仍须原生本地会话登记和准确owner incarnation屏障：登记在采集前完成，未最终保存/安全无音频终态不能注销。不能因child registry为空直接放行。退出参与正文窗口在首次等待前封新写入，保存成功后准确ACK；失败/超时取消退出并恢复合法编辑权限；迟到保存或清理成功不得重放过期quit ID或自动再次退出。保存重试不可被退出的暂时编辑封锁误判为真实撤权，真正授权变化仍拒绝。原生登记身份、窗口归属、存储权限均不放宽。

非正常销毁不能冒称保存成功或自动替换owner；强杀/崩溃的内存音频恢复不在本次承诺。原Mac18未存3秒现场继续保留，不退出/重载/复制；手机原13秒现场不操作。详见[任务66](../plan/tasks/app-mac-recording-sidebar66.md)。

## 定位与波形

试听计时由实际媒体事件确认；暂停播放仍保留最近实际位置，不能跳回活动录制总时间。真实未就绪时保留活动时间并给出状态。±15和绝对seek复用同一媒体可定位范围与seeked确认；拖动不会把UI预测值当成实际到达。鼠标/触摸拖动及键盘左右、Home/End对应真实seek，忙碌和失败不伪装成功。首次回放或播放结束后再次播放从头；当前播放的结束事实来自media ended。

历史波形必须来自本次实际onLevel采样，时间位置以活动时钟采样对应；不把最后90个值伸展为全部音频，也不通过随机波形掩盖静音。长录音可按时间桶聚合真实峰值限制内存；游标固定中轴并移动内容，刻度来自录音/播放时间。波形的时间轴表达不作为编码时长来源。

## 手机与范围

手机继续原帧sheet三态和安全区/底部行，不移用桌面右栏。共享相同真实采集与回放控制，补拖动和实际位置保持。没有听写/转写入口、文本或网络调用。保存后卡片沿现有AudioPlayer与本地附件协议，本轮不改数据库/归档版本、MIME、权限或包标识。

保存卡音频资源补充56：本地附件base64返回值按原MIME与字节建立Blob object URL，避免Mac WebKit拒绝data音频URL；换附件、卸载或迟到结果须清理资源，先停播清理控制器再revoke。失败仍可见且可重试，不扩大CSP、不改编码、不伪造时长。真实Mac15 SecurityOrigin拒绝及有限修复验收见任务56；最终可播结论以准确新包重开验收为准。

精确字体、背景、波形压缩比例、菜单、动画与全部窗口尺寸仍需实际原版对照；工程验收与整体像素一致分开。原版现有用户录音不操作、不终止、不删除。
