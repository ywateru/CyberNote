# 交互状态矩阵

本表为需验证的行为契约。除明确引用截图或视频帧的行为外，均为待取证/待实现，不能将列出的预期等同已通过。

| 状态/入口 | 动作 | UI 结果 | 持久/平台结果 |
|---|---|---|---|
| 文件夹页 | 新建/输入名称/确认 | 新行，焦点与选择跟随原版 | 父级/名称落库，重启恢复 |
| 文件夹层级 | 移到自身子级 | 拒绝，不破坏树 | 数据不改变 |
| 空文件夹 | 新建笔记 | 编辑器获得焦点 | 一条新笔记，不重复创建 |
| 笔记普通段落 | 输入中文组合 | 候选词期间光标稳定 | composition完成后完整保存 |
| 自动保存中 | 快速切到另一笔记 | 编辑器切换，前一内容保留 | 旧请求不覆盖新内容，不写错noteId |
| 编辑普通文本 | 开格式菜单/切样式 | 当前段/选区变化 | 结构化文档与标记持久化 |
| 清单 | 回车/空项回车 | 续项/退出清单 | 勾选状态和顺序持久化 |
| 已完成清单 | 取消勾选 | 恢复未完成 | 无文本丢失或多创建一项 |
| 表格 | Tab/末格Tab | 下一格/按原版增行 | 表格结构完整保存 |
| 笔记 | 置顶/取消置顶 | 移入/移出置顶组 | pinned持久化、计数不变 |
| 普通笔记 | 删除 | 从当前列表移除、最近删除出现 | deletedAt/originalFolderId保存 |
| 最近删除 | 恢复 | 原文件夹重新出现 | 原文件夹缺失时回默认 |
| 最近删除 | 永久删除/取消确认 | 数据保留 | 取消不修改 |
| 附件菜单 | 选文件后取消 | 回到笔记，光标不丢 | 不生成孤儿附件 |
| 本地图片/音频 | 插入/退出重启 | 预览/播放器仍可用 | 内容复制至受管目录，不依赖临时URI |
| 录音面板 | 暂停/继续/完成 | 计时、波形与按钮状态变化 | 真实音轨保存并可播放 |
| 录音无权限 | 开始 | 明确请求/拒绝反馈 | 不产生虚假录音卡片 |
| 绘画 | 换笔/颜色/撤销/完成 | 画布与历史一致 | 笔画保存，可重新编辑 |
| 更多菜单 | 横线与网格 | 手机选择页/应用纸张背景 | 每笔记设置持久化 |
| 搜索页 | 输入/清空/取消 | 结果/建议/原页面 | 不修改笔记正文 |
| 锁定笔记 | 错误密码 | 保持锁定、明确错误 | 密文不损坏 |
| 锁定笔记 | 正确密码/离开/重启 | 按会话策略显隐 | 不从预览/搜索泄露正文 |
| 手机编辑键盘出现 | Android Back | 先隐藏键盘 | 不退出应用或丢内容 |
| 手机菜单/面板 | Back/点外部 | 先关闭最上层 | 主导航不误跳 |
| 手机编辑器 | 左缘右滑 | 跟手返回上一级 | 未保存内容先入队 |
| Mac分栏 | 拖动分隔条/隐藏侧栏 | 内容重新布局 | 布局设置重启恢复 |
| Mac画廊 | 双击卡片 | 同一主窗口隐藏画廊并打开编辑器，保留侧栏；返回按钮回画廊 | 内容使用同一笔记数据，导航不创建副本 |
| Mac独立笔记窗 | 显式打开独立窗口 | 独立编辑窗 | 主窗与独立窗数据同步；入口仍须补证 |
| 亮暗模式 | 切换 | 内容/菜单/背景协调变化 | 用户设置持久化，system跟随系统 |

覆盖要求：同一功能至少测空内容、已有内容、取消、错误、重启五类边界中的适用项。对齐时关注动作前后的状态与顺序，不能用最后一张相似截图替代交互验收。
