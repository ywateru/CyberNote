# 手机智能文件夹：iOS 26 官方图片布局

状态：次级图片依据，2026-11-04。仅记录主任务保存的两张 Apple 官方中文支持图片中实际可见内容；来源网页与版本说明由主任务归档。本文已实际查看图片，不依据文件名推断页面，也不把静态图当操作录像。

用户原始 **224×480 录屏没有展示智能文件夹**。因此下述官方 iOS 26 图片可约束手机布局方向，不能取代该录屏或目标设备实机对照，不能据此宣称 Android 克隆像素或交互通过。共享查询/存储语义由共享契约负责。

以[Mac表单文档](smart-folders-macos.md)的保存记录为对照，仅比较各自已见部分：

| 部分 | Mac 已见 | 手机官方图片已见 |

## 官方文字补充与证据分级

已归档102288正文明确：名称后制作智能文件夹→选条件后勾号→再次勾号才创建；[官方文字复核](../research/mobile-smart-folder-official09.md)支持这条两阶段确认链。上面表格关于“静态图片不能证明动作”的限制继续成立，但不能把文字已给出的两个确认步骤也说成完全无依据。具体上层外观、×/Back取消及草稿恢复仍是工程约定，未做iPhone运行验证。
