# Agent 接入设置

2026-11-17，承接用户实际截图：测试入口隐藏、授权与配置的先后关系不清楚，页面顶部被嵌套滚动挤出。桌面设置承载本机 MCP；移动端仍仅显示支持范围说明。

布局使用现有备忘录设置的字体和主题令牌。经典浅色参考为纸面 `paper #ffffff`、分组 `grouped #f2f2f7`、正文 `ink #19191c`、次要文字 `secondary #666773`、选中 `selection #fff1cc`、分隔线 `line #d1d2da`；不在组件内固定颜色，八套明暗外观仍由主题提供。标题1.4em、分组标题1.05em、正文1em、辅助文字0.9em，沿用应用界面字号。

采用固定页头与单一滚动正文，左对齐。页头始终提供测试入口，正文按实际接入顺序安排；只对客户端授权使用边界容器，配置代码和机器标识默认折叠，减少初次接入的干扰。设计复核后取消重复卡片和摘要统计，保留一条明确的操作路径。

```text
Agent 接入                   [启动 MCP 测试程序]  ← 固定页头
让本机 Agent 访问你授权的备忘录。
──────────────────────────────────────────────
1  允许本机接入                       [开关]
   桌面应用需保持运行

2  授权客户端                     [创建授权]
   名称 / 状态 / 权限 / 目录 / 到期时间
   [查看接入配置] [撤销授权]   ▸ 授权详情

3  配置与连接
   客户端 [选择有效授权                    ▾]
   内置 MCP 已就绪（自动检查，无需填写路径）
   [复制 stdio JSON] [复制 TOML]
   ▸ 查看配置文本

▸ 近期操作（本次宿主内存）
▸ 接入诊断信息
```

测试按钮不受“查看接入配置”、开关状态或适配器就绪状态控制而消失。条件齐备时直接进入既有 MCP 控制台；否则打开标题为“MCP 测试程序”的准备弹窗，明确列出未完成条件，可选择有效授权，再进入控制台。未启用/无授权时指向设置正文的对应步骤，不自动开启接入、创建授权或执行二进制。

配置默认选择第一个未撤销、未过期的授权；用户明确选过失效授权时不自动替换。适配器由原生端从当前应用可执行文件同目录解析，检查为可执行的普通文件，前端不能选择或传入其他文件。配置自动使用包内路径，仅包含凭据引用；缺失时引导重新检查或安装完整应用。刷新保留有效选择；关闭接入、撤销/过期或宿主身份变化时关闭活动测试器并沿用原有进程回收流程。

验证使用命令构建、接入准备条件和真实生产事件回调的单元测试，以及已有 MCP 批量/取消/恢复测试；不执行 UI 自动化，排版、焦点与真机效果由用户验收。
