## 桌面与移动

桌面在工具栏下方居中展示设置面板，左侧五分类，右侧独立滚动内容。外壳最大 920 × 660px，受实际窗口约束。按图 2 将“设置”标题放在左侧分类栏顶部，右上角单独放置关闭入口。左栏 196px，内容左侧 36px、右侧 60px，使用浅灰侧栏、白色内容区和浅黄色选中态，遮罩采用浅色覆盖。外观为跟随系统、浅色、深色三张选择卡；两个字号各用五档分段控件及独立预览。分类和分段控件支持方向键、Home、End，关闭入口常驻。

移动端全屏展示分组设置首页，点击分类进入子页；子页固定返回、标题和完成。返回优先关闭同步确认、Apple 导入或存储详情，然后退到设置首页，最后退出设置。关闭按钮直接退出整个设置。

桌面卡片和分段控件使用 radiogroup / radio 语义、单一 Tab 停靠点和键盘选择；保存期间保留焦点并阻止重复提交。移动端仍使用其原有选择控件。界面字号使用既有五档比例。移动端控件至少 44px；编辑器字号只改变正文和正文预览。长内容在分类内滚动，支持窄屏和短屏。

## 顶部工具栏

消失的根因是原生 `toolbar.m` 在 `contentOverlay` 时主动隐藏按钮组、标题和计数并提前结束布局。本轮保留 overlay 的操作保护，只移除隐藏分支；按钮组、搜索、标题和计数保留原位置。设置期间按钮和搜索禁用，退出后恢复原状态。遮罩从工具栏下缘开始。

Web 后备主界面的三列在设置打开时设为 inert，工具栏保留显示，避免操作穿透。设置使用焦点约束，Escape 优先交给内层界面，再执行当前返回；退出后恢复可用入口焦点。

## 生命周期

- 同步首次访问才挂载，只在对应分类活动；离开后清除可见配对串及未提交输入，迟到响应不能恢复它们。
- 存储与备份使用同一保留实例、不同滚动区。切分类不丢失文件搜索、分页、滚动或在途结果。
- 存储首次访问才采样。备份分类不依赖采样成功，加载失败时仍可导入恢复。
- 权限代际变化仍清除旧存储快照，拒绝迟到结果；授权恢复后按需重新采样。
- 导入继续保留保存屏障及 prepare / commit 生命周期。活动录音期间继续禁用备份，错误、取消、成功按真实结果呈现。
- 设置保存失败在面板内提示。所有功能继续走原 handler，不新增账号、云服务或存储模型。

## 验证入口

`pnpm debug group preferences`，移动端加 `--mobile`。覆盖实际入口、五分类、保存及重新加载、字号、文件状态保留、备份在途、权限变化、焦点、原生保护投影、浅深和五档字号的布局。另执行同步、数据管理、存储与备份回归，以及 AppKit 可见性 / 禁用 / 几何 / IME 状态检查。浏览器使用隔离合成数据；不将其作为真实设备或 OS 权限验证。

## 构建标识（2026-11-09）

外观与字号页底部增加“版本信息”，两端使用同一数据对象，展示 CyberNote版本号、UTC构建时间、Git源码revision及完整产品输入SHA256。长指纹折行且可选择复制，不横向撑破390px界面。开发预览明确显示开发态与“未生成安装包”，不能用当前时间冒充安装包时间。原有五分类、焦点约束与即时设置保存保持不变。打包元数据与核验流程见[构建交付规格](../architecture/build-delivery.md)。

## 界面细节（DESIGN100A，2026-11-09）

外观与字号中新增默认折叠的“界面细节”，位于两组字号之后、版本信息之前。字段与范围以[双端设计规则](design-rules.md)为唯一来源；当前平台只显示自己的操作区域比例。展开内容在分类内滚动，含同一变量映射生成的即时示例、持久失败提示与只重置细节的入口。主题、字号和其他设置保留。

该基础阶段仅接设置/存储与示例；全局控件变量应用和父组件持久失败回滚须在DESIGN100整合，不以设置预览视为整体完成。模块与验证边界见[100A交付说明](../verification/design-settings100a.md)。

## evolve114 主题设置（已实现）

“外观与字号”现在分开选择主题（Classic / Paper / High Contrast）与明暗（跟随系统 / 浅色 / 深色）；三套主题均有明暗变体。桌面使用原有可键盘操作的 radio group，移动使用有标签的 select。只有确认保存后，选中项与实际 palette 一起更新；保存中阻止重入，失败显示错误并保留原值。桌面选择有勾选标识，选中不只依靠颜色。

AppearanceV2 是本地设备设置，沿现有备份保存；字号和界面细节继续独立。radiusScale 乘各组件基础值，菜单、画廊、按钮不再被同一圆角覆盖；圆形播放/录音保持圆形。macOS 系统菜单和工具栏仅支持系统明暗及既有尺寸投影，设置中明确说明不支持皮肤 palette / 自定义圆角。布局、密度和移动列表模式属于 115，未在 114 提供。
