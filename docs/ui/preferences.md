# 设置页

设置主区使用分隔列表。右侧显示当前分类和设置搜索。桌面保留原侧栏，手机使用设置首页和子页。同步、备份和更新的技术边界见[设置架构](../architecture/settings121.md)。

2026-11-07。按最新要求直接沿用 CyberNote 现有样式和真实功能重构；本轮不调用图片生成模型。取代旧“设置 / 数据”双标签界面。历史方案见 `docs/design/settings-redesign-20261107/`，实际界面以本规格和运行截图为准。

## 功能组织

| 分类 | 内容 |
| --- | --- |
| 外观与字号 | 系统 / 浅色 / 深色；界面和编辑器各自独立的极小、小、中、大、极大；独立预览、即时保存 |
| 备忘录 | 编辑日期 / 创建日期 / 标题排序；桌面列表或画廊；按日期分组；重新锁定所有已打开的锁定备忘录 |
| 账户与同步 | 登录、凭据存储、账户设备、同步冲突及 WebDAV / S3 / GitHub 同步 |
| Agent 接入 | 本机 MCP 接入、客户端授权与配置 |
| 存储空间 | 实际应用文件占用、分类、全部文件、搜索、分页、附件导出、数据位置和采样诊断 |
| 导入与备份 | 完整备份导出 / 合并导入；Mac 主窗口的 Apple 备忘录复制导入 |
| 关于 | 版本、更新检查和下载、更新偏好、发行及构建信息 |

桌面和手机的显示方式及密度分别保存。日期分组用于桌面列表。

## 控件选择规则

- 短小、固定且互斥的选项用 `PreferenceSegments`。例如登录方式、凭据存储、同步方向及服务、明暗、排序、密度、菜单间距、开启或关闭。通常为两到五项，需在支持的字号和语言下保持可读。桌面行左侧为标签，右侧为控件。手机可以把整组移到标签下方，触摸目标至少 44px。
- 标签长、项目多或由数据决定的选项用 `PreferenceSelect`。例如主题和版本列表。桌面用带选中标记的菜单，移动端用系统选择器。独立且可以同时勾选的多项用复选框，动作使用按钮。只读状态、当前设备和来源直接显示；高级配置和错误诊断才按需展开。
- 分段控件使用 `radiogroup` / `radio`，Tab 进入当前项，方向键和 Home / End 切换。搜索定位聚焦当前项。即存设置以保存结果为准，凭据切换、同步启用和安装按各自边界确认。
- 云同步表单在行下展开，按服务、凭据、加密口令、同步内容排列，低频项放入「高级」。取消丢弃草稿，预览只读草稿指定的目标，开启或保存才持久化。

## 账户与同步

先显示 CyberNote 账户状态和登录或退出操作。未登录时用分段控件选择应用内登录或系统浏览器；授权中直接显示实际使用的入口及取消／继续操作。桌面凭据存储是一行直接可见的分段设置，新安装默认本机加密文件，保留既有选择。切换仍需退出并确认。

登录后直接列出此设备的同步许可、最近传输与其他设备；设备名称放在确认说明中，方向只提供短标签。同步冲突和 WebDAV / S3 / GitHub 各自独立，自有云同步不需要登录 CyberNote。

## 桌面与移动

桌面在工具栏下方居中展示设置面板，左栏宽 196px，右侧独立滚动。设置标题位于左栏顶部，关闭入口位于右上角。两个字号各用五档分段控件及独立预览。

移动端全屏展示分组设置首页，点击分类进入子页；子页固定返回、标题和完成。返回优先关闭同步确认、Apple 导入或存储详情，然后退到设置首页，最后退出设置。关闭按钮直接退出整个设置。

界面字号使用既有五档比例。编辑器字号只改变正文和正文预览。长内容在分类内滚动，支持窄屏和短屏。侧栏和内容区共同使用当前主题的背景、卡片、边界、文字、强调色和明暗变体。

## 顶部工具栏

消失的根因是原生 `toolbar.m` 在 `contentOverlay` 时主动隐藏按钮组、标题和计数并提前结束布局。本轮保留 overlay 的操作保护，只移除隐藏分支；按钮组、搜索、标题和计数保留原位置。设置期间按钮和搜索禁用，退出后恢复原状态。遮罩从工具栏下缘开始。

Web 后备主界面的三列在设置打开时设为 inert，工具栏保留显示，避免操作穿透。设置使用焦点约束，Escape 优先交给内层界面，再执行当前返回；退出后恢复可用入口焦点。

## 生命周期

- 同步首次访问才挂载，只在对应分类活动；离开后清除可见配对串及未提交输入，迟到响应不能恢复它们。
- 存储与备份使用同一保留实例、不同滚动区。切分类不丢失文件搜索、分页、滚动或在途结果。
- 存储首次访问才采样。备份分类不依赖采样成功，加载失败时仍可导入恢复。
- 权限代际变化仍清除旧存储快照，拒绝迟到结果；授权恢复后按需重新采样。
- 导入继续保留保存屏障及 prepare / commit 生命周期。活动录音期间继续禁用备份，错误、取消、成功按真实结果呈现。
- 即存选项只在权威回执后改变选中值。保存时拦截重复提交，保留焦点、当前分类、滚动位置和已展开内容；错误在本页提示，不撑开面板。显式字号/密度变更可按预期重新排版。

## 验证入口

`pnpm debug group preferences`，移动端加 `--mobile`。覆盖实际入口、五分类、保存及重新加载、字号、文件状态保留、备份在途、权限变化、焦点、原生保护投影、浅深和五档字号的布局。另执行同步、数据管理、存储与备份回归，以及 AppKit 可见性 / 禁用 / 几何 / IME 状态检查。浏览器使用隔离合成数据；不将其作为真实设备或 OS 权限验证。

## 关于与更新

「关于」展示发行版本、UTC 构建时间、源码修订和可复制的源码指纹。开发构建明确标出开发预览。打包元数据见[构建交付规格](../architecture/build-delivery.md)。

手动或自动检查发现当前频道的较新版本后，设置工具栏显示更新徽标。点击徽标打开「关于」并开始下载。已下载的 macOS 更新可从徽标或「关于」发起原生安装确认。「关于」展示进度、版本说明和失败重试。徽标可隐藏三天，也可长期关闭。检查频率提供 30 分钟、1 小时、6 小时和 24 小时，保留旧安装已选的 15 分钟或 12 小时。平台能力及频道语义见[更新契约](../architecture/settings121.md#更新)。

## 界面细节（DESIGN100A，2026-11-09）

“界面细节”默认折叠，位于两组字号之后。字段与范围以[双端设计规则](design-rules.md)为唯一来源；当前平台只显示自己的操作区域比例。展开内容在分类内滚动，含同一变量映射生成的即时示例、持久失败提示与只重置细节的入口。

该基础阶段仅接设置/存储与示例；全局控件变量应用和父组件持久失败回滚须在DESIGN100整合，不以设置预览视为整体完成。模块与验证边界见[100A交付说明](../verification/design-settings100a.md)。

## evolve114 主题设置（已实现）

“外观与字号”现在分开选择主题（Classic / Paper / High Contrast）与明暗（跟随系统 / 浅色 / 深色）；三套主题均有明暗变体。桌面使用原有可键盘操作的 radio group，移动使用有标签的 select。只有确认保存后，选中项与实际 palette 一起更新；保存中阻止重入，失败显示错误并保留原值。桌面选择有勾选标识，选中不只依靠颜色。

AppearanceV2 是本地设备设置，沿现有备份保存；字号和界面细节继续独立。radiusScale 乘各组件基础值，菜单、画廊、按钮不再被同一圆角覆盖；圆形播放/录音保持圆形。macOS 系统菜单和工具栏仅支持系统明暗及既有尺寸投影，设置中明确说明不支持皮肤 palette / 自定义圆角。布局、密度和移动列表模式属于 115，未在 114 提供。
