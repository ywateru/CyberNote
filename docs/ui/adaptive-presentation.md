## 桌面主工作区

```text
┌────────────────────────────────────────────────────────────────────┐
│ 原生/应用工具栏：目录显隐  新建  搜索  集合视图  格式/附件  更多     │
├───────────────┬─────────────────┬──────────────────────────────────┤
│ 文件夹 / 标签 │ 搜索与当前范围  │ 笔记标题/日期/保存状态             │
│ 智能文件夹    │ 列表 或 画廊    │ 正文（同一个 Editor）              │
│               │ 选中与置顶      │                                    │
│ 同步摘要      │ 空态/错误重试   │          [录音时：独立 owner 右栏] │
└───────────────┴─────────────────┴──────────────────────────────────┘
```

三栏/两栏属于导航布局；列表/画廊属于集合视图。附件画廊仍是独立路由，不当作第三个笔记集合 view。缩窄时先减少非必要操作、再依据可用空间折叠导航，不能通过整体缩小文字/命中区塞入三栏。

桌面内容预算以正文最小宽度 `320px`、目录最小宽度 `220px`、列表最小宽度 `280px` 为基线：三栏最低 `820px`，不足时解析为两栏；两栏内容最低 `600px`，不足时解析为专注。Web 主窗仍保留 `<700px` 的移动交互身份，因此默认三栏偏好在 700px 进入两栏、699px 进入手机流程是兼容边界，不是新的内容预算。栏宽、字号、密度和录音栏占用必须一起计算；压缩窗口只影响有效宽度，不回写用户偏好。

默认三栏保持已有体验。两栏为集合+正文；目录从按钮抽屉打开，关闭后焦点回触发器。专注模式仅正文+最小工具栏，保留返回来源和搜索位置，退出恢复原导航布局。录音右栏是非模态业务表面，空间不足提供明确的收起/恢复入口，不能切模式就停止录音或改 owner。

| 输入 | 建议行为 |
| --- | --- |
| 单击列表 | 打开对应正文；保留原保存/搜索停车规则 |
| 单击桌面画廊卡片 | 选中；Enter或双击打开；空格如沿用 button 激活语义需统一打开，不能只选中无反馈 |
| 方向键/Tab | 集合中可达且有明确焦点环；菜单打开后焦点移入菜单，关闭回触发器 |
| 分栏方向键 | 每步8px，Shift每步24px；Home/End到当前有效边界；aria-valuemin/max/now匹配有效值 |
| Escape | 先关闭最内层菜单/对话，再按既有路由处理；不把焦点模式退出与所有模态关闭混为一条逻辑 |
| 切换主题/密度/列表画廊 | 确认设置成功后应用；保持 noteId、正文、滚动与 Undo，不提前清空编辑状态 |

保存状态只显示真实状态：“正在保存 / 已保存到本机 / 保存失败，重试”。本地保存与设备同步是两层事实：正文不必为同步进行阻塞编辑；同步错误提供账户/设备入口，不在每个卡片持续刷屏。agent 更改可显示轻量“由某客户端更新”与操作记录入口；首版不承诺尚无版本历史支撑的“一键撤销外部写入”。

## 移动首页与集合

```text
┌─────────────────────────────┐
│ [‹ 笔记] 当前目录名      ⋯  │ ← 根目录为文件夹入口；目录页为返回
│ [搜索当前范围              ]│
│ [全部] [置顶] [标签]        │ ← 筛选仅显示已支持能力
├─────────────┬───────────────┤
│ 标题/摘要   │ 标题/摘要     │
│ 缩略图/日期 │ 缩略图/日期   │ ← 画廊；列表模式为单列
├─────────────┼───────────────┤
│             │               │
│                         [+] │ ← 安全区上方，一键创建并请求键盘
└─────────────────────────────┘
```

页头规则：根目录只显示一个文件夹入口；进入目录后返回入口显示“笔记”并保留真实命中区；标题占据中间可伸缩列，长名称允许两行换行；存在查询或筛选时标题显示“搜索结果”；右侧只有一个“显示选项”入口，视图和排序在该菜单内完成。设置入口放在目录页底部的 `.folder-footer`，不再与集合页头争夺横向空间。快速首页的完整规则见 [Android 快速首页](android-quick-home.md)。

保留“打开即画廊”和新建直接输入作为默认；新增移动列表偏好，和桌面集合视图独立。小屏或极大字号可降为单列，但不偷偷改持久默认。卡片标题最多两行，摘要最多三行，日期贴底，更多入口固定在右上并保留 44px 命中区；同排卡片等高，缩略图有固定比例且延迟加载，长标题和无附件时不跳动。

双列不沿用174px三按钮侧滑。首版建议双列以长按菜单和显式更多入口提供置顶/移动/删除；单列可保留侧滑，显示完整动作并有撤销软删除入口。无障碍用户无需长按即可找到相同行为。

长按计时器在 touch/pointer cancel、滚动阈值、导航或组件卸载时清理。点击空白与卡片动作分清 owner，避免“松手晚弹菜单”。边缘返回需要与纵向滚动、正文选字、表格横向滚动、速绘缩放仲裁；未经验证不全屏拦截所有横滑。增加跟手反馈时遵守 reduced-motion。

## 移动正文与输入

```text
┌─────────────────────────────┐
│ < 来源          附件/录音 ⋯ │
│ 日期 · 本机保存状态         │
│ 标题                        │
│ 正文                        │
│                             │
├─────────────────────────────┤
│ 格式  清单  表格  附件  绘画│ ← 与键盘/格式面板协调
├─────────────────────────────┤
│ 系统 IME 或 格式面板        │ ← 切换不重建 Editor
└─────────────────────────────┘
```

- 进入已有笔记浏览态；新建成功且目标仍有效才聚焦并弹键盘。返回保留原集合/搜索筛选/滚动位置。
- 格式面板保持契约不变：选字、长按正文不能自动关闭；手动关闭后按 EditorSession 恢复正文焦点与键盘。
- Back 继续由 Navigation 分层处理：最内层弹层、格式/绘画/录音处理、IME、路由等遵循现有明示顺序；先核对实际 keyboard insets，不依赖“历史最高高度−当前高度”判定旋转后的键盘。
- 原生 Android 横屏/分屏保持移动输入与触摸语义；可用宽高改变布局，不改变音频卡控件身份和 owner。
- 操作栏避开 safe area 和 IME，触达≥44px。极大字体允许菜单滚动/换行，不能覆盖最后一段或让确认按钮不可见。
- 保存失败保留当前全文、选区和附件，错误入口就近可达；重试和离开确认使用真实保存结果。

## 设置：外观与展现 / Agent 接入

```text
桌面设置                         移动设置
┌────────────┬────────────────┐  ┌──────────────────────────┐
│外观与展现  │主题卡片        │  │设置 > 外观与展现         │
│备忘录      │Classic Paper HC│  │主题 / 明暗               │
│设备同步    │明暗：系统/浅/深│  │首页：画廊/列表           │
│Agent 接入  │布局/集合/密度  │  │字号 / 密度 / 界面细节    │
│存储/备份   │界面/正文五档字 │  │真实示例 + 保存/错误      │
│            │界面细节与示例  │  └──────────────────────────┘
└────────────┴────────────────┘
```

以上为目标分组示意；当前实际入口仍为“外观与字号”（主题/明暗/字号）和“备忘录”（布局/集合/密度）。“外观与字号”后续可扩为“外观与展现”；桌面仍分类侧栏，移动仍分组首页/子页。移动端的设置入口位于目录页底部，不占用集合页头。先选主题，再选明暗；列表/画廊和三栏/专注明确分组。界面细节默认折叠，避免把图标倍率等高级设置变成首次使用负担。当前设备形态的布局/集合/密度选项优先显示，另一形态放在明确标注的可折叠分组中；手机行采用标签在上、控件在下，保留 44px 命中区。

当前示例使用与真实组件相同 token/字号映射；保存中禁用冲突操作，失败保持旧已确认值并显示重试。当前已提供界面细节重置；“当前外观/当前布局”独立重置属于后续设计，未作为本轮可用入口。不同时重置账户、正文纸张或备份。系统菜单限制在设置说明中明确，不承诺 AppKit 跟随全部圆角/间距。

Agent 页优先桌面：总开关、单客户端授权、目录选择、读/建/改权限、凭据引用、复制配置、撤销、近期操作。新增授权对话打开时焦点到名称，取消不创建 grant，确认后才显示凭据配置，关闭返回触发器；日志空态提示尚无调用，宿主不可用/过期/撤销分别呈现。移动不暴露不可用的“本机 MCP 运行”开关。

本轮新增“启动 MCP 测试程序”入口，弹出具有焦点约束的测试对话框，关闭恢复入口焦点。连接真实适配器后提供工具/schema、手动 JSON 调用、只读批量与显式读写批量。权限不足跳过，读写测试仅修改本轮新建测试笔记；响应、错误、耗时逐项展示，停止/关闭释放子进程。布局及运行边界见[本轮任务](../plan/appearance-mcp-tester-20261117.md)。这不是独立笔记窗口，不注册新的编辑/录音 owner。

待办清单使用圆形可见框，框和首行正文对齐，长行折行留在正文列；紧凑的行距不能继承普通段落的额外间隔。手机触控区域和可见圆圈分别设计，避免扩大段落 margin 来获得命中面积。嵌套任务保持各自缩进，普通列表与正文间距保持自身语义。

## 状态、叠层与响应

| 状态 | 呈现与恢复 |
| --- | --- |
| 加载 | 列表/正文各自显示骨架或明确等待，保留来源；不把空数组当“没有笔记” |
| 真正空态 | 当前范围说明、可用的新建/清除筛选；权限不足不暴露隐藏内容计数 |
| 搜索无结果 | 展示查询和范围，清除查询入口；保持当前输入焦点 |
| 保存/加载错误 | 保留可恢复内容，显示实际阶段和重试，不伪装成功 |
| busy | 保存、录音、导入分别表示；非相关操作尽量可用；外部写遇用户编辑返回忙碌 |
| 受限空间 | 折叠导航/降低列数/溢出菜单/滚动；不缩小命中区 |
| 撤权/锁定 | 既有 access 层覆盖正文、菜单、预览和录音可视内容；主题无权降低遮挡 |

叠层继续复用 content → editor → toolbar → preview → menu → modal → notice → access → startup。抽屉和设置使用正确 portal 目标继承主题；模态约束焦点并恢复；录音右栏与图片浮动预览保持既有非模态语义。

响应代表尺寸：320/390/430px手机、Android横屏与分屏、699/700交互身份边界、820px三栏内容预算、600px两栏内容预算、1100px桌面压缩边界、常用宽窗与短窗；具体断点最终由内容空间约束和实际验证确定。实际组件树为 `PresentationContext → WorkspaceShell → 固定 sidebar / notes-pane / editor-pane`；DesktopShell 提供外围控制，MobileShell 提供集合表头，二者不条件包裹 Editor。EditorSession、SaveQueue、recording owner 位于稳定装配层，不能随 Shell 条件卸载。
