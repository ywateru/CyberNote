# 速绘编辑与手势

2026-11-08

- 移动备忘录页顶部保留返回和更多，移除原“完成编辑”对勾。正文仍自动保存；速绘面板的“完成”负责提交笔画。
- 正文速绘单击进入编辑；长按 500ms 打开统一 MenuSurface 菜单。移动超过 10px 或手势取消会终止长按，长按后的 click 不再进入编辑。桌面可右键或用 Enter/空格进入。
- 菜单提供编辑、复制、剪切、粘贴、导出 SVG、删除；复制保留矢量笔画，粘贴在原速绘后插入独立速绘。系统文本剪贴板允许时写入带笔画元数据的 SVG，移动 WebView 无剪贴板权限时使用应用内回退。回退受源备忘录授权约束。
- 进入速绘同步取消正文自动聚焦意图、收起键盘并冻结正文编辑。完成/取消均不重新聚焦正文。提交前核对源编辑器、备忘录、授权及原绘图节点，防止异步操作写入其他笔记。同内容节点替换使用内容相等判断，避免不改笔画保存后无法再次进入。
- 一指/笔输入绘图，双指平移与缩放。第二根手指落下会撤销第一根手指的临时笔画并保留重做栈；缩放结束后须全部抬起才能继续绘图。笔画坐标使用视图矩阵逆变换，背景与笔画共同移动。取消指针不保存残余笔画。
- 触摸板双指滑动平移画布，捏合以手势位置为中心缩放，范围 15%–800%。兼容 Chromium 的 Ctrl+wheel 和 Mac WKWebView 的 gesturestart/change/end；WebKit 缩放量按手势起点计算，并避免同一捏合重复处理 wheel。只在画布内阻止页面滚动/缩放；画笔按下期间忽略触摸板输入，避免笔画坐标跳变。触摸板导航不产生笔画或改变撤销/重做栈。
- 顶部“横线与网格”支持原有空白及三档横线、网格。修改随完成保存到原备忘录 paperStyle，取消放弃；原笔记更多菜单的背景入口及旧选择页已移除。“适合画布”恢复完整笔画视图。
- 桌面原生附件菜单启用“添加速绘”，面板顶部避让原生工具栏。导出走系统保存位置选择器；Mac 使用现有原子发布与数据目录保护，Android 使用系统文档 URI，临时文件随操作释放。导出期间保留源笔记授权检查。

验证：`pnpm test:drawing` 覆盖单击/长按、菜单图标、矢量复制粘贴、原生导出参数、缩放坐标/误触、撤销重做、完成/取消背景、320px 排版、Android 返回、Mac 原生菜单路由，以及触摸板双轴平移、缩放锚点、WebKit 累计缩放/事件去重、缩放范围和笔画历史保护。该自动化使用真实产品 React/ProseMirror 代码，系统对话框和 IPC 由隔离环境模拟，WebKit 手势由合成事件验证；原生打包和真机记录另见 artifacts/drawing-interactions，触摸板版 Mac 包及原生平移截图见 artifacts/drawing-trackpad。
