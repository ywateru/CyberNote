## Default Permission

Own-window toolbar binding, state updates, inspection, search focus and teardown. No note storage access.

#### This default permission set includes the following:

- `allow-bind`
- `allow-update`
- `allow-unbind`
- `allow-inspect`
- `allow-focus-search`
